# 我有一座恐怖屋 · 陈歌篇（文字版）· 开发守则

源码在 `src/`，`python3 build.py --deploy` 生成 `../index.html`。存档键前缀 `kbw.`（`kbw.save.N`、`kbw.jr.N`、`kbw.set`）。单人游戏，没有联机。
设计沿用《完美世界·石昊篇》的界面与规则（见游戏厅 `wanmeiol/src/OPTIMIZATIONS.md`），恐怖演出参考「百物语」。
