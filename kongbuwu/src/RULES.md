# 我有一座恐怖屋 · 陈歌篇（文字版）· 开发守则

源码在 `src/`，`python3 build.py --deploy` 生成 `../index.html`。存档键前缀 `kbw.`（`kbw.save.N`、`kbw.jr.N`、`kbw.set`）。单人游戏，没有联机。
设计沿用《完美世界·石昊篇》的界面与规则（见游戏厅 `wanmeiol/src/OPTIMIZATIONS.md`），恐怖演出参考「百物语」。

| # | 规则 | 怎么保证 |
|---|------|----------|
| 1 | **玩家就是陈歌。** 剧情按原著顺序走（接手恐怖屋 → 平安公寓 → 西城私立学院 → 暮阳中学 → 海明公寓 → 第三病栋），人名、地名、任务、道具、天赋、称号用原著的；剧情文字全部原创改写，不抄原著段落。黑色手机的提示只保留很短的功能性原句。原著没交代的不编造设定。 | 人工；改剧情前先 grep 原文核对 |
| 2 | **一次只显示一种画面**：探索（冷青黑）· 对话（旧纸；黑色手机的话是黑底红字）· 对峙（暗红；白天吓游客是暗紫）。记录/回忆录/档案/弹幕收在「📜 记录」；底栏只有 探索·陈歌·员工·背包·地图·📱手机。画面交叉淡化，离开对话先等 140ms。 | `test/mobile.js` 看图 |
| 3 | **不画原著角色**：说话的人用印章名牌（乐园橙、警察蓝、游客绿、鬼怪紫、红衣赤、敌人暗、医生青、网络灰）。惊吓画面只画“某种东西”。 | 人工 |
| 4 | **选择要有后果**：选项写进 `C.f`，后面一定读到（徐婉好感、徐叔的台词、猜凶手、寻人启事、笔仙的雇佣、门后开口掉精神……）。 | `test/flow.js` 打印 flags |
| 5 | **对峙**：对方意图提前显示；⚠ 大招先亮一回合，能防御减半，打懵/打中弱点/白猫扑脸能打断；陈歌和员工各有回合、先后可选、技能横幅分开；吃喝不占回合（每回合一次）；自动对峙会吃喝、防大招、打弱点；故事战有绝境（一次）和首领半血狂怒。白天接待游客用同一套引擎：把游客「胆量」吓到零，自己的「氛围」不受伤。 | `test/features.js` |
| 6 | **动画只是回放** `B.ev`；默认开，不跟随系统“减弱动态效果”；关掉也能在卡片上看到本回合伤害。**惊吓画面**（整屏的脸 + 刺耳声）设置里能单独关，关掉换成红光和心跳。 | `test/features.js` |
| 7 | **不用现实时钟**：一天 12 格，0–6 白天（乐园营业、接待游客），7–11 夜里（任务、夜探）；睡觉换天；日常任务、歇脚按游戏天刷新。夜里打车不耗时间（不会把夜间任务拖到天亮）。 | `35_play.js` |
| 8 | **非战斗互动用小游戏**（`44_mini.js`：看准时机 / 按住 / 忍住别点 / 连点 / 趁它没看着）。先显示说明，点「准备好了」才开始计时；都能跳过；失败先问「再试一次 / 跳过」，跳过走失败那一支，绝不卡关。 | `test/features.js`、`node test/flow.js 1 fail` |
| 9 | **不经用户确认不改平衡数值**（`BAL`、`HERO`、`MOBS` 倍率、`PROF`）。改前改后都跑 `node test/balance.js`，目标：标准难度自动对峙胜率 70–100%。剧情战的等级跟着陈歌走（`L(±n)`）。 | `test/balance.js` |
| 10 | 顶层函数不能重名；剧情步骤 id 唯一、不能改；地图出口必须双向；闲话/闲聊带地点和剧情区间、不重复、不超进度；小剧场指令、道具贴图、场景、效果、音效（`^` 和 `~`）拼错直接报错。 | `build.py` 直接报错 |
| 11 | **点了没反应 = bug**：按钮要么生效要么 toast 原因。跳章/读档/回标题遇到进行中的剧情、小游戏、对峙直接放弃（`dropRunning`），保留玩家偏好。 | `test/features.js` |
| 12 | 新写一卷 = 一整套：剧情步骤 + 区域/地点（含画） + 对手和台词 + 首领 `epic` + 闲话/闲聊 + 夜探怪表 + 跳章预设 + 平衡测试 + flow 走到新结尾。 | 清单 |
| 13 | 手机竖屏/横屏、平板、电脑都放得下，**所有画面统一上下排**：上面是画面（探索横幅/小剧场），下面是文字和按钮；宽屏时内容是居中的一栏（不再左右分开）。横屏手机藏掉日志小条、小游戏时藏掉小剧场。宽屏菜单在右侧窄栏靠下。 | `test/mobile.js`（6 种屏幕，查横向溢出和按钮出屏） |
| 14 | 行内注释只用 `/* */`。脚本台本（`T_`）每行 “谁\|话”，行首 `@` 手机、`>` 弹幕、`!` 惊吓（同时闪白+震屏）、`#` 整屏旁白（`#m` 回忆、`#r` 血色）、`~` 音效、`%` 震屏、`^` 小剧场指令（见下）。 | — |
| 15 | **像素小剧场**（`51_pix.js` 是百物语的像素小人库，`53_stage.js` 是舞台）：对话画面上方是 208×112 的像素舞台，探索画面的横幅是 320×112。说话的人自动从镜头边缘走上台、面朝陈歌；打电话的人（`^call 名字`）不上台，陈歌拿着手机；鬼怪淡入淡出。人物一律是通用像素小人（`PPL` 表只定发型/衣色/体型），不画原著角色。指令：`^in 名字 [格]`（走上台）、`^at 名字 格`（直接出现）、`^out 名字`、`^to 名字 格`、`^turn 名字 L/R/F/B`、`^down/^up 名字`、`^fx dark/candle 格/rain/red/tv/flash/shake/light/clear`、`^prop id 图 x y {json}`（`{"front":1}` 画在人前面，如铁笼）、`^del id`、`^stage 场景`、`^call/^hang 名字`、`^wait 毫秒`。`^stage` 和剧情里的 `go()` 会立刻换景（清掉别人、效果、道具），所以先换景、再加人和效果。舞台按地点的 `art` 选背景（`STAGES`），夜里变暗、陈歌带手电光圈，黑暗里其他人留一圈淡光；镜头放得下就拍进所有人。剧情开场只带上当前地点的 NPC。同时最多 6 个人。 | `test/features.js`、`node test/storyboard.js`（每句话截一帧，看站位） |
| 19 | **剧情要真的吓人**：每场至少一个“不对劲”的具体细节（多出来的人偶、慢半拍的倒影、对不上的嘴型、湿的头发、多走一步的脚步声），用留白和短句收尾；白天营业的轻松场景结尾也留一点阴影。开头有冷开场（半年前凌晨两点四十四分的黑色手机）。**恐怖演出**（只在必要的地方用，不要句句都吓）：`^fx flicker`/`steady` 手电接触不良；`^creep 名字 格` 只在灯灭的那一下往前挪（配合 flicker）；`^fx glitch [on/off]` 画面撕裂；`^scare 名字` 贴脸特写（关掉惊吓画面时只闪红光 + 心跳）；`^sfx whisper/steps/creak/breath/giggle/scrape/hum…` 单个声音。黑暗场景里会自己随机出环境声，鬼离陈歌很近时有心跳。剪影鬼（红影、黑影、镜鬼）用 `sil`，瘦长怪物用 `tall`。 | `test/features.js` |
| 16 | **主线有门槛，门槛要说清楚**：步骤可以带 `need()`（如“本月游客 100 人”“好评/差评”“再接待两批”），没达到时任务栏直接写差多少、主线箭头指回恐怖屋门口，到了剧情地点也只 toast 原因，不会开始剧情。门槛只用营业能攒到的东西。 | `test/flow.js`（会自己去营业凑门槛，打印 grind） |
| 17 | **营业要有选择**：每批游客人数随关注涨；6 个场景各有特色（`scenePas`：胆量/收入倍率 + 某类手段加成 + 每回合效果）；6 类游客各有特性（`TRAITS`，卡片和档案里写明）；总控制室能花钱翻新（`UPGRADES`，8 项，永久）。陪员工（每天一次 +6 好感）、员工值班会涨好感。 | `test/features.js` |
| 18 | **剧情要看得清**：调查用 `look()`（列出能看的东西，看够了才能继续）；读过的句子记在 `kbw.read`，⏩ 快进只跳读过的；「回看」显示本段已说过的话；剧情里熬夜/天亮要拨钟（`setClock`）和出天数卡（`dayCard`）。夜探有 16 个按进度出现的一次性事件（`NIGHT_EV`）。 | `test/features.js` |
| 21 | **镜子要真的照出东西**：`^mirror 格 [big]` 挂镜子（画在黑暗上面，反着烛光）；`^mirror follow/lag/stare/smile/close/empty/other 名字/hand/crack/out/off`。镜子剧情（镜子游戏、舞蹈室、303、走廊、浴室）都用它，不要只写“镜子里的你……”。整屏惊吓 `!face/mirror/eyes/hand/red` 是 120×160 像素逐帧动画（`paintScare(x,W,H,kind,p)`），每种配不同声音。 | `node test/storyboard.js S_mirror,…` 看图 |
| 22 | **声音**（`00_core.js`，全部合成）：混响 + 左右声道；`V({...})` 一个声音（振荡器/噪声、滤波、包络、声像、混响、颤音、调幅）；每个音效在 `SFX_GAIN` 里校准过音量（氛围音峰值约 0.06–0.15、惊吓重击 0.2–0.3、背景 rms 约 0.02）。背景氛围 `MOODS`：持续音（会呼吸）+ 底噪 + 不定时事件（八音盒、敲门、脚步、耳语、远处的闷响、金属、尖啸）。剧情里 `^mus 氛围` 在这一场里一直有效。 | `node test/audio.js`（离线渲染：每个音效、每种氛围都有声音且不爆音，导出试听 WAV） |
| 20 | **好玩但不复杂**（`46_fun.js`）：新玩法每条最多多一个按钮，不加要管理的资源。看准时机（开门杀/断电的缩圈，完美 ×1.3）、躲大招（防御时看准时机完全躲开）、换着吓（换招连段 +8%/层，最多 4 层；同一招连用 ×0.88/次）、全场尖叫（一回合吓跑一整批，每人 +15 尖叫）、挑剔的游客（每天一位，吓对了 +120 元）、评论墙、营业一整天、首领软肋（开场提示，用对 ×1.5 + 懵）、场景一击（每场一次，不占回合）、夜探三扇门和弹幕点播、怨念物（4 组×3 件，凑齐有小加成）、特殊游客（8 位）、转盘大奖、陪员工小剧场、东郊倒计时（十天一阶段）、章节评级（S/A/B/C）、30 多个成就、每天第一次回恐怖屋的小惊喜。**自动对峙要会用这些**（比如接待游客时会换招），不然平衡会被拖垮。数值都在 `46_fun.js` 顶部的常量里。 | `test/features.js` 第 16 段 |
