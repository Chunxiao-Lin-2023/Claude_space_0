# 我有一座恐怖屋 · 陈歌篇（文字版）

根据我会修空调《我有一座恐怖屋》改编的单人文字游戏。第一卷五章：濒临倒闭的恐怖屋 → 午夜逃杀（平安公寓）→ 红舞鞋（西城私立学院）→ 暮阳中学 → 第三病栋。

- 白天在恐怖屋门口「接待游客」：像百物语那样的俯视鬼屋地图，六个场景各 5–8 个房间（死路、暗道、能躲的柜子）。先布置——圆圈里放开门杀、纸人、断电、老电视、喜堂唢呐……人形框里安排徐婉、小小、笔仙、白猫、校服残念站岗；再开门亲自扮鬼：点哪走哪，躲进柜子，等游客踩上机关那一刻拉下去，追着慌了的游客扑。别让他们迎面看见你。吓退一半以上就有门票、尖叫和好评（100 尖叫转一次转盘）。剧情里的几批“难缠游客”各有规则：鹤山躲在学姐身后、费友亮举着摄像头找员工、王海龙兄弟抢校牌。
- 剧情小剧场：每个场景的布景按剧情地点画（发霉的 208、三个人的 303、器材室、院长办公室、门后的红色病房、雨里的深井……）；鬼怪都有自己的样子（长发红衣、瘦长无脸、两张脸、半边脸、歪脖子护士……），黑里也看得见；血从墙上淌下来、地上伸出手、黑暗里的眼睛、黑色的雪、水底的走廊、镜头推到脸上。
- 开门以后看得到全屋：右上角是监控小窗，拖动地图看别处，画面边上的箭头指着外面的游客；电控机关（📡）在哪都能拉。总控制室能采购吊死鬼、衣柜鬼手、婴儿哭声、午夜电话、人偶墙、血手印、天花板脚步、棺材；每个场景还有一个自带的专属机关（鬼新娘、剪刀狂人、僵尸群、第三个人、广播点名、推床）。敲墙「引」游客过来、点员工让他冲出去、每场有 S/A/B/C 评级。随时能暂停、提前收工。
- 夜里的大战之前先被追：钻柜子、换地方躲、找到关键的东西或撑到员工准备好，再回头跟它打。
- 剧情有像素小剧场（参考百物语）：说话的人走上台，鬼怪淡入，手电光圈、烛光、雨、红光、闪白震屏；五章都有站位和道具。
- 恐怖演出：手电接触不良时有东西在黑暗里逼近、画面撕裂、贴脸特写、耳边的呼吸和脚步声，鬼靠近时有心跳。都能在设置里关掉惊吓画面。
- 夜里做黑色手机的任务：小游戏（镜子游戏、深水、看不见的客人、笔仙、看谁先开口说话……）和对峙。
- 员工：徐婉、殷小小、笔仙、白猫、校服残念；张雅只在吃下那颗糖的时候出现。
- 📱手机里有恐怖屋面板、日常任务（简单 / 一般 / 噩梦）、转盘、厉鬼好感。
- 玩法小花样（都只是多一个按钮）：开门杀看准时机打出完美一击、首领大招看准时机躲开、换着手段吓有连段、一回合吓跑一整批是“全场尖叫”、每天一位挑剔的游客、评论墙、一键营业一整天、首领软肋、场景一击、夜探三扇门和弹幕点播、怨念物收集、午夜售票台的特殊游客、转盘大奖、东郊乐园倒计时、章节评级、成就。
- 5 个存档位、存档码、跳章、难度三档；对话能回看、能快进读过的句子；惊吓画面和动画都能在设置里关。
