# 我有一座恐怖屋 · 陈歌篇（文字版）

根据我会修空调《我有一座恐怖屋》改编的单人文字游戏。第一卷五章：濒临倒闭的恐怖屋 → 午夜逃杀（平安公寓）→ 红舞鞋（西城私立学院）→ 暮阳中学 → 第三病栋。

- 白天在恐怖屋门口「接待游客」：用背景故事、背景曲、开门杀把游客的胆量吓到零，赚门票和尖叫（100 尖叫转一次转盘）。
- 夜里做黑色手机的任务：小游戏（镜子游戏、深水、看不见的客人、笔仙、看谁先开口说话……）和对峙。
- 员工：徐婉、殷小小、笔仙、白猫、校服残念；张雅只在吃下那颗糖的时候出现。
- 📱手机里有恐怖屋面板、日常任务（简单 / 一般 / 噩梦）、转盘、厉鬼好感。
- 5 个存档位、存档码、跳章、难度三档；惊吓画面和动画都能在设置里关。

源码在 `src/`，守则和测试方法见 `src/RULES.md`。存档键前缀 `kbw.`。
