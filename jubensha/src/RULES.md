# 剧本杀 · 开发守则

> 做新剧本、或者改了引擎/AI/界面之后：先读、再更新 [`SCRIPT_GUIDE.md`](SCRIPT_GUIDE.md)（字段参考、制作流程、设计规则、平衡目标、试玩清单、踩过的坑）。

## 结构
- `00_core.js` 状态 `G`、存档、阶段表、难度表 `DIFF`（AI 发言预算、行动点、提示扣分、反驳/嫁祸开关）
- `1N_<剧本>.js` 剧本数据（每本一份，可拆两个文件）。原文放在 `text/*.txt`，构建时注入 `TEXT`。字段说明见 `SCRIPT_GUIDE.md`
- `20_engine.js` 规则引擎：`apply(G, action, seat)` 是唯一改状态的入口；联机时只在房主上跑
- `25_ai.js` Claude 扮演 AI 玩家（只在单机/房主运行）；`vendor/aikit.js`、`vendor/titlekit.js` 是 `shared/` 的副本
- `30_ui.js` 画面与弹窗；`40_art.js` 程序绘制（每本剧本的平面图/线索图挂在 `SCRIPTS.<sid>.art`）；`45_audio.js` 合成音效；`50_net.js` PeerJS；`90_main.js` 入口
- `python3 build.py [--deploy]` → `out/index.html`、`out/test.html`（带 `window.__dbg`）、`out/artifact.html`；`--deploy` 写 `../index.html`
- `check.js` 在构建时检查剧本数据：引用的线索/证词/话题/角色都要存在，非凶手不能有谎话，第一题答案必须是凶手

## 剧本数据怎么写（新剧本照这个格式）
- `clues`：r=1 现场（要在 `spots` 里给平面图位置），r=2 私有（`owner`）或现场深入（`scene`）
- `facts`：证词和推论。`who` 决定放在时间线板哪一列，`t` 决定哪一行；推论 id 用 `d_` 开头
- `ans[角色][话题]`：从上往下第一条 `when` 成立的；`kind` 是 truth / evade / lie / crack。**非凶手只能 truth / evade**
- `show[角色][线索]`：被出示时的反应；`brk` 打开话题（之后问他就说实话）；`_` 是默认反应
- `talk`：AI 主动发言、互相提问、互相出示，按顺序挑第一条能做的；推论类排在前面；每阶段受难度里的 `budget` 限制，剩下的要靠玩家自己出示证据或「指出关联」触发。`diff: 'rebut' | 'frame'` 的条目只在对应难度出现（AI 凶手反驳 / 嫁祸）；`cut` 削弱一条推论、`uncut` 恢复、`push` 加嫌疑
- `links`（11_ 文件）：玩家「指出关联」时能成立的两两组合 → 得出推论（`reveal`）或逼出实话（`brk`）；`contra` 里的组合也能被玩家指出
- `intros`：自我介绍三选一（low / strong / mislead）；strong 让 AI 多一分戒心，最终陈述里会被提起
- `finals`：最终陈述（真人嫌疑人投票前的一句话）
- `deck[角色]`：真人扮演时能选的说法（`vol` = 能主动说；`push` 加别人的嫌疑；`cut` 削弱某条推论；`confess` 1=认罪 2=支线失败）
- `contra`：两条一起公开 = 有人说谎被抓，指定谁来指出
- `sus`：公开后 AI 心里的嫌疑加减。AI 投票只看已公开的东西，从不读真相

## Claude 扮演 AI 玩家（`25_ai.js` + `vendor/aikit.js`，源头在 `shared/aikit/`）
- 只在单机/房主上运行；朋友不需要密钥，只看结果（台词随状态同步）。没有密钥或调用失败就是原来的脚本 AI。
- **硬性规则（代码保证）**
  1. 引擎决定一切事实（谁说实话、透露什么、谁破防），Claude 只把引擎定好的那句台词换个说法（日志 `e.text0` 留着脚本原句，界面上“Claude”小标签悬停可看）。
  2. Claude 拿不到未公开的线索、别人的剧本、真相；只拿到这个角色的人设、已公开信息、最近对话和要说的原句。
  3. 每句都过 `aiCheck`：秘密词表 `secrets`（未公开前不许出现，原句里有的除外）、时间点必须在原句或已公开证词里出现过、凶手不许有认罪说法（`confess`）、不许出戏词、长度上限。不过就用脚本原句。
  4. 玩家自由打字只会被归到已有动作（问某人某话题 / 出示某条 / 选剧本允许的某句说法）；不是凶手的玩家，说和自己剧本矛盾的话直接被拒。自由打字不会产生剧本里没有的效果；朋友发来的 `free` / `fromFree` 操作房主一律丢弃，只能由房主本机归类后产生。
  5. 失败、超时（12 秒/20 秒）、401/429：用脚本台词；密钥无效时自动关掉 Claude 并提示。
- 档位：省钱（全 Haiku）/ 均衡（破防、最终陈述、指出矛盾用 Sonnet）/ 高质量（全 Sonnet）。
- 测试：`node test/ai.js`（假 API，不花钱）：台词改写、泄露/编时间/认罪被拦、超时退回、自由提问和出示归类、非凶手说谎被拒、联机时朋友无密钥也能看到 Claude 台词和自由提问。

## 难度（`00_core.js` 的 `DIFF`）
| | 简单 | 标准 | 困难 |
|---|---|---|---|
| AI 发言预算（一轮/二轮） | 10/16 | 8/12 | 6/8 |
| 真人行动点 | 7 | 6 | 5 |
| 提示扣分（评级） | 0 | 3 | 6 |
| AI 凶手反驳推论 | 否 | 是 | 是 |
| AI 凶手嫁祸 | 否 | 否 | 是 |
| 座位下的嫌疑条 | 显示 | 显示 | 不显示 |
AI 反驳把推论打到 ×0.6，真人反驳打到 ×0.4；无辜 AI 会回击，把推论恢复。

## 平衡（用户确认前不改数值）
`test/solo.js` 会跑三种局并打印 AI 的嫌疑分：
- 侦探局按正常思路打 → AI 投王村长，满分
- 凶手局“消极”（总选第一个说法）→ 应该被投出
- 凶手局“聪明”（藏借条和床板、在地洞上撒谎、嫁祸张村民、反驳推论）→ 应该有机会脱身（目前标准难度 王 6 对 张 10.1，偏宽松）
- 无辜玩家（胡调研）照实说 → AI 应该投王村长
改 `sus`、`DIFF`、`talk` 顺序之后都要再跑 `node test/balance.js`，目标见 `SCRIPT_GUIDE.md` 第 5 节。

## 界面守则（沿用 wanmeiol/src/OPTIMIZATIONS.md 的剧情类规则）
- 一次一个画面，各阶段配色不同（读本/答卷=纸、搜证=夜色青、讨论=烛光、真相=暗红）；同一画面重画不重放淡入（`body.same`）
- 说话的人用印章名牌；新消息到达自动滚到底，但用户往上翻时不打断（显示「↓ N 条新消息」）；只有新消息淡入，旧消息不重放
- 弹窗在画面刷新时保持滚动位置；笔记、关联这类有输入的弹窗不随状态刷新
- 点了没反应就是 bug：不能做的按钮置灰或弹提示
- 房间码用等宽粗体
- 回游戏厅：标题左上「‹ 游戏厅」，菜单里「返回游戏厅」；联机中要点两次确认

