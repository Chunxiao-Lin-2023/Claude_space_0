# 剧本杀 · 夜半推理馆

单文件网页剧本杀。1–2 名真人，其余位置由 AI 扮演（纯脚本，不联网也能玩）。第一本是《人吃人》（无主持封闭本原文），第二本《再见卡门》制作中。

- **玩法**：读本 → 自我介绍 → 第一轮现场勘查（赵家平面图，线索全公开）→ 讨论 → 第二轮搜身搜屋（每人 6 点行动点，你查一次 AI 也查一次，搜到的线索只有自己看得到）→ 讨论 → 八道题答卷（第一题即指认）→ 投票 → 真相（时间线逐格回放、原文案件解析、个人结局、得分）。
- **模式**：单人当侦探（4 名嫌疑人都是 AI，你一个人指认）、单人入局（拿一本人物剧本，可能就是凶手）、双人联机（两人都入局，或房主当侦探）。
- **AI**：只有凶手会说谎，其他人只会隐瞒或回避。向任何人提问、出示线索或证词；戳中要害，隐瞒的人会改口说实话。点「听大家说」，AI 会互相质问、提出推论。玩家是嫌疑人时，AI 会来问你，你只能从你的剧本允许的说法里选（凶手可以撒谎、嫁祸、反驳推论，谎话被别的证词撞上会被当场指出）。
- **工具**：📖 剧本、🗂 线索箱（公开 / 私有 / 证词与推论）、🕒 时间线板（已公开证词按时间排好）。
- 进度自动保存（单机和房主），标题画面「继续上次」。

源码在 `src/`，守则和测试见 `src/RULES.md`。存档键前缀 `jbs-`。
