# 沙丘乱斗

俯视角 3D 吃鸡乱斗（实时 three.js，程序化建模的原创 Q 版英雄）。草丛隐身、开能量箱攒能量块（+生命/伤害）、可破坏墙体、毒雾缩圈，活到最后的人（队伍）获胜。

- **单人吃鸡**：你 + 9 个 AI，各自为战。
- **双人吃鸡**：你和一个 AI 队友 vs 4 支 AI 队伍；队友活着时阵亡可复活。
- **联机双人**：一人点「创建房间」，把 4 位房间码发给朋友，朋友输入后加入，两人组队 vs 4 支 AI 队伍（WebRTC 直连，房主页面保持在前台）。

英雄（12 位）：铁砧（霰弹）、灵狐（弩箭狙击）、熔岩（火焰坦克）、炸弹喵（越墙投掷）、飞鸢（双枪连射）、扳手兔（弹跳能量球 + 炮台）、蘑菇婆婆（毒圈 + 治疗圈）、冰冰（减速雪球 + 暴风雪）、阿刺（突刺 + 飞扑）、灯灯（穿墙回旋灯笼 + 隐身）、熊大锤（近身锤击 + 眩晕震地波）、电光（连锁闪电 + 护盾）。

操作：WASD 移动 · 鼠标瞄准 · 左键攻击 · E/右键 按住瞄准大招 · 空格 自动瞄准 · F 自动大招 · Esc 暂停 · M 静音；大厅里 ←→ 选英雄、Enter 开战。iPad：左半屏拖动移动，右下摇杆拖动瞄准松手攻击（轻点自动瞄准），黄色摇杆放大招。

源码在 `src/`（见 `src/README.md`），改完运行 `python3 src/build.py --deploy` 重新生成本目录的 `index.html`。
