# 十夜怪谈

像素风恐怖探索合集：十个流传已久的怪谈，每个故事是一章俯视角探索解谜游戏。支持双人联机——两人共享同一个角色和画面，同一时刻只有一人操作，另一人可以请求接手（操作者同意后交换）。

| 夜 | 故事 | 来源 |
| --- | --- | --- |
| 一 | 血腥玛丽 | 英美都市传说 |
| 二 | 裂口女 | 日本都市传说（1979） |
| 三 | 厕所里的花子 | 日本学校怪谈 |
| 四 | 一个人的捉迷藏 | 日本网络怪谈（2006 前后） |
| 五 | 电梯游戏 | 韩国 / 网络怪谈 |
| 六 | 375路末班车 | 中国大陆网络都市传说 |
| 七 | 消失的搭车客 | 美国及世界各地都市传说 |
| 八 | 猴爪 | W·W·雅各布斯短篇（1902） |
| 九 | 画皮 | 蒲松龄《聊斋志异》 |
| 十 | 哭泣的女人 | 墨西哥民间传说 |

## 源码

- `src/shell.html` 页面骨架与样式；`src/js/` 引擎（核心/精灵/世界/剧本/联机/界面）；`src/chapters/` 每章一个文件。
- 构建：`python3 nighttales/src/build.py`（生成 `index.html`；`--artifact out.html` 生成单人预览版；`--only id` 只打包某章）。
- 写新章节看 `src/AUTHORING.md`。
- 测试：`src/tests/play.py`（每章自动通关，步骤在 `tests/sol/`）、`src/tests/coop.py`（本地 PeerJS 服务器 + 双客户端联机）。
- 本地存储键前缀 `nighttales.`；联机房间 id 前缀 `nighttales-`。
