# 第四夜「湘西赶尸」审查与优化（ganshi）

先按 `play.py --shots` 跑通并逐张看截图，再用实时脚本按真人速度模拟了让道段（锣声追来）和三更潜行段（她循着气味找人），据此写下 20 条，全部已实现。

## 故事与传说

1. **祖师爷传说进游戏**（已实现）：起源说（蚩尤命军师驱尸还乡、辰州「祝由科」）原来只写在档案里，游戏里看不到也听不到 → 幺儿第二次搭话时讲祖师爷蚩尤的故事，并带出「别个都说是背着走、抬着走的……可有些喜神是自己在走的」，和盐客、田老伯的怀疑说法对照。
2. **台词前后呼应**（已实现）：夜里想出店门会提示「滕师傅说了，鸡叫之前莫出店门」，可滕师傅从没说过；田老伯管朱砂的线索藏在老板娘第三句轮换台词里，补符时却说「老板娘说过」→ 滕师傅交代规矩时补上「鸡叫之前，莫出店门」；田老伯线索挪进老板娘第一次对话，轮换台词改成指路（往南走到头是祠堂和义庄）。
3. **「回头」的后果兑现**（已实现）：木牌写着「回头它就记得你了」，但 `S.f.looked` 之后只用了一句台词 → 山路上回过头的人：三更时她的脑袋朝你屋子歪过来，嗅觉范围多 1 格；义庄里那声音多一句「山路上……你回头看过我的呀」；好结局多一段尾声（铃声在他背后停了一停，像是认出了他）。

## 谜题

4. **符头写名不能瞎蒙**（已实现）：原来是「吴氏 / 秀姑 / 滕秀姑」三选一，最长的那个一看就是答案 → 改成密码盘，从「吴 滕 向 秀 姑 氏」六个字里一笔一笔写三个（键盘 1–6），「向」取自祠堂匾额作干扰；写错一次香短 30 秒，并按写法给针对性的内心提示（吴＝账簿上的假名、向＝祠堂的姓、只写秀姑＝缺姓）。
5. **铃锣密码盘说清楚、能用键盘**（已实现）：原提示不说要按几下，键盘只能用方向键挑 → 提示写明「按四下 / 两下 / 三下」，加 `alias` 让 1＝铃、2＝锣（L/G 也行）；双人时提示「另一位可以打开『笺』念口诀」，形成一人念一人敲的分工。
6. **卡关逐级提示与补救**（已实现）：寨口起身/随行敲错只会重复同一句；先舀了井水的人倒不掉，得跑完祠堂回来写符失败才知道 → 连错两次滕师傅亲口念那句口诀；敲出「锣锣」开头她会原地转身（口诀里「转身」那句终于有了回应）；拿着井水去檐下瓦缸可以泼掉重接无根水。

## 节奏

7. **盐客一口气九页**（已实现）：第一次搭话把三种怀疑说法连讲九页，玩家想走走不了 → 拆成两次：先讲背尸、竹竿抬尸，末尾「再坐一会儿？我还有一说」；第二次讲遗骨说和「我是不信……可我也从来不回头」；之后才进轮换台词。

## 恐怖与氛围

8. **秀姑的惊吓大头像**（已实现）：三处 `S.scare('face')` 都在裁人物精灵的小脑袋，糊成一团 → 新增 `faces.xs3up`（符落后：湿发贴脸、歪斗笠、额上一道往下淌的朱砂、先闭后猛睁的翻白眼、嘴角淌河水）和 `faces.xs3`（山路回头时：黄符盖脸，被风掀起一角，露出一只睁着的眼）。
9. **合成阴锣、铜铃、鸡叫、狗叫**（已实现）：锣声原来用 `thud`（像跺脚），天亮的公鸡打鸣用的是 `bell` → 用 `S.tone` 合成锣（低频＋不和谐泛音的「哐」）、铜铃（两下脆响）、公鸡三段打鸣、狗吠；让道段锣铃按队伍距离由远及近，跟随段前方锣铃一直在雾里引路，敲口诀时听到的也是真锣真铃。
10. **黑暗里的心跳**（已实现）：三更堂屋黑度 0.88、光圈 2.4 格，常常看不见她在哪 → 她进入 4 格内就有心跳声，越近越急（4/3/2 格三档），既是氛围也是潜行时「该站住了」的提示。
11. **回店时门板后的喜神转了头**（已实现）：补符段要在三张图之间来回跑，老店里毫无变化 → 第一次回堂屋时，门板后第二位喜神的斗笠偏向你这边（sting＋轻震），之后调查它有新的描述。

## 危险段

12. **让道段太容易**（已实现）：走到 x≥14 就响锣，石窝就在脚边（12、13），躲进去不用一秒 → 改为 x≥17 触发，两边最近的石窝各 4 格，队伍 2.1 格/秒；实测反应 1.2 秒后往回躲约 3 秒到位，愣在路当中 8.7 秒被撞上，往前冲去东边石窝也来得及。
13. **潜行规则不公平**（已实现）：原来要站定 1.2 秒才算屏气，期间她照样 35% 朝你游走，按提示「站着不动」反而常被撞上 → 站定 0.5 秒即闻不着；你不动时她不再朝你偏；贴到跟前只会「闻一闻」（气泡＋低语）然后走开；被追时先走开再站定 1 秒她就停。
14. **一炷香每次都回满**（已实现）：每次存档、每次死后重来，`resume` 都重新给 300 秒 → 存档时记下香还剩多少（`S.f._inc`），重来取「剩余与 90 秒」中较大者，写错名字扣的时间也算进去。
15. **死亡后逐级提示**（已实现）：同一段死几次，重来后都一样 → 死亡次数写进当前检查点：让道段第 2 次起说清石窝的样子和位置；三更段第 1 次提醒「走一步停一停」、第 2 次讲清心跳＝该站住、被追先走开（附 toast），第 3 次起她的嗅觉范围减 1 格；香烧完重来时提醒并刷新缺什么的目标。

## 双人

16. **关键抉择改成两人投票，客机判定改用 `S.moving`**（已实现）：回头看一眼、吹灯、义庄应声、天亮送不送、寨门替她应五处改 `S.vote`，并写出意见不合的分支（「脖子还是自己拧了过去」「喉咙里冒出半个音……棺材里『咚』地一声」「两个人的声音叠在一起」）；屏气判定和寨口跟走时的锣铃原来看 `p.mv`，客机操作时主机上不准，改用 `S.moving`。

## 结局

17. **结局收集**（已实现）：章节没有 `endings`，三个 `S.end` 都没有 `id` → 加 `endings: {home, lamp, answer, leave}`，每个结局都带 `id`，档案里显示「结局 n/4」。
18. **第三结局「没有送她」**（已实现）：天亮后滕师傅托你送秀姑回麻阳，原来的第一个选项「送她回去吧」和他下一句「明天替我敲锣」重复，而且没有不送的余地 → 他讲完秘密后存检查点 `dawn`，两人投票「我跟你去 / 这一趟我不敢」；不送进入坏结局（老人倒在寨外风雨桥上，娘在寨门下站了一夜，「桥和寨门，只隔着三十步」），保留检查点，重来直接回到这个选择。

## 画面

19. **石窝认不出来**（已实现）：目标写「躲进山壁上的石窝」，石窝却只是山壁上一块和路一样颜色的缺口 → 新增 `shiwo` 精灵画在石窝的墙面格：熏黑的凹槽、往上的烟痕、插着的残香（香头一明一暗）和蜡泪，远远就能看出那是能躲人的地方。

## 可玩性与 bug

20. **寨口的黄狗从来不叫**（已实现）：狗的精灵有 `bark` 状态，剧本却只把它设成 false，口诀「家犬须拴牢，莫使吠叫」落了空 → 领着秀姑一上路（x≥8）狗就扯着链子狂叫（合成狗吠，身后的跳步声顿了一顿），走近（x≥19）看清你身后的东西后叫声断掉、缩成一团（新增 `cower` 画法和对应的调查描述）。
