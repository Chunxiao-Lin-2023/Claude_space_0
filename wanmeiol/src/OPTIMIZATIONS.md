# 完美世界 · 石昊篇（文字版）— 优化记录

游戏：Chunxiao-Lin-2023/Claude_space_0 仓库的 `wanmeiol/`（源码在 `wanmeiol/src/`，开发守则在 `src/RULES.md`）。
这份记录汇总了 2026-11 这一轮里用户提出或认可的所有优化（28 条通用规则）。**以后继续做这个游戏、或做别的剧情类网页游戏时，这些都要保持。**

---

## 一、通用清单（做任何剧情游戏都照做）

| # | 要保持的东西 | 由来 |
|---|---|---|
| 1 | **一次只显示一种画面**：探索（暗绿）/ 对话（米黄纸）/ 战斗（暗红），颜色一眼分得清；完整文字记录、回忆录、图鉴收进顶栏「📜 记录」；底栏只放 探索·石昊·灵兽·背包·地图 | 「界面过于繁琐，不同类型的界面分不太清」→ 选了“场景切换式” |
| 2 | **切换不许闪**：画面常驻、交叉淡化；离开对话先等 140ms（下一句往往马上就来）；同一个人连着说话不重复盖章；只有进战斗有整屏转场 | 「每次对话或日常点击之间太闪，不丝滑」 |
| 3 | **不画原著角色**：说话的人用原创印章名牌（名字 + 阵营底色） | 版权 |
| 4 | **选择要有后果**：选项写进 flag，之后一定在台词 / 奖励 / 事件里读到 | 建议 1 |
| 5 | **回忆录**：剧情台词按章节记下来，随时重读；剧情步骤按 id 存档，插新剧情不坏旧档 | 建议 3 |
| 6 | **战斗可读、可应对**：敌人下回合意图提前显示；⚠ 大招能防御减半，打晕或打中弱点能**打断**；首领半血狂怒并说一句话 | 建议 3、8、9 |
| 7 | **主角和伙伴各有回合**：先给主角选，再给伙伴选；两人连着出手，**先后由玩家选**；两人的技能**分开播动画**（技能名横幅：主角金、伙伴绿、首领红） | 「主角和伙伴都有自己的回合」「分开展示不一样的技能动画，可以选择先用谁」 |
| 8 | **主角和伙伴的技能要配合**：伙伴分 攻击 / 增益 / 减益 / 防守；破甲、印记、战吼、加持让主角打得更狠，嘲讽替主角挡刀；主角打晕敌人，伙伴打它更痛 | 「主角和伙伴的技能可以配合」 |
| 9 | **吃药不占回合**（每回合一次）；自动战斗会吃药、会防大招、会打弱点 | 「战斗中吃药占一个回合不合适」 |
| 10 | **动画默认开**，不跟随系统“减弱动态效果”；设置里能关。动画只是回放引擎的记录，关掉动画也必须能看到伤害（卡片上的“本回合受伤”） | 「之前说的动画加了吗」（被系统设置悄悄关掉过） |
| 11 | **成长不能到顶**：宝术熟练度（小成/大成）、宝骨、格子随境界增加、伙伴自己升级（可超过主角）、招式升阶、觉醒/返祖；技能多了能**替换低阶的** | 「伙伴后续不能继续提升了吗」「技能更多了能否替换低阶技能」 |
| 12 | **敌人变强必须配套**：变强的同时给更多格子和配合；用 `test/balance.js` 量自动战斗的胜率和剩余气血再定数值；改数值先给用户看 旧值 → 新值 | 「可以让敌人变强，但技能数量与宝术宝骨数量相应增加」 |
| 13 | **不用现实时钟**：游戏内的天和昼夜，睡觉换天；虚神界次数、每日奖励、悬赏、凶兽首领都按游戏天 | 「虚神界按真实时间，有必要吗」 |
| 14 | **支线不被主线挡**：任务列表把主线、支线、悬赏并列，可以选追踪，▶去 和地图 ★ 跟着走 | 「支线任务是不是会被主线挡住，无法手动选择」 |
| 15 | **补给方便**：所有城镇能休息，野外能歇脚；背包分栏；有钱（灵石）能买卖 | 「只能回村中补状态不合理；背包没法分类也卖不掉」 |
| 16 | **非战斗的互动用小游戏**，不要打一架凑；都能跳过，失败也要有交代、不卡剧情 | 「搬石头、破阵法都是用对战实现的」 |
| 17 | **敌人有台词**（开场狠话 / 残血 / 倒下；野兽写动作），主角偶尔回嘴 | 同上 |
| 18 | **江湖传闻**：不占版面，讲别人眼里已经发生的事、或给后续剧情埋引子；绝不超出当前进度（`from`/`to` 由 build 检查）。手机上一次飘过一条；电脑/平板在地点画上常驻最近 3 条；**点一下打开「📜 记录 → 江湖传闻」看全部历史**（存进存档，按天分组，最多 80 条），不连着重复同一条 | 「把网游人机对话加进来，但不超出当前剧情」「电脑或平板上多展示几行，可以点进去查看历史」 |
| 19 | **小游戏的提示要清楚**：不用硬记（骨文连线数字一直在）；关掉动画也要能看到亮起 | 「骨文没有一道道亮起来，需要我自己记住吗」 |
| 21 | **氛围跟着地点走**：每个区域一套配色（背景、按钮、文字、分隔线都用 CSS 变量），探索画面背后是放大、虚化的地点画，战斗画面背后是地点画加红色压暗；再加一层飘动的小粒子（村里柳絮、山林落叶、宗门云气、禁地风沙、虚神界光点、秘境火星，夜里换萤火）和很淡的区域纹理；记录类页面也要有场景感（江湖传闻做成「闲话酒肆」）。粒子跟随“动画”开关，后台不跑 | 「历史界面做得更有江湖气，比如酒馆」「村子的背景做得村子一点，山里的做得山野一点，整体更有氛围感」 |
| 22 | **画面要精致，但不繁杂**：地点画按山水手卷来画——分形山脊从山顶墨色渐淡到雾里、带皴笔，雾带分层，松（弯干、针叶团）、杉（垂枝层）、点叶树、茅屋（石脚、茅草顶、窗、夜里亮灯）、飞檐殿阁，再铺一层纸纹；不用三角形、圆、方块直接拼。每处只留一个标志物 | 「背景还可以更精美，不要用简单的元素集成，也不要过于繁杂」 |
| 23 | **小游戏失败不默认跳过**：失败后停下来问「再试一次 / 跳过，接着往下」；骨文没一气呵成也能「再连一次」 | 「游戏如果失败了可以选择继续尝试或者跳过，不要默认跳过」 |
| 24 | **战斗里的话要看得完**：气泡按字数停留 3.6–7.5 秒，同一个人只留最新一句；开场狠话一句一句来 | 「对战的时候，角色的对话消失得太快了」 |
| 25 | **每个小章节的高潮要壮阔、有情感**：首领登场卡（大字名号、来历、两三句铺垫、首领音乐）；半血时首领的一句话横贯屏幕；**绝境**——石昊第一次跌到三成气血（或要倒下）时，想起某个人的一句话，回 25% 气血、清掉坏状态、3 回合攻击 +30%（每场一次）；最后一击白光和墨爆，再接收尾句；剧情的关键时刻用整屏电影式旁白（回忆用旧照片色），章节开头有标题卡 | 「每个小章节如果有高潮，把对应的战斗或剧情做得壮阔一点，引起一些情感」 |
| 26 | **电脑/平板的手感**：菜单是右侧一条窄栏，按钮放在靠下的位置（拇指够得着）；主线和能做的事（做事/说话/去往）放在整个画面最下面横着一排；手机横屏保持左右两栏 | 「最下面的栏放到右侧，主线、做事放在整体下面，手不用抬起来」 |
| 27 | **对话要多、要有梗、要有人味**：每个人有自己的口头禅和笑点（小不点“这能吃吗”、二猛“我偷的”、诡爷“……吵”、火灵儿要争功），反复出现成梗；点人有「💬 闲聊」小对话（带选项、每段一次）；战斗里敌人开场/挨打/重击/打空/倒下都有话，主角按对手类型回嘴（野兽→当晚饭，人→嘴贫，鬼→嫌弃），灵兽伙伴和同伴会插话；每回合最多两句，不刷屏 | 「把所有相关的对话做得丰富很多，更有意思有梗」 |
| 28 | **江湖传闻不重复**：每条一个存档只听一次，听完就安静，等剧情往前走再有新的；新增的话要放在事件**发生之后**的那一步；build 检查文字重复 | 「江湖传闻不要有明显重复的，历史里面会很多重复」 |
| 20 | **每项都有自动测试**：`features.js` 逐项检查，`flow.js` 整条剧情，`coop.js` 联机，`mobile.js` 7 种屏幕，`hub.js` 游戏厅；随机相关的检查要写成确定的 | 多次因测试依赖随机数误报 |

## 二、这个游戏里具体做了什么

### 界面
- 场景切换式三画面；对话是纸面 + 印章名牌 + 背景地点淡墨画；战斗有出手顺序条、伙伴回合面板、技能横幅、飘字、受击抖动、首领狂怒震屏、胜/败/逃印章。
- 字号 标准 / 大 / 特大；存档码（导出/导入，含回忆录）；合成背景音乐（村 / 野外 / 战斗 / 补天阁 / 虚神界）。

- 区域氛围（`53_atmo.js` 的 `ATMO`）：石村暖土木色 / 大荒深林绿 / 补天阁冷青 / 百断山赭石 / 虚神界紫 / 秘境暗石；夜里整体压暗偏蓝。

### 剧情与内容
- 选择后果：引开青鳞鹰（族长、大壮的反应）、立誓（族长临别叮嘱、虚神界前十的石毅对话）、救云曦（不老泉还人情、百断山打首领来帮忙）、对毛球 / 大红的态度（初始亲近）。
- 补天阁扩写：师兄立规矩 + 诡爷第一句“……吵。”；清风线三段（夜里练拳、外门小比、临行）+ 她自己考进内门。
- 野外事件随境界解锁，夜里有夜行凶兽、夜景描述、夜里才有的台词；凶兽图鉴；虚神界首次前 50/10/1 奖励 + 每日奖励；石毅在第 1 名，有“重瞳”（同一宝术连用伤害减半）。
- 地点探索度、每日悬赏、困难秘境、新秘境「雷池深处」、18 个称号、传送玉符、睡到天黑 / 天亮、柳神处洞天重开。

### 战斗与成长
- 弱点（雷 / 火 / 钝击 / 骨文）、宝术配合（锁链后物理 ×1.3、锈剑砍流血 ×1.35、雷道劈晕眩 ×1.25、狻猊打狂怒 ×1.2）、一拳解决、换伙伴上场、难度三档。
- 宝骨 14 件，栏位 2 → 3（12 层）→ 4（17 层）；宝术栏 4 → 5（10）→ 6（14）→ 7（18）。
- 伙伴：四类招式（亲近 25/50/75 解锁）、招式栏 4（觉醒后 5）、自己的等级（第一卷里最多比主角高 2 级，之后到 30 级）、招式升阶（每阶 +20%）、觉醒（亲近 100，+15%）、返祖（25 级，再 +15%）。

### 数值（用户同意过的）
- 10 层起经验 ×(1 + 0.06×(层−9))，剧情战经验 ×2。
- 首领半血狂怒 +25% 攻击；狈祖附体 +35% → +25%。
- 敌人随等级变强：11 层前不变，18 层 气血 ×1.6、攻击 ×1.25（曲线前缓后陡）。
- 难度：简单 气血 ×0.75 攻击 ×0.8；困难 ×1.25 / ×1.15，经验 ×1.15。
- 买价：兽奶 6、止血草 8、凶兽肉 10、灵药 30、宝药 90、兽骨 6；卖半价。

### 小游戏、台词、传闻
- 举石锁（看准时机）、引雷（收缩圈）、破阵（全部按灭）、潜行（趁老虎睡熟迈步）、搬石（连点）、骨文连线（学宝术时）。
- 敌人台词 `SAY`（37 种凶兽 / 人物）、虚神界对手和石毅的台词、石昊回嘴。
- 江湖传闻 31 条，按剧情区间出现；听过的存进 `C.rumorLog`，「记录」里有「江湖传闻」页。

## 三、踩过的坑（别再犯）
- 两个同名顶层函数会互相覆盖（剧情断过一次）→ `build.py` 查重名。
- 系统“减弱动态效果”让动画、骨文亮起全部消失 → 不再跟随系统设置。
- 联机时队友每次同步拿到的是新的战斗对象 → 比对 `B.id`，不要比对对象。
- 动画结束时的重绘早于动画计时结束 → 按钮不出现；结束时先清计时再重绘。
- 用现实时钟做每日内容，单机玩家只会被卡住。
- 测试脚本里的 `${...}` 会让命令被安全检查拦下 → 补丁写成脚本文件再执行。
