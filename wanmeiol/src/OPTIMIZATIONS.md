# 完美世界 · 石昊篇（文字版）— 优化记录

游戏：Chunxiao-Lin-2023/Claude_space_0 仓库的 `wanmeiol/`（源码在 `wanmeiol/src/`，开发守则在 `src/RULES.md`）。
这份记录汇总了 2026-11 这一轮里用户提出或认可的所有优化（33 条通用规则）。**以后继续做这个游戏、或做别的剧情类网页游戏时，这些都要保持。**

---

## 一、通用清单（做任何剧情游戏都照做）

| # | 要保持的东西 | 由来 |
|---|---|---|
| 1 | **一次只显示一种画面**：探索（暗绿）/ 对话（米黄纸）/ 战斗（暗红），颜色一眼分得清；完整文字记录、回忆录、图鉴收进顶栏「📜 记录」；底栏只放 探索·石昊·灵兽·背包·地图 | 「界面过于繁琐，不同类型的界面分不太清」→ 选了“场景切换式” |
| 2 | **切换不许闪**：画面常驻、交叉淡化；离开对话先等 140ms（下一句往往马上就来）；同一个人连着说话不重复盖章；只有进战斗有整屏转场 | 「每次对话或日常点击之间太闪，不丝滑」 |
| 3 | **不画原著角色**：说话的人用原创印章名牌（名字 + 阵营底色） | 版权 |
| 4 | **选择要有后果**：选项写进 flag，之后一定在台词 / 奖励 / 事件里读到 | 建议 1 |
| 5 | **回忆录**：剧情台词按章节记下来，随时重读；剧情步骤按 id 存档，插新剧情不坏旧档 | 建议 3 |
| 6 | **战斗可读、可应对**：敌人下回合意图提前显示；⚠ 大招能防御减半，打晕或打中弱点能**打断**；首领半血狂怒并说一句话 | 建议 3、8、9 |
| 7 | **主角和伙伴各有回合**：先给主角选，再给伙伴选；两人连着出手，**先后由玩家选**；两人的技能**分开播动画**（技能名横幅：主角金、伙伴绿、首领红） | 「主角和伙伴都有自己的回合」「分开展示不一样的技能动画，可以选择先用谁」 |
| 8 | **主角和伙伴的技能要配合**：伙伴分 攻击 / 增益 / 减益 / 防守；破甲、印记、战吼、加持让主角打得更狠，嘲讽替主角挡刀；主角打晕敌人，伙伴打它更痛 | 「主角和伙伴的技能可以配合」 |
| 9 | **吃药不占回合**（每回合一次）；自动战斗会吃药、会防大招、会打弱点 | 「战斗中吃药占一个回合不合适」 |
| 10 | **动画默认开**，不跟随系统“减弱动态效果”；设置里能关。动画只是回放引擎的记录，关掉动画也必须能看到伤害（卡片上的“本回合受伤”） | 「之前说的动画加了吗」（被系统设置悄悄关掉过） |
| 11 | **成长不能到顶**：宝术熟练度（小成/大成）、宝骨、格子随境界增加、伙伴自己升级（可超过主角）、招式升阶、觉醒/返祖；技能多了能**替换低阶的** | 「伙伴后续不能继续提升了吗」「技能更多了能否替换低阶技能」 |
| 12 | **敌人变强必须配套**：变强的同时给更多格子和配合；用 `test/balance.js` 量自动战斗的胜率和剩余气血再定数值；改数值先给用户看 旧值 → 新值 | 「可以让敌人变强，但技能数量与宝术宝骨数量相应增加」 |
| 13 | **不用现实时钟**：游戏内的天和昼夜，睡觉换天；虚神界次数、每日奖励、悬赏、凶兽首领都按游戏天 | 「虚神界按真实时间，有必要吗」 |
| 14 | **支线不被主线挡**：任务列表把主线、支线、悬赏并列，可以选追踪，▶去 和地图 ★ 跟着走 | 「支线任务是不是会被主线挡住，无法手动选择」 |
| 15 | **补给方便**：所有城镇能休息，野外能歇脚；背包分栏；有钱（灵石）能买卖 | 「只能回村中补状态不合理；背包没法分类也卖不掉」 |
| 16 | **非战斗的互动用小游戏**，不要打一架凑；都能跳过，失败也要有交代、不卡剧情 | 「搬石头、破阵法都是用对战实现的」 |
| 17 | **敌人有台词**（开场狠话 / 残血 / 倒下；野兽写动作），主角偶尔回嘴 | 同上 |
| 18 | **江湖传闻**：不占版面，讲别人眼里已经发生的事、或给后续剧情埋引子；绝不超出当前进度（`from`/`to` 由 build 检查）。手机上一次飘过一条；电脑/平板在地点画上常驻最近 3 条；**点一下打开「📜 记录 → 江湖传闻」看全部历史**（存进存档，按天分组，最多 80 条），不连着重复同一条 | 「把网游人机对话加进来，但不超出当前剧情」「电脑或平板上多展示几行，可以点进去查看历史」 |
| 19 | **小游戏的提示要清楚**：不用硬记（骨文连线数字一直在）；关掉动画也要能看到亮起 | 「骨文没有一道道亮起来，需要我自己记住吗」 |
| 21 | **氛围跟着地点走**：每个区域一套配色（背景、按钮、文字、分隔线都用 CSS 变量），探索画面背后是放大、虚化的地点画，战斗画面背后是地点画加红色压暗；再加一层飘动的小粒子（村里柳絮、山林落叶、宗门云气、禁地风沙、虚神界光点、秘境火星，夜里换萤火）和很淡的区域纹理；记录类页面也要有场景感（江湖传闻做成「闲话酒肆」）。粒子跟随“动画”开关，后台不跑 | 「历史界面做得更有江湖气，比如酒馆」「村子的背景做得村子一点，山里的做得山野一点，整体更有氛围感」 |
| 22 | **画面要精致，但不繁杂**：地点画按山水手卷来画——分形山脊从山顶墨色渐淡到雾里、带皴笔，雾带分层，松（弯干、针叶团）、杉（垂枝层）、点叶树、茅屋（石脚、茅草顶、窗、夜里亮灯）、飞檐殿阁，再铺一层纸纹；不用三角形、圆、方块直接拼。每处只留一个标志物 | 「背景还可以更精美，不要用简单的元素集成，也不要过于繁杂」 |
| 23 | **小游戏失败不默认跳过**：失败后停下来问「再试一次 / 跳过，接着往下」；骨文没一气呵成也能「再连一次」 | 「游戏如果失败了可以选择继续尝试或者跳过，不要默认跳过」 |
| 24 | **战斗里的话要看得完**：气泡按字数停留 3.6–7.5 秒，同一个人只留最新一句；开场狠话一句一句来 | 「对战的时候，角色的对话消失得太快了」 |
| 25 | **每个小章节的高潮要壮阔、有情感**：首领登场卡（大字名号、来历、两三句铺垫、首领音乐）；半血时首领的一句话横贯屏幕；**绝境**——石昊第一次跌到三成气血（或要倒下）时，想起某个人的一句话，回 25% 气血、清掉坏状态、3 回合攻击 +30%（每场一次）；最后一击白光和墨爆，再接收尾句；剧情的关键时刻用整屏电影式旁白（回忆用旧照片色），章节开头有标题卡 | 「每个小章节如果有高潮，把对应的战斗或剧情做得壮阔一点，引起一些情感」 |
| 26 | **电脑/平板的手感**：菜单是右侧一条窄栏，按钮放在靠下的位置（拇指够得着）；主线和能做的事（做事/说话/去往）放在整个画面最下面横着一排；手机横屏保持左右两栏 | 「最下面的栏放到右侧，主线、做事放在整体下面，手不用抬起来」 |
| 27 | **对话要多、要有梗、要有人味**：每个人有自己的口头禅和笑点（小不点“这能吃吗”、二猛“我偷的”、诡爷“……吵”、火灵儿要争功），反复出现成梗；点人有「💬 闲聊」小对话（带选项、每段一次）；战斗里敌人开场/挨打/重击/打空/倒下都有话，主角按对手类型回嘴（野兽→当晚饭，人→嘴贫，鬼→嫌弃），灵兽伙伴和同伴会插话；每回合最多两句，不刷屏 | 「把所有相关的对话做得丰富很多，更有意思有梗」 |
| 28 | **江湖传闻不重复**：每条一个存档只听一次，听完就安静，等剧情往前走再有新的；新增的话要放在事件**发生之后**的那一步；build 检查文字重复 | 「江湖传闻不要有明显重复的，历史里面会很多重复」 |
| 29 | **对话不挡、不重复**：战斗气泡自己找空位（屏内、不叠在别的气泡上、上面没地方就放到卡片下面），整屏旁白出现时气泡先让开；`test/occlude.js` 在 6 种屏幕上检查所有对话和按钮有没有被挡、有没有出屏；台词用“洗牌袋”——一组话全说过一遍才会重复；路上听到的话优先没听过的（记在存档里） | 「对话有时会被其他模块挡住一部分」「不重复的对话尽可能多加」 |
| 30 | **自动只管这一场**：战斗里点的「🤖 自动」只对这一场有效；想一直自动，在探索画面「做事」里开「🤖 自动对战」；野外有「🔁 自动探索」，气血低于三成五、遇到剧情或小游戏就停；**要停得下来**：打完一场先停 3 秒、按钮上倒计时“3 秒后继续”，战斗里有「打完这场停止自动探索」，在战斗里点「停下」接手也会一起停，Esc 随时停 | 「自动对战退出当前战斗后不要在下一场自动启动，或者在做事下面加自动探索、自动对战」「自动探索打完一场很难手动停，下一次开始得太快」 |
| 31 | **宝术越练越深，还能合成**：熟练度六档（初窥→入门→小成→精通→大成→圆满），两门都到圆满可以花宝药、过一个「融合骨文」小游戏合成一门更强的宝术（失败不丢东西） | 「宝术熟练度分更多等级，满级之后和其他宝术合成更顶级的宝术」 |
| 32 | **跳章**：设置里能直接从某一章开始，按**玩得不错的中上水平**准备好（比预设高 3 级但不越过还没打开的境界关口，宝术熟练度 ×1.3，伙伴亲近 +15、等级 +3，灵石和物品 ×1.5，虚神界名次 ×0.6，第六卷起已穿戴的宝骨直接炼好 +1/+2/+3，悟道点按每级 1.2，天庭各 +1 级）等级、宝术熟练度、功法、洞天、伙伴、宝骨、物品和剧情标记，已达成的称号静默记上；会覆盖存档，点两次确认。新写一卷就要在 `JUMPS` 里加一档 | 「加一个跳章功能，直接从某一章开始玩」「跳章时等级宝术最好比平均高不少，中上 level」 |
| 33 | **多个存档位**：标题画面「📂 存档」有 5 个位置，每个显示境界、章节、天数、地点和保存时间，可读取、开新档、删除（点两次）；回忆录跟着存档位分开；设置里也能打开存档列表；旧存档自动在 1 号位；**联机直接用现有存档**：标题画面「🔗 用这个存档开房间」、存档列表每档「🔗 开房间」，朋友在标题输入房间码就接着你的进度一起玩，进度记在房主存档里 | 「可以开启不同的存档」 |
| 34 | **点了没反应 = bug**：任何按钮要么生效，要么弹一句为什么不行。跳章、读档这类“换存档”的操作，遇到正在进行的剧情/对话/小游戏/战斗，直接放弃它（它的 Promise 不再结算、`B.aborted` 拦住结算），绝不悄悄 return。 |
| 35 | **换角色不丢设置**：跳章、新档要带上玩家的偏好（自动对战、难度、创建时间），只重置进度。 |
| 36 | **后开的地点不能只通过还锁着的地点到达**：每个剧情步骤要去的地方，在那一步时必须能走到；`flow.js` 用真实寻路走完整条主线来验证。 |
| 37 | **新卷 = 一整套**：剧情步骤 + 区域/地点/地图格子 + 敌人和台词 + 首领 `epic` + NPC 闲话/传闻/闲聊 + 野外事件 + 悬赏/交换 + 跳章预设 + 境界上限/门槛 + 区域配色和画 + 音乐 + 平衡测试 + flow 测到新的结尾，缺一样都算没做完。 |
| 38 | **跳过的内容就当看过**：跳章跳过了教学的那一章，就把教学提示标成已看过，别在第十三章还弹“怎么打”。 |
| 39 | **战斗气泡绝不叠放**：候选位置铺满整行，先选离说话人最近的空位；气泡之间留 9px（尾巴 6px 也要算进去）；实在没空位，最早的那句先让位（消失）再找；入场只淡入 + 轻微放大，不能从下面滑上来（滑的那一下会压到下面的气泡）；窗口大小、横竖屏一变，按说话先后重新摆一遍。 | 「战斗气泡偶尔重叠的老问题」 |
| 40 | **一次性提示用块注释**：往一行很长的压缩代码里插注释，`//` 会把后半行吃掉（跳章就这样坏过一次）；行内一律用 `/* */`。 |
| 41 | **同一个 NPC 出现在好几个地方时，找人要找“现在去得了”的那个**：任务提示、测试、自动寻路都用 `npcLocNow`，不要拿列表里第一个（第六卷齐道临在天仙城和争霸城都有，曾指向还锁着的争霸城）。 |
| 42 | **剧情里死去或离开的角色，之后就从地图上消失**：NPC 列表、江湖传闻的说话人、闲话都要跟着改（孟天正在安澜一战后不再出现在帝关城）。 |
| 43 | **剧情步骤 id 不能重名**：构建时检查（第六卷的 `q_cliff` 和第四章重名过）。 |
| 44 | **补剧情先查原著有没有漏掉的大事**：查第六卷时发现第三卷漏了“不老山塌后和被封印 16 年的父母重逢”，补上了，并把之后提到“爹娘也许在上面”的台词一起改掉。 |
| 45 | **往后写之前，先核对前面的时间线**：查第九卷时发现“帝关 → 逃回下界”中间漏了“被出卖、异域一百年、仙域原始帝城”。宁可回头重排已上线的卷（第八卷结尾改成被出卖），也不要将错就错；改完把相关闲话、传闻的时间范围一起挪。 |
| 46 | **地图出口必须双向**：构建时检查单向出口（海瀑→界海之滨、仙域古城→帝关城曾经只能去不能回）。 |
| 47 | **NPC 闲话的有效期要想清楚**：写成“到这一卷结束”的台词，下一卷一开就全消失了；对后来仍然成立的话，有效期写到全书结尾（`q_fin`）。 |
| 48 | **后期首领各有一样自己的东西**：时光倒流、黑暗叠层、问话、复活、召唤、看穿同招、护盾、吞噬、潮汐、拉门、反噬、傲气、吞盾（`31_mech.js`）。每个机制第一次出现时，日志里用灰字写明怎么破。 |
| 49 | **“打不赢”的剧情战改成“撑住 N 回合”**（可以要求护住一个人）：撑住了，剧情多一段、记一个旗标；没撑住，剧情照常往下。七神、安澜、三仙王、尸骸仙帝、王长生都是这样。 |
| 50 | **后期不能一场一级，用不上的经验不能白扔**：44 层后经验曲线变陡；卡在境界关口或到顶时，多出来的经验化成悟道点，玩家自己决定花在哪儿。 |
| 51 | **野外事件只在“探索”里触发**（有怪的地方）；城镇和没有怪的地方的支线，要用到达事件（`EVENTS`），否则永远不会出现。 |
| 52 | **玩家做过的选择要被记住**：每卷结尾回顾这一卷的选择，结局里把一路上的选择一条一条想起来，读档隔了 20 分钟先给前情提要。 |
| 53 | **重要的选择要有后果**：放过的人以后会出现（银坤替你砍开道统山门）；当场动手还是记账，后面的对手状态不一样（王长生带伤）。 |
| 54 | **每章留一口气**：后期每章在两场大战之间插一段不打架的“歇脚”，有一个小选择，有的会在后面被想起（帝冲峰下刻的“荒”，在帝落古战场被摸到）。 |
| 55 | **数据表里的文字不能在加载时读存档**：人物介绍里拼了剧情旗标，写成了字符串而不是函数，页面一打开就崩（`C` 还是空的）。凡是跟进度有关的文字，一律写成函数。 |
| 56 | **有怪的地点必须有等级范围**：雨王府、校军场、天仙书院、天人城有怪没有 `lv`，一探索就报错（老问题，用新写的 `sweep.js` 扫出来的）；构建时检查。 |
| 57 | **伙伴优先用原著里和主角关系最近的**：原创的伙伴不如原著里真正跟过他的（打神石、小白、三黑、无畏狮子、金毛犼）；拿不准先查。 |
| 58 | **跳章要跟上所有系统**：不只等级、宝术、功法、宝骨，还有到那时该遇到的伙伴（等级跟着石昊、亲近、觉醒/返祖/真身）、悟道点和已花的悟道、天庭等级、一路上的选择旗标（取第一个选项）。每加一个新系统，就在 `jumpLate` 里补上。 |
| 59 | **多个伙伴一起打，开战前挑人**：野外 1 个、剧情战/秘境/守城 2 个、首领战 3 个，困难 +1，15 层前最多 1、30 层前最多 2；首领战、秘境、守城前弹出挑选（按敌人推荐）；每个伙伴的招都由你选，也能“剩下的伙伴自己打”；伙伴越多，敌人越硬、每个伙伴分到的力气越少。 |

## 二、这个游戏里具体做了什么

### 界面
- 场景切换式三画面；对话是纸面 + 印章名牌 + 背景地点淡墨画；战斗有出手顺序条、伙伴回合面板、技能横幅、飘字、受击抖动、首领狂怒震屏、胜/败/逃印章。
- 字号 标准 / 大 / 特大；存档码（导出/导入，含回忆录）；合成背景音乐（村 / 野外 / 战斗 / 补天阁 / 虚神界）。

- 区域氛围（`53_atmo.js` 的 `ATMO`）：石村暖土木色 / 大荒深林绿 / 补天阁冷青 / 百断山赭石 / 虚神界紫 / 秘境暗石；夜里整体压暗偏蓝。

### 剧情与内容
- 选择后果：引开青鳞鹰（族长、大壮的反应）、立誓（族长临别叮嘱、虚神界前十的石毅对话）、救云曦（不老泉还人情、百断山打首领来帮忙）、对毛球 / 大红的态度（初始亲近）。
- 补天阁扩写：师兄立规矩 + 诡爷第一句“……吵。”；清风线三段（夜里练拳、外门小比、临行）+ 她自己考进内门。
- 野外事件随境界解锁，夜里有夜行凶兽、夜景描述、夜里才有的台词；凶兽图鉴；虚神界首次前 50/10/1 奖励 + 每日奖励；石毅在第 1 名，有“重瞳”（同一宝术连用伤害减半）。
- 地点探索度、每日悬赏、困难秘境、新秘境「雷池深处」、18 个称号、传送玉符、睡到天黑 / 天亮、柳神处洞天重开。

## 三、踩过的坑（别再犯）
- 两个同名顶层函数会互相覆盖（剧情断过一次）→ `build.py` 查重名。
- 系统“减弱动态效果”让动画、骨文亮起全部消失 → 不再跟随系统设置。
- 联机时队友每次同步拿到的是新的战斗对象 → 比对 `B.id`，不要比对对象。
- 动画结束时的重绘早于动画计时结束 → 按钮不出现；结束时先清计时再重绘。
- 用现实时钟做每日内容，单机玩家只会被卡住。
- 测试脚本里的 `${...}` 会让命令被安全检查拦下 → 补丁写成脚本文件再执行。
- 测试里一行压缩代码的 `//` 注释把后面的等待吞掉了，气泡检查一直在动画第一帧做 → 测试代码同样只用 `/* */` 或换行。
- 气泡位置只算了方框，没算尾巴和入场位移 → 偶尔重叠，排查了好几轮；“偶尔”的问题先找动画和时序。
- 公共 PeerJS 服务器偶尔几分钟不回应，开房间就一直停在“正在开房间…”，看起来像“没法创建房间” → 联机每一步都要有超时（组件下载 9 秒换下一个 CDN，连服务器 12 秒换一条新连接、最多 3 次），失败要说清楚是哪一步、该怎么办。
- 剧情后面又“学会”一门早已进化掉的宝术，会把旧的加回来 → `learnSkill` 遇到已经进化的直接跳过；跳章核对也要认进化关系。
- 测试里的战斗不自己打：探针要先开 `C.auto`，否则卡在等你出招。
- 状态值有两种：持续伤害（流血/灼烧/中毒/黑暗）按出手者攻击换算，其余（虚弱/破甲/印记/凶性/坚守/灵动）是比例。混在一起算，虚弱就成了“缴械”，游戏一直偏简单却查不出来——测难度先看战斗日志里有没有 -1。
- 测难度不能只看胜率和剩余气血：自动战斗低血会吃药，要看“战斗中最低掉到多少”和回合数；还要分中上和普通两种玩家，只测一种会把另一种卡死。
