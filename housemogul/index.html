电脑对手

开局可选玩法：纯粹只有房价涨跌和买卖；完整加上贷款、房租、装修、验房、新闻和手续费；自定义挑着开。下面带 ★ 的只在开了对应选项时有。

目标

攒钱，用现金一次付清买下山顶豪宅就赢。时间一直在走，越快越好；双人时谁先买下谁赢，15 分钟到了还没人买下就比总身家（现金 + 房子的市场价）。

怎么玩

城市一直在变：房价时涨时跌，房子随时挂出来卖，开发商在空地上盖新楼，老房子会被拆掉。地图上每套在卖的房子头上都有价签，旁边的小圆圈是还能卖多久。简单难度标着 超值 划算 的就是比市场价便宜；其他难度显示便宜或贵了百分之几。

点房子（或它的价签）会弹出小卡片，一下就能买。你自己的房子头上写着现在卖能赚多少，数字一直在跳，看准了点它再点「卖」。刚买的房要过户几秒才能卖；有人抢着要时会亮起「抢手」，出价特别高。

难度

简单：豪宅便宜，便宜房多，有「超值 / 可以卖」提示。普通、困难依次变难，提示也更少。

★ 估价误差

市场价是中介估的，可能差 10% 左右，花一点钱「验房」才知道真价。

★ 手续费

买入 2%，卖出 3%。

★ 按揭

首付 30% 就能买，剩下的是贷款，时间一走就付利息（利率随新闻变化），卖房时自动还清。杠杆放大收益也放大亏损：现金一变成负数，银行会按 85% 的价格强制卖掉你的房，没房可卖就破产。豪宅只能全款。

★ 其他

装修能把破旧房变普通、普通变精装，涨价比花的钱多，但装修期间不能卖、没房租。传闻不一定成真；拆迁传闻成真时，那条街的老房按 1.8 倍价值补偿。

操作

拖动地图平移，滚轮或双指缩放；空格 = 暂停（单人），1 / 2 / 3 = 倍速，H = 看我的房，G = 看豪宅，Esc = 菜单。
