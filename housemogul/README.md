# 房产大亨 Real Estate Mogul

2.5D 等距小城里的炒房游戏，灵感来自老 Flash 小游戏 Mansion Impossible：房源随机挂牌，房价每月涨跌，低价买进、高价卖出，攒够钱**全款买下半山顶的终极豪宅**就赢。回合制，每回合一个月，最多 120 个月。

- **城市**：老城区、江景区、学府区、科技新区、城郊、半山六个区，约 90 套房（老平房、老公房、联排小楼、学区房、科技园公寓、江景大平层、独栋洋房、半山别墅）。各区有自己的长期走势、波动和对牛熊周期的敏感度；房价 = 户型底价 × 区域指数 × 房屋质量 × 房况。
- **挂牌**：每月 9–13 套挂牌，挂牌价相对参考价有高有低，约 13% 是真「急售」（7–9 折）；卖不掉会降价，过期下架。持有的房每月有一个买家出价（偶尔有「抢手」高价）。
- **玩法选项**（开局选，联机由房主选）：
  - **纯粹**：只有涨跌、挂牌、买卖。
  - **完整** / **自定义**：按揭贷款（首付 30%，月利率随加息降息变化，现金为负会被银行按 85% 强制卖房，卖光还为负就破产）、房租与物业费、装修（破旧→普通→精装）、估价误差与验房、新闻与传闻（地铁、拆迁 1.8 倍补偿、名校、裁员、限购……传闻不一定成真）、交易手续费（买 2% 卖 3%）。
  - 豪宅底价：不开按揭 900 万，开按揭 1400 万（杠杆让钱涨得快）。
- **新手友好**：难度分简单 / 普通 / 困难（豪宅价格 ×0.7 / ×1 / ×1.15，捡漏房比例、买家出价、每月保底便宜房数量不同，默认简单）。挂牌房直接标「超值 / 划算 / 正常 / 偏贵」，自己的房标「已经赚了，可以卖 / 小赚 / 再等等」。用词尽量口语化：市场价、总身家、现在有人出价。第一局单人有新手引导（选房 → 买下 → 下个月 → 卖出），可跳过，菜单里能重看。刚买的房下个月才能卖（防止同月倒手）。
- **对手**：单人竞速（记录各玩法最少月数）、对抗电脑「王老板」，或双人联机（PeerJS，房主权威、整份状态同步），两人都点「下个月」才翻月；谁先买下豪宅谁赢，120 个月后比净资产。对方掉线可以用同一个房间码重新加入。
- **操作**：拖动平移，滚轮 / 双指缩放，点房子看详情；回车 = 下个月，Esc = 菜单，1–4 切换侧栏，M 静音。

## 源码

- `src/` 下按序拼接：`00_core.js`（工具、种子随机数、平衡参数 `BAL`、户型 / 区域 / 玩法选项表）、`10_world.js`（地图布局、房产、估值）、`30_sim.js`（市场、新闻传闻、挂牌出价、玩家操作、月结、电脑对手）、`50_render.js`（Canvas 等距程序绘制）、`60_audio.js`（合成音效）、`62_input.js`、`70_net.js`（联机）、`80_ui.js`、`90_main.js`、`99_boot.js`；页面骨架 `template.html`。
- 构建：`python3 housemogul/src/build.py --deploy`（写 `../index.html`；`src/out/` 里另有 `test.html`（带 `window.__dbg`）和 `artifact.html`（单人版））。
- 测试（仓库根目录 `python3 -m http.server 8765`）：`test/smoke.js`、`test/phone.js`（iPhone 横竖屏、iPad）、`test/coop.js`（先 `node test/peerserver.js`）、`test/balance.js`（node 直接跑模拟，各难度下机器人、新手机器人和王老板买下豪宅要几个月）、`test/tutorial.js`（按新手引导走一遍，`VP=phone` 手机竖屏）、`test/cover.js`（游戏厅封面）。
- 本地存储键前缀 `housemogul.`；联机房间 id 前缀 `housemogul-`。
