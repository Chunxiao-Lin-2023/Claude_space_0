# 房产大亨 Real Estate Mogul

> 现在收在 **百戏茶馆** 里（`baixi/src/games/housemogul.js` 注册卡片，类别「联机社交」，排在地产大亨后面），游戏厅里没有单独的卡片。茶馆开局时用 iframe 嵌入 `housemogul/?embed=1`：嵌入时隐藏自己的「返回」按钮，茶馆顶栏的暂停通过 postMessage 传进来。直接打开 `housemogul/` 也能玩，返回按钮通往百戏茶馆。

2.5D 等距小城里的**实时**炒房游戏，灵感来自老 Flash 小游戏 Mansion Impossible：房价连续涨跌，房源随时挂牌、倒计时到了就撤，低价买进、高价卖出，攒够现金**全款买下山顶豪宅**就赢。一局限时 15 分钟。

- **城市自己发展**：老城区、江景区、学府区、科技新区、城郊、半山六个区。开发商每 9–17 秒在空地上开工（地基、脚手架、塔吊，楼慢慢长高），9 秒后作为新楼盘开卖，有时打折开盘。城里老房子（平房、破旧老公房和联排）会被拆掉（尘土动画），空出来的地之后再盖新楼。每盖好一栋，所在区域房价小涨。
- **地图**：25×25 格，5 格宽的街区之间是马路。每栋房子四周至少留一格院子（种树），斜着也不相邻，开局约 66 栋，城市发展后八九十栋。新楼也按这个规则选址。
- **点击**：价签按重要程度排位，互不重叠。顺序是选中的、引导指向的、你的房、豪宅、超值和划算的、其他。放不下的往上或往两边挪，用细线连回房子；还放不下就缩成一个小圆点，点小圆点或放大地图就能看到。区名如果被价签挡住就先不画。点到价签或圆点附近 26 像素以内都算点中。手机开局镜头离城区更近。
- **价格**：区域指数是连续的随机过程，带牛熊周期。每套房还有小幅抖动；买家出价围绕市场价波动，偶尔「抢手」高价持续几秒。挂牌价在挂出时就定了，之后市场涨跌会让它变得更划算或更贵。挂牌 24–46 秒，期间可能降价。
- **全在地图上**：没有侧栏，也没有「下个月」。
  - 在卖的房子头上挂价签，带剩余时间圆环。简单难度显示「超值 / 划算 / 正常 / 贵」，其他难度显示比市场价便宜或贵了百分之几。
  - 你的房显示现在卖能赚或亏多少，数字实时跳动，涨跌时闪 ▲▼。
  - 区名旁边显示该区最近 30 秒的涨跌。
  - 点房子或价签，旁边会弹小卡片，一个按钮就能买或卖；「详情 ›」里有走势图、验房、贷款、装修。
  - 刚买的房要过户 5 秒才能卖。
- **单人**：可暂停，可切换 1× / 2× / 3× 速度，打开菜单时也会暂停。新手引导期间时间冻结，直到买下第一套，然后带着卖出第一笔。
- **难度**：简单、普通、困难，豪宅价格分别 ×0.7 / ×1 / ×1.15，捡漏房比例、买家出价和保底便宜房数量也不同。简单难度保证有新手买得起的便宜房。
- **玩法选项**：纯粹、完整或自定义。可选项有贷款、房租物业、装修、估价误差与验房、新闻与传闻（地铁、拆迁 1.8 倍补偿、名校、裁员、限购……）、手续费。豪宅底价：不开贷款 1100 万，开贷款 1500 万。
- **对手**：单人竞速（各玩法记录最快用时）、对抗王老板（每 3–4 秒想一次），或双人联机。联机时房主跑模拟，有结构变化时发整份状态（不含历史，约 30 KB），平时每秒 5 次发数值包（约 2.5 KB），客机自己记价格历史。联机不能暂停。
- **按键**：拖动平移，滚轮或双指缩放；空格暂停，1/2/3 切换倍速，H 依次查看我的房，G 看豪宅，M 静音，Esc 打开菜单。

## 源码

- `src/` 下按序拼接：`00_core.js`（工具、种子随机数、平衡参数 `BAL`、户型 / 区域 / 玩法选项表）、`10_world.js`（地图布局、房产、估值）、`30_sim.js`（按秒推进的模拟：市场、单套房抖动与出价、挂牌、城市建拆、新闻传闻、玩家操作、王老板）、`50_render.js`（Canvas 等距程序绘制）、`60_audio.js`（合成音效）、`62_input.js`、`70_net.js`（联机）、`80_ui.js`、`90_main.js`、`99_boot.js`；页面骨架 `template.html`。
- 构建：`python3 housemogul/src/build.py --deploy`（写 `../index.html`；`src/out/` 里另有 `test.html`（带 `window.__dbg`）和 `artifact.html`（单人版））。
- 测试（仓库根目录 `python3 -m http.server 8765`）：`test/rt.js`（实时流程：引导、买、卖、建拆、暂停、详情、买豪宅；`VP=phone` 手机竖屏）、`test/phone.js`（iPhone 横竖屏、iPad 布局）、`test/coop.js`（先 `node test/peerserver.js`）、`test/balance.js`（node 直接跑模拟，机器人每 3 秒看一次地图，各难度买下豪宅要多久）、`test/cover.js`（游戏厅封面）。
- 本地存储键前缀 `housemogul.`；联机房间 id 前缀 `housemogul-`。
