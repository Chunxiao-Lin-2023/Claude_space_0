# 尸潮堡垒 Dead Tide

低多边形 3D 斜俯视（Three.js 正交相机）的双人丧尸生存游戏，是侧视版「尸夜孤楼」的 2.5D 版本。128×128 的地图：西边河流、三座桥和大片树林，东北山坡和坡道，北边农田和谷仓，主路以南到东南是棋盘街道的大片废弃小镇（三排街区 29 栋房子 + 谷仓，两层的留着半个二楼和楼梯，每栋一头剩半截瓦顶）。白天 5 分钟（之后每天 4 分钟），夜晚至少 150 + 6×夜数 秒，尸潮放完后还会有小股丧尸陆续过来直到天亮。白天砍树采石、搜汽车 / 补给箱 / 瓦砾，在营地周围 41×41 的黄框里最高盖到 9 层、在工作台造枪；夜里尸潮从营地外 36 格的一圈涌来，一路追着离它最近的人。纯生存：撑过 15 夜获救，所有人同时倒下失败。每天天亮刷新 3 个小任务（击杀 / 搜索 / 建造 / 推开 / 手雷 / 今夜无人倒下……），完成即发奖励（材料、全队弹药、医疗包、手雷、强化弹头）。

- **视角**：滚轮 / ＋－ 缩放，Q E / ⟲⟳ 90° 转镜头。楼层视图默认自动：在屋顶下时会隐藏你头顶的楼层，在室外显示全部；▲▼（PageUp / PageDown）手动逐层查看，「跟随我所在的层」恢复。墙挡住你时自动切矮。
- **建造**：木 / 砖 / 钢墙、木 / 钢楼板、楼梯（R 转朝向）、木门、射击栅栏、铁丝网、探照灯。指哪盖哪（相机射线打到的面：墙顶叠高、墙侧贴建、地面 / 楼板上盖；楼板会退而试天花板和自己所在层），按住拖动锁定直线一次盖一排，拆除指哪拆哪。三维支撑：从地面往上传，水平每格减 1，断了会连锁坍塌。
- **矮墙**：地面以上、头顶没有东西的木 / 砖 / 钢墙是半人高（`PH`）的矮墙，子弹从上面飞过；贴着矮墙（`LEAN` 格内）可以探身往下打。地面层的墙仍是整面墙。
- **楼梯**：往下走楼梯 / 从边缘跳下要继续推 `stairHold` / `ledgeHold` 秒；楼梯口三面有栏杆，侧面进不去。小镇每栋房子至少三面有门洞，营地小屋四面有门。
- **触屏摇杆**：左侧任意处按下出现，拖出圈外底座跟着走，死区 0.12，靠近网格方向自动吸附；左下角虚线圈提示。
- **丧尸**：流场寻路（会算上砸墙的代价，所以会挑最薄弱的地方砸），走楼梯和山坡；攀爬者会翻墙上楼；喷吐者远程吐酸；重锤拆墙；血月（第 5 / 10 / 15 夜）有巨尸，尸潮从四面来。
- **角色**（`src/54_chars.js`）：幸存者是分段关节模型（膝盖、手肘、手套、靴子、脸、发型；1P 短乱发橙夹克，2P 马尾红头带青色外套），下半身朝移动方向、上半身朝瞄准方向，倒退走自动反向；手臂用两段 IK 按武器握枪；开枪后坐 / 枪口上跳 / 霰弹枪拉栓 / 狙击枪拉机柄，换弹、推、扔雷、挥锤、用医疗包、受伤后仰红闪、倒地跪姿都有动作。丧尸照恐怖屋的怪物规则做（有机的锥形身体、多关节肢体、长指爪、不对称、歪头、破布条和长发、夜里发光的眼睛、偶尔抽搐）：游荡者 5 种变体（伸手拖腿、红衣长发、独臂、歪脖子、下巴脱落）、疾跑者前倾甩臂张嘴、攀爬者四肢着地像蜘蛛、喷吐者鼓胀发光的肚子和仰头蓄力、重锤一只巨拳加背上骨刺、巨尸两张脸。攻击有举手前摇再砸下，中弹踉跄，三种倒法，尸体慢慢沉下去。粗曳光、墙面火花和烟、地上血迹、跑步扬尘、自己开枪时镜头往后一顶。
- **第三轮**：小镇改成 16 栋分散的房子（院子、公园、加油站、停车场、军事检查站、废车场、营地）。可搜的：汽车、售货机（搜过会变暗，第二天一半补满）、补给箱、瓦砾、垃圾桶、遇难者背包、柜子、工具箱、军用物资箱、油桶（搜完就消失，每天天亮在别处随机补到定额 `SPOTS[k].n`）；可采的：树、石头、废铁堆、原木堆、灌木。新丧尸：尸犬（成群）、爬行尸、爆尸（死了炸开，伤人伤墙）、尖叫者（让周围丧尸发狂并在夜里引来更多）、防暴尸（正面减伤到 30%，穿透武器 / 火 / 爆炸不受影响）。新武器：弩（穿透 3、钉住）、喷火器（锥形点燃、火会传染）、榴弹发射器（落地爆炸）；老武器各有特点（手枪爆头 ×2.2、霰弹近距离满伤 + 打晕、步枪连射扩散、狙击打晕 + 激光）。楼梯换成靠墙爬梯（丧尸爬得慢）；人能翻越矮障碍和一人高的墙、跳过一格空隙（空格 / 「跳」键），丧尸不会；新障碍物：沙袋矮墙、拒马、铁皮掩体、捕兽夹。建造和拆除先预览，再点 ✓ / Enter / 再点一次确认（可关）。挡住角色的墙、废墟、树冠和屋顶会自动切掉，角色脚下有永远可见的圈。任务栏默认折叠。
- **双人**：PeerJS，房主权威，材料共用；倒地后队友按住 F 扶起或医疗包自救。

## 源码

- `src/` 按序拼接：`00_core.js`（数据表、`BAL`）、`10_world.js`（分层网格、地形生成、三维支撑）、`20_nav.js`（移动、楼梯 / 坡道、流场、三维射线）、`30_sim.js`、`35_zombies.js`、`50_render.js`（Three.js：合并地形网格 + 实例化方块 / 树 / 丧尸，切层、光照、小地图）、`52_arch.js`（建筑美术：程序纹理的木栅栏 / 砖堡 / 钢碉堡墙、墙顶木桩 / 垛口 / 尖刺、沙袋射击栅栏、小镇墙皮和残破瓦顶）、`54_chars.js`（人物和丧尸模型 / 动画、曳光、血迹）、`56_props.js`（可搜物件、障碍物、爬梯、建造预览、透视圈）、`60_audio.js`、`62_input.js`、`70_net.js`、`80_ui.js`、`90_main.js`、`99_boot.js`；`template.html`；`three.vendor.js`（three r160 + mergeGeometries，和幽宅双影同一份）。
- 构建：`python3 deadtide/src/build.py --deploy`；`src/out/` 另有 `test.html`（带 `window.__dbg`）和 `artifact.html`（单人版）。
- 测试（`node test/serve.js out 8766`）：`test/smoke.js`、`test/phone.js`、`test/coop.js`（需 `node test/peerserver.js`）、`test/balance.js`、`test/touchctl.js`、`test/views.js`、`test/buildings.js`、`test/mechanics.js`（任务 / 矮墙 / 建造指向 / 楼梯 / 门洞 / 摇杆）、`test/chars.js`（角色总览截图）、`test/round3.js`（搜刮补货 / 新丧尸 / 新武器 / 翻越 / 爬梯 / 捕兽夹 / 建造确认）、`56_props.js` 见源码、`test/cover.js`。无头 Chromium 的软件渲染很慢，测试时关掉绘制（`__dbg.skipDraw`），只在截图时渲染。
- 本地存储键前缀 `deadtide.`；联机房间 id 前缀 `deadtide-`。
