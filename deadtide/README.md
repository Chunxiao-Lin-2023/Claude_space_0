# 尸潮堡垒 Dead Tide

低多边形 3D 斜俯视（Three.js 正交相机）的双人丧尸生存游戏，是侧视版「尸夜孤楼」的 2.5D 版本。160×160 的地图：西边河流、三座桥和大片树林，东北山坡和坡道，北边农田和谷仓，主路以南到东南是棋盘街道的大片废弃小镇（三排街区 29 栋房子 + 谷仓，两层的留着半个二楼和楼梯，每栋一头剩半截瓦顶）。白天 5 分钟（之后每天 4 分钟），夜晚至少 150 + 6×夜数 秒，尸潮放完后还会有小股丧尸陆续过来直到天亮。白天砍树采石、搜汽车 / 补给箱 / 瓦砾，在营地周围 41×41 的黄框里最高盖到 9 层、在工作台造枪；夜里尸潮从营地外 36 格的一圈涌来，一路追着离它最近的人。纯生存：撑过 15 夜获救，所有人同时倒下失败。每天天亮刷新 3 个小任务（击杀 / 搜索 / 建造 / 推开 / 手雷 / 今夜无人倒下……），完成即发奖励（材料、全队弹药、医疗包、手雷、强化弹头）。

- **视角**：滚轮 / ＋－ 缩放，Q E / ⟲⟳ 90° 转镜头。楼层视图默认自动：在屋顶下时会隐藏你头顶的楼层，在室外显示全部；▲▼（PageUp / PageDown）手动逐层查看，「跟随我所在的层」恢复。墙挡住你时自动切矮。
- **建造**：木 / 砖 / 钢墙、木 / 钢楼板、楼梯（R 转朝向）、木门、射击栅栏、铁丝网、探照灯。指哪盖哪（相机射线打到的面：墙顶叠高、墙侧贴建、地面 / 楼板上盖；楼板会退而试天花板和自己所在层），按住拖动锁定直线一次盖一排，拆除指哪拆哪。三维支撑：从地面往上传，水平每格减 1，断了会连锁坍塌。
- **矮墙**：地面以上、头顶没有东西的木 / 砖 / 钢墙是半人高（`PH`）的矮墙，子弹从上面飞过；贴着矮墙（`LEAN` 格内）可以探身往下打。地面层的墙仍是整面墙。
- **楼梯**：往下走楼梯 / 从边缘跳下要继续推 `stairHold` / `ledgeHold` 秒；楼梯口三面有栏杆，侧面进不去。小镇每栋房子至少三面有门洞，营地小屋四面有门。
- **触屏摇杆**：左侧任意处按下出现，拖出圈外底座跟着走，死区 0.12，靠近网格方向自动吸附；左下角虚线圈提示。
- **丧尸**：流场寻路（会算上砸墙的代价，所以会挑最薄弱的地方砸），走楼梯和山坡；攀爬者会翻墙上楼；喷吐者远程吐酸；重锤拆墙；血月（第 5 / 10 / 15 夜）有巨尸，尸潮从四面来。
- **角色**（`src/54_chars.js`）：幸存者是分段关节模型（膝盖、手肘、手套、靴子、脸、发型；1P 短乱发橙夹克，2P 马尾红头带青色外套），下半身朝移动方向、上半身朝瞄准方向，倒退走自动反向；手臂用两段 IK 按武器握枪；开枪后坐 / 枪口上跳 / 霰弹枪拉栓 / 狙击枪拉机柄，换弹、推、扔雷、挥锤、用医疗包、受伤后仰红闪、倒地跪姿都有动作。丧尸照恐怖屋的怪物规则做（有机的锥形身体、多关节肢体、长指爪、不对称、歪头、破布条和长发、夜里发光的眼睛、偶尔抽搐）：游荡者 5 种变体（伸手拖腿、红衣长发、独臂、歪脖子、下巴脱落）、疾跑者前倾甩臂张嘴、攀爬者四肢着地像蜘蛛、喷吐者鼓胀发光的肚子和仰头蓄力、重锤一只巨拳加背上骨刺、巨尸两张脸。攻击有举手前摇再砸下，中弹踉跄，三种倒法，尸体慢慢沉下去。粗曳光、墙面火花和烟、地上血迹、跑步扬尘、自己开枪时镜头往后一顶。
- **第三轮**：小镇改成 16 栋分散的房子（院子、公园、加油站、停车场、军事检查站、废车场、营地）。可搜的：汽车、售货机（搜过会变暗，第二天一半补满）、补给箱、瓦砾、垃圾桶、遇难者背包、柜子、工具箱、军用物资箱、油桶（搜完就消失，每天天亮在别处随机补到定额 `SPOTS[k].n`）；可采的：树、石头、废铁堆、原木堆、灌木。新丧尸：尸犬（成群）、爬行尸、爆尸（死了炸开，伤人伤墙）、尖叫者（让周围丧尸发狂并在夜里引来更多）、防暴尸（正面减伤到 30%，穿透武器 / 火 / 爆炸不受影响）。新武器：弩（穿透 3、钉住）、喷火器（锥形点燃、火会传染）、榴弹发射器（落地爆炸）；老武器各有特点（手枪爆头 ×2.2、霰弹近距离满伤 + 打晕、步枪连射扩散、狙击打晕 + 激光）。楼梯换成靠墙爬梯（丧尸爬得慢）；人能翻越矮障碍和一人高的墙、跳过一格空隙（空格 / 「跳」键），丧尸不会；新障碍物：沙袋矮墙、拒马、铁皮掩体、捕兽夹。建造和拆除先预览，再点 ✓ / Enter / 再点一次确认（可关）。挡住角色的墙、废墟、树冠和屋顶会自动切掉，角色脚下有永远可见的圈。任务栏默认折叠。
- **第四轮**：房子改成 1–4 层的大楼（11×9 到 14×13，混凝土楼板、每层一道隔墙），每层两个爬梯**挂在隔墙上**，从楼板的洞口爬到隔墙顶上（楼上隔墙在那里留门洞）；四层楼可以上屋顶。营地小屋改成 11×11 两层 + 屋顶平台（矮墙围一圈），四个挂墙爬梯。自己造爬梯必须贴墙放、墙顶上要能站人，放的时候会自动转向贴着的墙。夜里尸潮出生圈从营地外 36 格缩到 27 格，四分之一的丧尸在开头 3 秒内一起出发，整波放完的时间 80 + 5n 秒 → 50 + 4n 秒。触屏换枪：有 3 把以上时点枪名弹出全部武器一次选；「跳」键挪到换弹和手雷之间的外圈，不再和交互键重叠（`test/overlap_tc.js` 查所有触屏按键重叠）。
- **第五轮**：搜索 / 砍树 / 扶人改成点一下就自动做完（走开或再点一下就停）。地图扩到 160×160，小镇 16 栋大楼（每栋 300–700 格，约为上一版 3 倍）：公寓楼（中间走廊、两边房间、阳台、屋顶栏杆，3–5 层）、别墅（多个房间、阳台、尖顶阁楼）、仓库（两层高的大厅、北侧夹层平台、货架），每层两个挂墙爬梯；门框是醒目的黄色，梯子是亮黄色。营地小屋 13×11：一楼大厅 + 工作间，二楼两个房间 + 阳台，屋顶平台；梯子挂在大厅内墙的两个角上。在楼里只隐藏这栋楼的上层（其它楼照常显示）。渲染只装填镜头附近的格子，楼内被楼板盖住的东西不画。数值（旧 → 新）：每夜丧尸 16 + 7n → 22 + 9n，白天游荡 6 → 8 只，夜里小股最多 6 → 8 只；武器伤害全部约 +30%（手枪 26 → 34、霰弹 13 → 17/颗、步枪 23 → 30、狙击 150 → 195、弩 85 → 110、喷火 9 → 12、燃烧 22 → 28/秒、榴弹 170 → 220、手雷 220 → 286）。存档：每天天亮自动存、暂停菜单可手动存、切后台自动存，标题页「继续上次」（`92_save.js`，`test/save.js`）。
- **第六轮（修复 + 性能）**：修好联机时 2P 突然整张地图消失（事件序号字段 `s` 和格子事件里的楼板 id `s` 重名，2P 把序号写进了楼板网格，渲染一遇到非法方块就整帧报错；序号改为 `q`，2P 用自己的计数器 `W.rq`，渲染跳过非法格；2P 的支撑重算改成每帧最多一次；2P 的「已搜过」同步改用 `W.srch`）。自动视图下，你所在的楼、紧挨着你的楼（2.5 格内）和挡在镜头与你之间的楼都切到你这一层（尖顶一起拿掉），看得到门和屋里（`cutBox` / `LCUTS`，`test/cut.js`）；建造指向会穿过被切掉的部分。性能：点光源 10 → 5 个，地形 / 楼板 / 托梁 / 栏杆 / 石头 / 栅栏 / 小物件不再投影（三角形约少 30–35%）；画质分高 / 中 / 低，默认自动——连续 3 秒低于约 30 帧就降一档（先降分辨率，再关阴影），记在本地，暂停菜单可改（`test/qual.js`、`test/perf.js`）；不再加载 Noto Sans SC 网络字体，中文用系统字体。
- **第七轮（键位 + 瞄准）**：电脑端左上角列出当前可用的按键（`uiKeys`；用不上的变灰，没子弹时 R、残血时 H 闪红，建造模式换成建造键位，可折叠，记在 `SET.keysOff`），武器栏标出数字键。鼠标瞄准（`aimPick`）：指在丧尸身上按指的高度瞄（身形最上面一截 = 爆头，原来固定瞄 65% 高度、爆头只靠散布碰运气），没指中但离屏幕上的丧尸 34 像素内会吸附；自定义准星（`drawReticle`）的圆圈 = 武器在那个距离的真实散布（步枪连射会变大），红 = 锁定、黄 = 爆头、虚线 = 超出射程，换弹时显示进度。触屏自动瞄准（`touchAutoAim`）：2.5 格内的丧尸优先，当前目标除非别的明显更好否则不换（不再来回跳），锁定后每帧跟着目标走（原来每 0.1 秒才更新一次位置），被切掉的楼层里的丧尸不锁。两种都在被瞄的丧尸脚下画锁定圈（`OBJ.lockI`）。`test/aim.js`、`test/stances.js`、`test/knife.js`、`test/touchaim.js`。
- **第八轮（尺寸）**：所有丧尸放大约 20%（`ZT` 的模型比例 `sc` ×1.2、命中盒高度 `h` ×1.2、半径 `r` ×1.12，重锤半径封顶 0.44 免得卡门）：游荡者 r 0.28 → 0.31、h 1.0 → 1.2，重锤 h 1.45 → 1.74，巨尸 h 2.2 → 2.64 等；尸犬模型也跟着 `sc` 缩放。命中盒变大，丧尸更好打中，攻击距离（`p.r + z.r + 0.28`）略长一点。默认镜头 9 → 8（画面里所有东西大约 12% 大），存过的缩放会重置一次（`SET.zv`）。人物和建筑本身不变：楼层高 1.3、门宽 1 格都是按人 1.0 高定的，一起放大等于拉近镜头。
- **第九轮（持枪姿势）**：每把武器按真实用法持握（`54_chars.js` 的 `STANCE`）：手枪双手等腰式、举到视线高度；霰弹枪侧身抵肩、身体前压、左手握泵把（开枪后拉泵）；步枪侧身抵肩、脸贴枪托、左手托护木；狙击枪站着不动时单膝跪地、眼贴瞄准镜（开枪后拉枪栓）；弩抵肩；喷火器腰际双手持握；榴弹发射器抵肩、枪口上抬。枪托固定在肩窝，身体侧转时枪反向转回来保持指向目标。走动且 1.4 秒内没开枪时，长枪转成低姿戒备（枪托不离肩、枪口朝下），一开枪就抬起。枪口火光和曳光从模型的真实枪口出（`muzzleW`）。`test/stances.js` 截图。
- **第十轮（物资）**：修好「第二天起箱子不刷新」：楼里生成的箱子远多于旧定额（开局约 400 个，定额合计 126），天亮只补到定额，所以第一天后全图物资骤降，且剩余数高于定额时一个都不补。现在开局记下每种的数量（`W.spotN`，存进存档），天亮补回到这个数（不低于定额 `n`），搜掉的在别处刷出。数值（旧 → 新）：汽车 / 售货机每天恢复 50% → 100%；定额 补给箱 16 → 30、瓦砾 24 → 40、垃圾桶 24 → 40、背包 10 → 24、工具箱 10 → 16、军用箱 4 → 8、油桶 14 → 24；楼里每层放的物件 公寓 3 → 6、别墅 / 仓库 2 → 5、屋顶 2 → 3、仓库夹层 3 → 5；开局另在空地撒 1.2 倍定额的补给箱 / 工具箱 / 瓦砾；补刷时补给箱 / 工具箱 / 瓦砾 60% 放室外。实测第一天约 600 个（室外约 130），之后每天补满（室外约 230）。
- **第十一轮（刀）**：「推开」换成刀（V / 触屏「刀」，按住连砍）：自动找 2.3 格内、看得见、最接近你朝向（触屏用走的方向）的丧尸，转身冲过去（最多 1.3 格，撞墙会停）贴身砍；没目标就原地挥空。数值（旧推开 → 刀）：伤害 18 → 55，击退 6 → 2.5（重锤 25%、巨尸不退），冷却 0.55 → 0.5 秒，范围 1.3 格扇形 → 2.3 格自动锁定；从背后捅 ×2（`knifeBack`），背刺也能绕过防暴尸的正面减伤；砍中会让丧尸硬直 0.4 秒。冲刺在本地算（像跳跃），伤害由房主判定（`knife(p, zid)`，目标超出距离就在房主那边重新找）。人物动作：收枪、右手持刀从右上斜劈到左下、左手护身。任务「推开 N 次」改成「用刀砍中 N 次」。`test/knife.js`、`test/touchaim.js`。
- **第十二轮（触屏手动瞄准）**：手机 / iPad 右半屏空白处（横屏 x > 30%、竖屏 x > 40%，不在按钮附近）手指按住就朝那里打，规则同鼠标（`aimPick` 按指的高度瞄、头顶 = 爆头），手指吸附半径 50 像素（鼠标 34）；拖动手指准心跟着走，松手停火（`INP.tAim`）。两指捏合缩放照旧（会取消手指瞄准）。射击键的自动瞄准保留。`test/touchaim.js`。
- **第十三轮（瞄准难度）**：触屏手指只瞄准不开火：准星显示在手指上方 64 像素（`FINGER_UP`），按「射击」键才开火（打准星的位置）。射击键单独按 = 自动瞄准，新增「辅助瞄准」三档（`ASSIST`，暂停菜单切换，存在 `SET.assist`）：标准（默认）= 锁定距离为射程的 75%、锁到新目标后 0.3 秒才开火（脚下灰圈收紧变红）、自动瞄准时散布 ×1.5（`p.inp.auto`，2P 通过 `au` 发给房主）；强 = 旧的效果；关 = 射击键只朝面对的方向打，鼠标 / 手指也不吸附。射速（旧 → 新）：手枪 0.2 → 0.3 秒/发，步枪 0.095 → 0.12 秒/发。
- **双人**：PeerJS，房主权威，材料共用；倒地后队友按住 F 扶起或医疗包自救。
