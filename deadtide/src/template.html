玩法和操作

点标题展开 · 触屏随时点右上角「?」看按键说明

目标标题页点「模式」选玩法和地图：尸城求生（默认）丧尸占了半座城——红色标记的楼里睡着尸群（头上「z」）：你在它视线里待久了它会察觉（「?」越变越大，背对你的察觉得慢），开枪会把附近的吵醒（隔着墙听得小一半，弩几乎没声），用刀能悄悄一刀解决睡着的丧尸；清掉一栋楼拿图纸箱和奖励，任何地方都能就地建造临时据点；箱子里能搜到蓝图，解锁砖墙、钢墙、拒马、铁丝网、捕兽夹、探照灯、地雷、机枪塔和四种载具（见「载具」）；搜刮收获翻倍，地上到处有弹药盒；每夜到点就天亮，撑过 10 夜获胜。经典守夜撑过 15 夜；修车逃离找齐 6 个零件修好卡车；摧毁尸巢炸掉 5 个尸巢和母巢；信号塔守住 4 座塔的校准再等直升机；抢空投集齐 6 个空投信标后守住撤离点；尸王狩猎击杀 4 只尸王。当前目标显示在屏幕上方，屏幕边的箭头和大地图（点小地图 / 按 M）指路。所有人同时倒下就失败。丧尸会一路追着离它最近的人，挡路的墙会被砸开。
丧尸游荡者、疾跑者、攀爬者（翻墙）、喷吐者（吐酸）、重锤（拆墙）、巨尸（血月），还有成群的尸犬、贴地的爬行尸、死了会炸开（连墙一起炸）的爆尸、会尖叫让周围丧尸发狂并引来更多丧尸的尖叫者、正面打不动的防暴尸（绕到侧面后面，或者用狙击枪、弩、火、炸药）。
武器和装备每把枪有自己的用处（切枪时会提示一句）：手枪子弹无限、准，伤害最低；霰弹枪近身清群；步枪持续火力；狙击枪打精英，穿 5 只；弩几乎没声音、钉住丧尸；喷火器堵门，火会传；榴弹发射器炸一片。
快捷武器：在「装备」（电脑按 I，触屏拖武器键选「装备…」）里选 4 把放进快捷栏，电脑 1–4 切换、Z 切回上一把。
近战：刀或防暴盾（商店 → 武器 里买，二选一，X / 触屏在「刀 / 盾」键上滑一下切换）。盾推：把前面一片丧尸（最多 8 只）推开约 3 格、晕 1 秒；拿着盾时正面挨打少受一半。
手雷：电脑按住 G 会在光标处显示落点圈（爆炸范围），松开扔；触屏点一下自动扔向射程内最大的尸堆，拖动手雷键放落点圈，松手扔。
商店在任何建筑里（或营地）按 C / 点「商店」。分四栏：武器 · 弹药（一把枪和它的子弹在同一张卡上）、道具（四种手雷、医疗包）；放置类道具不在商店，见下面「道具」、载具、强化。材料全队共用，买到的东西归你。
道具（建造）按 B / 点「道具」拿出道具栏：墙、地板、梯子、门、掩体（木板路障 / 射击栅栏）、陷阱（铁丝网 / 地雷）、炮塔（机枪 / 霰弹 / 狙击）、跳板，同类的合在一格——再点一次同一格（或点上面的小条）换材料，比如木墙 → 砖墙 → 钢墙。放下去不分朝向：梯子会自己贴到能爬上去的那面墙。指哪放哪，按住拖动放一排；放一个扣一份材料，右键 / 「拆除」拆掉退一半。墙、地板、梯子、门只能在营地周围的黄框里放（尸城求生哪都能放）；掩体、陷阱、地雷、机枪塔、探照灯、跳板哪都能放（尸城求生里有些要先找到蓝图）。方块要有支撑，断了会连锁坍塌。楼上最外圈的墙是半人高的矮墙，能探身往下打。
跳板：踩上去把你朝走的方向弹出约 5 格，前面有矮楼顶（最多高 2 层）就弹上去，用一次就没——被围住时的逃生道具。
载具自行车快 70%，没有发动机（攻楼时不会吵醒楼里的丧尸，别的车会），泥地不减速；骑着开枪射速不降、伤害 +15%，骑起来时 40% 的攻击能闪开；摩托车快 90%，后座带一个队友；货运三轮坐在车上就能搜东西（够得更远、时间减半、材料 +50%）；装甲车车里的人（含后座）受到的伤害只剩 30%，3 秒没挨打每秒回 4 血，撞丧尸 70 伤害并撞倒，后座带一个队友、从射击孔开枪射速不降；旋翼机会飞，越过屋顶和尸群（丧尸咬不到，喷吐者还能打到），只能在地面或楼顶起飞（头顶不能有屋顶），一箱油飞 60 秒，没满随时能加（商店「载具」栏一键加满，或在有屋顶的房间里按 F），飞着用机头下的机枪打（机上自己的子弹，商店「武器 · 弹药」里买，最多存 500 发），手里的枪不能用，手雷能扔；后座能带一个队友（上去后旋翼空转约 1 秒，队友这时按 T 上来），后座的人能开枪；再按 T 降落，没油会自己降落；坦克自带炮塔，开火打炮弹（打到哪炸到哪，120 伤害、半径 2.3，1.6 秒一发；炮弹在商店「武器 · 弹药」栏买，车里最多 200 发），受到的伤害只剩 20%，撞开丧尸，但慢、太大进不了楼（有屋顶的地方开不进去）。变形成机甲：骑车时按 X（触屏：骑车时「刀」键变成「变形」），1 秒后载具站起来变成机甲，再按变回。每种载具一台：自行车→疾风（最快，机枪不用换弹、浮游炮放 10 台悬浮机枪）、摩托→赤刃（臂刃下劈、冲斩）、三轮→工蜂（一次扔 3 个快递、快递雨倾泻 36 个，能搜刮）、装甲车→铁卫（左拳 / 右拳 / 双拳捶地，掀地把周围 7 格的丧尸掀飞，最耐打）、旋翼机→苍隼（火箭弹，技能键起飞 / 降落一直飞，飞着一次齐射 3 发）、坦克→重炮（手臂炮、齐射用炮弹）。机甲会把路上的石头、灌木、栅栏踩平。开火 = 出拳，手雷键 = 技能；装甲打光或电用完会变回载具，装甲和电下车后慢慢恢复，商店「载具」栏能马上修好 / 充满；屋顶下站不起来。在商店「载具」栏或「装备」里选一辆当默认：T / 点「载具」就上这辆，再按下车；Shift+T / 长按「载具」换车。车上也能开枪，只是射速慢（司机 40%、后座 70%；自行车 80%），准度不变。
怪兽：第 5 夜起隔夜出现（第 11 夜起两只），血很厚，每种有自己的大招，放之前地上会有红色范围提示、身上发光——裂颚兽喷酸（扇形）、钢尾兽甩尾（一圈）或低头冲锋（一条线）、掘地兽钻地从你脚下冒出来还带爬行尸。蓄力时用震地、爆破手雷等把它震晕能打断。
白天和永久任务出门砍树（木材）、采石（砖石），搜汽车、补给箱和废墟瓦砾（钢材、零件、弹药），离家越远收获越多；回来盖楼；在任何建筑里（或营地工作台）都能造枪、买弹药（按 C / 点「商店」）。河上只有两座桥，丧尸也只能从桥上过河。每 5 夜一次血月。
右上角「任务」小条点开是永久任务（击杀、搜索、建造、砍树采石、手雷击杀、整夜无人倒下……），每完成一档拿一个永久提升：生命上限、背包（弹药上限）、医疗包上限、手雷上限、复活次数。
飞行丧尸和能力者第 2 夜起有尸鸦群：飞过墙和屋顶在头顶盘旋，尖叫一声后朝地上红圈俯冲（走开就扑空），有时会沿一条红线低空扫过来（往旁边躲）；第 3 夜起混着大个的尸鹫，在高处往你要走到的地方丢酸液（红圈，别停在里面）；第 4 夜起有尸蝠，咬到可能扒在你身上吸血，用刀把它打下来。躲进有屋顶的楼里它们就够不着。第 3 夜起每晚有能力者（头顶有名字），每个都有破解办法，破解后它会露出破绽（黄色标签，几秒内受到双倍伤害）：闪影者瞬移到你身后（紫光），出现后有一拍才砍——这时打它就能反击，或者马上走开让它砍空；唤尸者会躲着你、从地下叫丧尸，追上去打，叫的时候打够伤害就打断，它死了叫出来的也跟着倒；护盾者给周围丧尸套护盾，站进护盾里打才打得动，但它会把里面的人震出去（红圈），震之前狠打它能连护盾一起打碎，爆破弹也能；隐身者摸过来时地上有淡淡的红点，偷袭前会闪一下——转身面对它（或打它）就能反击，背对就挨刀。打死能力者掉零件、钢材和特殊手雷。
蓝图与改装新开一局时在「模式 / 地图」里选 2 种开局载具（默认自行车 + 货运三轮），其它载具要找到它的蓝图才能造（尸城求生照旧用它自己的载具 / 建筑蓝图，但机甲、枪械、战甲图纸一样会搜到）。搜箱子 / 车 / 柜子时偶尔会翻出蓝图（大约二十个里有一张）：载具蓝图找到就解锁；机甲强化图纸和枪械改装图纸要在商店里花钢材和零件装上，每种最多 3 级，每一级都能在模型上看到变化，每台机甲各有一套：疾风 护甲套件 → 双联机枪 + 推进器 → 极速尾翼；赤刃 大铠 → 燃烧的妖刀 + 旗指物 → 新月前立 + 鬼火；工蜂 安全帽 → 快递无人机 → 蜂后翅膀；铁卫 塔盾 → 液压重拳 → 金角；苍隼 流线座舱 → 腰挂导弹 → 光翼 + 尾羽；重炮 反应装甲 → 主炮 → 雷达。第 1 级更耐打，第 2 级更痛，第 3 级两样都再加。枪：1 级扩容弹匣（弹匣 ×1.4，枪身变黑橙）→ 2 级双联枪管（多一根枪管，一次打 2 发并排的子弹、每发 ×0.58，总伤害 ×1.16；枪身变蓝、青色弹道带拖尾、激光瞄准线）→ 3 级三联镀金（三根枪管一次 3 发、每发 ×0.42，总伤害 ×1.26，弹匣 ×1.7；金色枪身、金色弹道和激光）。并排的子弹扫得更宽，打尸群更好用；喷火器是火焰更宽更远，榴弹是一次多发。
等身战甲：图纸里还有六件战甲（头盔、胸甲、肩甲、护臂、腿甲、动力背包），谁在商店里「穿上」就归谁（自己已有的留给队友），每件花钢材 18、零件 14：头盔视野 +3 格、受伤 −5%，胸甲受伤 −20%，肩甲被击退减半、受伤 −8%，护臂换弹快 25%、射速 +10%，腿甲步行快 12%，动力背包生命上限 +40、4 秒没挨打就每秒回 3 血；穿齐六件受伤再 −10%、怪兽和能力者打你再 −15%（全套合计约少挨 37% 的伤害，打怪兽约少 47%），战甲上的光纹全亮。穿了哪件，人物身上就多哪件。另外，弹匣打空会自动换弹。
机甲被控制机甲打得更狠、更扛打，但大块头和特殊丧尸会想办法困住它（只对机甲 / 神兽有效，步行不受影响），每种都有预警、也都有办法：硬直（重锤震地 / 冲撞、怪兽甩尾 / 冲锋 / 扑击 / 巨石 / 钻出、翼龙俯冲；0.6–1 秒不能动也不能出招）——看到地上的红圈和冲撞预警就走开；减速（喷吐者酸液、裂颚兽酸息、毒液尸王的毒池）——离开酸液；破甲（防暴尸、钢尾兽甩尾；6 秒内机甲挨打 +25%）——先打掉它；扒住（攀爬者跳到机甲上，最多 3 只，每只慢 15% 还一直挠装甲）——普攻甩掉一只，放技能 / 变形 / 进化全部甩掉。同一种控制 5 秒内再中只有一半时间；进化成神兽的瞬间解除所有控制。被控制时机甲头顶会写出来。
步行和开车：丧尸要贴着你一小会儿（约 0.45 秒）才咬得到，从旁边擦过、开着车冲过去都不会挨咬。
第二形态有了载具以后，不管步行、开车还是机甲，杀丧尸都会攒进化槽（一只 4%，大块头 / 能力者 15%，怪兽 40%），最多能存到 500%（每 100% 能变 22 秒，打怪兽时小怪清完了也能撑住；变回来剩下的还留着），满 100% 后在机甲形态长按 X（触屏长按变形键，满了会发光）进化成神兽（点一下 X 还是变回载具），期间再杀敌能多撑一会，装甲回 30%（30 秒内一次），进化瞬间把身边的丧尸震开。神兽形态点 X 变回机甲，长按 X 直接变回载具。
青蛇（自行车）最快、35% 闪避，只用尾巴：两下甩尾横扫一圈、第三下尾巴砸地，都能打晕，技能毒雾；赤龙（摩托）按住喷火，技能龙腾冲 10 格；玉兔（三轮）最耐打，两只长耳朵像鞭子一样往前抽、第三下转一圈，技能月落砸出大坑；玄龟（装甲车）最硬、身边队友减伤 40%，缩壳往前冲撞，技能旋甲刀枪不入；火凤（旋翼机）一直飞，扇翅从翅尖射出火羽，技能涅槃回装甲还给队友回血；铁熊（坦克）左右掌举高拍下 + 双掌砸地，杀敌回装甲，技能熊吼震住一片并狂暴。
怪兽第 5 夜起隔夜来一只（第 11 夜起两只，每只血少一些）。每个大招都有红色预警，放完会露出破绽（双倍伤害）：喷完酸会喘气、甩尾后站不稳、冲锋撞到结实的墙会晕 3 秒、钻地冒出来会卡住、扑击落地会僵住；预警时打出足够伤害（或用机甲重击 / 爆炸晕住）能直接打断。裂颚兽会远距离扑过来（落点有红圈），钢尾兽会扔巨石（能砸墙），掘地兽会放一排地刺（红线）。怪兽能撞烂木墙木门，砖墙以上的楼里它进不来，但会用远程招数打你。血少于一半会暴怒：吼一声把人震开，技能更快。第 7 夜起还可能来会飞的翼龙兽：在高空盘旋（枪、火箭、旋翼机打得到），沿红线俯冲后会落地僵住（这时近身打），往你要去的地方洒酸（落在屋顶上会腐蚀屋顶），人聚在它下面时会扇风把人吹开；预警时打出足够伤害能把它打下来，在地上躺 3 秒。
视野和复活只看得到你和队友视野里的丧尸（画面和地图都是）：步行 18 格，越高看得越远，夜里看得近；装甲车只有 13 格，旋翼机在天上 26 格。丧尸在你们的视野外不会扑、冲、吐、叫或放技能。血少于 30% 屏幕四周会泛红、有心跳声。队友死了，你在任何建筑里或营地按交互键就能让他在你身边复活。
爬梯和翻越朝梯子走就爬上去，往下要继续推一下；丧尸爬梯子很慢（攀爬者除外）。没有跳键：走路碰到沙袋、拒马、掩体、栅栏、瓦砾和一人高的墙会自己翻过去，朝一格宽的空隙走会自己跳过去；丧尸不会翻，只能砸。

触屏左半屏按下就是摇杆。右下角只有一个射击键，四周四个小键：
· 射击键：点一下 = 打一发；按住不动 = 一直打（自动吸附最近的丧尸），按住后再拖 = 边打边转方向；先拖再松手 = 只选目标（脚下蓝圈），之后按住就打它。
· 武器键：点一下换下一把快捷武器；按住往上拖武器键上方弹出一小圈武器，滑到想要的那把松手（圈里还有「换弹」，中间是「装备」）。
· 交互键：旁边有能搜 / 砍 / 扶的东西时变亮，点一下开始；骑车时是「下车」。
· 医疗：交互键左边的绿键，点一下用医疗包（倒地时 = 自救），受伤时会亮起来。
· 刀 / 盾：点 = 近战（刀冲上去砍，盾推开一片）；在键上滑一下 = 刀和盾互换。手雷：点一下自动扔向最大的尸堆；拖动 = 地上出现落点圈，松手扔，拖回中间取消；按住不动 = 手雷键上方弹出一小圈手雷种类（和武器键一样），滑过去松手。
· 没有跳键：走路会自己翻过矮障碍、跳过一格空隙。
也可以直接点丧尸：点一下选中，再点同一只开火。右上角：「道具」放墙 / 陷阱 / 跳板，「载具」上下车（长按换车），「商店」（在建筑里出现），「视角」，「?」按键说明。两指捏合缩放。
