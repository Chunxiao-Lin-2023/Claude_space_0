# 百变迷藏 Prop Hunt

变身捉迷藏：一个人藏，一个人找。躲方能变成房子里**已有**的家具（椅子、盆栽、纸箱、马桶……），抓方只能一件件去**敲**，敲错的次数有限。玩法参考 Garry's Mod 的 Prop Hunt 模式（打错扣血 → 这里是有限次敲击）、堡垒之夜 / COD Prop Hunt 的定时哨声、《女巫来了》的嘲讽。

- **房子**：一栋九个区域的低多边形 2.5D 房子（厨房、餐厅、主卧、浴室、客厅、走廊、书房、儿童房、花园），每局按种子随机布置约 100 件家具（40 多种）；同一房间里同类家具颜色一致，方便“混进去”。
- **实时追逐**：躲方 30 秒藏身（抓方黑屏数数），抓方 3 分钟、可敲错 5 次。抓方只看得见自己所在的房间（门口两边都亮）。躲方每 30 秒自动吹哨（显示房间名、位置有 2 米左右的偏差），可主动嘲讽换时间 -15 秒。变身后能慢慢挪动，但会被看见、会有摩擦声；人形走路有脚步声。敲错时若躲方在 2.5 米内会提示“附近有动静”。
- **回合推理**：整栋房子可见。躲方选一种家具放下（必须是那个房间已有的同款）；抓方每回合敲一件，敲错得到 烫/热/温/冷（2.5/5/8 米）提示并标在家具上；之后躲方可挪动 3 米内（不能穿墙）、就地变成 3 米内的别的家具，或不动——这时抓方是黑屏。每 3 回合吹一次哨。可敲错 6 次。
- **对手**：单人时电脑躲（会挑同类家具多、靠墙、朝向一致的位置，实时模式下趁你不在时换地方、偶尔嘲讽；回合模式里被敲“烫/热”后倾向逃开）。双人联机（PeerJS，房主权威，客人在实时模式下对自己的位置/变身权威），每局交换角色、记比分。
- **操作**：WASD/方向键移动，E/空格 敲或变身（也可直接点家具），Q 变回，R 旋转，T 嘲讽，滚轮缩放，Esc 菜单，M 静音。触屏：左下浮动摇杆，点家具敲/变身，回合模式双指缩放、拖动查看。

## 源码

- `src/` 按序拼接：`00_core.js`（工具、随机数、平衡参数 `BAL`）、`10_props.js`（家具库，盒子/多边柱拼成）、`15_map.js`（房间、门、墙、随机布置）、`30_sim.js`（规则、碰撞、敲击、哨声、电脑躲方）、`50_render.js`（Canvas 2D 正交斜视渲染、按占地拓扑排序、拾取）、`60_audio.js`、`62_input.js`、`70_net.js`、`80_ui.js`、`90_main.js`、`99_boot.js`；页面骨架 `template.html`。
- 构建：`python3 prophunt/src/build.py --deploy`（写 `../index.html`；`src/out/` 里另有 `test.html` 和单人版 `artifact.html`）。
- 测试（仓库根目录 `python3 -m http.server 8765`；playwright 等装在任意 `node_modules`，用 `NODE_PATH` 指过去）：`test/smoke.js`（单人两种模式）、`test/coop.js` 和 `test/turncoop.js`（先 `node test/peerserver.js`；实时/回合联机 + iPad 触屏摇杆）、`test/phone.js`（iPhone 竖横屏、iPad、桌面各界面截图）、`test/cover.js`（游戏厅封面）。
- 本地存储键前缀 `prophunt.`；联机房间 id 前缀 `prophunt-`。
