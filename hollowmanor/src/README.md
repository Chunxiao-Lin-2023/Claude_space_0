# 幽宅双影 源码

- `00_core.js` … `99_boot.js`：按编号顺序拼接成一个 `<script>`：核心与数值表（`BAL`、角色 `ROLES`、证据 `EVID`、怨灵 `GHOSTS`、宅主 `BOSS`、遗物 `ITEMS`、镇物 `ANCHORS`）→ 地图引擎：碰撞、视线、寻路、互动点生成（`10_map.js`，`buildMap(fi)` 读 `FLOORS[fi]`）→ 三层楼的数据表（`11_floor1.js` / `12_floor2.js` / `13_floor3.js`：房间、门、家具、灯、机关、目标与提示、每层数值覆盖 `bal`）→ 像素工具、地板瓦片与墙纸（`40_px.js`：3/4 斜俯视投影 `PX`=20 像素/米、`VS`=0.6）→ 家具（`41_props.js`：每件家具在自己的坐标系里用小方块搭起来，按朝向旋转、由后往前画进缓存画布）→ 角色精灵（`42_chars.js`：阿岩、小雾 20×32 四方向走路帧、倒地和跪姿；五种怨灵真身与面纱形态、遗物、镇物、贴脸惊吓用的 32×32 鬼脸）→ 主机权威模拟（`30_sim.js`：楼层切换、`PZ` 机关表、恐惧、证据、仪式；同屏模式两个人都在本机移动）→ 怨灵 AI（`35_ghost.js`：游荡、闹鬼事件、猎杀、僵直）→ AI 队友（`36_ai.js`：单人模式里扮演另一个角色；0.5 米格子上的寻路（家具挡路、锁着的门不通、墙缝只让灵视者过），按优先级决定做什么：扶人 → 躲 / 保护 → 守仪式 → 去标记点 → 身边的本职工作 → 跟随；会说话）→ 场景组装（`50_render.js`：地板缓存、0.5 米一片的墙、门窗、墙上的东西、灯具）→ 每帧画面（`51_frame.js`：按深度排序绘制、墙后的人把墙变淡、黑暗遮罩 + 房间灯 + 射线裁剪的手电光锥、灵视层、雷电、后期）→ 像素小剧场与惊吓（`52_stage.js`：每层开场和结局的台词、贴脸惊吓、不时出现的“不对劲”）→ 合成音效（`60_audio.js`）→ 键鼠 / 触屏 / 手柄（`62_input.js`：同屏时阿岩 WASD + 鼠标、小雾方向键 + 回车；平板左右两个摇杆）→ 联机（`70_net.js`）→ 界面（`80_ui.js`）→ 主循环（`90_main.js`）→ 启动。
- `template.html`：页面骨架、CSS 和界面 DOM（含 iPhone 横竖屏适配，见仓库根目录 `IPHONE.md`）。
- `build.py`：输出 `out/index.html` 和 `out/test.html`（带 `window.__dbg` 测试钩子，支持 `?solo=1&seed=&role=&floor=` 单机测试，同伴是跟随机器人），加 `--deploy` 时写 `../index.html`。没有 claude.ai artifact 版本。测试钩子：`window.__dbg.noStage` 跳过小剧场，`__dbg.cam=[x, z]` 把镜头摆到任意位置，`window.__dbgLight` 关掉黑暗。
- 存档（localStorage，前缀 `hollowmanor.`）：`settings` 设置（含 `scare` 贴脸惊吓开关）、`mute`、`prog`（解锁到的楼层）。
- `test/`：Playwright 测试（`npm i playwright peer peerjs express`，用预装 Chromium）。先 `node test/serve.js out 8765`：
  `smoke.js`（单机跑 3 分钟模拟）、`flow.js`（用真实互动代码从头打通一层：证据→保险丝→暗门→电力→符文锁→遗物→双拉杆→错误献祭→正确献祭→上楼）、`flow23.js`（接着打通二楼和阁楼：阀门与钥匙、铜铃顺序、裂缝与门闩、梳妆镜仪式、油灯、镇物、法阵守护、天窗通关）、`shots.js`（按 `SHOTS` 环境变量截图，`Q` 追加查询参数）、`phone.js`（iPhone / iPad / 桌面布局与出屏检查）、`ai.js`（单人模式：AI 跟随、转符文锁、装保险丝、双拉杆、推书架、扶人、强光保护、灵视者报密码、主持仪式、躲柜子、钻墙缝开门闩、铃铛标记、镇物、法阵、一起爬天窗）、`coop.js`（两个真客户端联机：大厅、换角色、开始、客机移动与拾取、快捷信号、跨楼层同步、掉线；需 `node test/peerserver.js`）。
