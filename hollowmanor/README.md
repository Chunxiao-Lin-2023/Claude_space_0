# 幽宅双影 · Hollow Manor

双人联机的俯视角 3D 鬼屋探索（实时 three.js，场景、家具、角色和怨灵全部程序化建模）。雨夜，两个人被困在一座老宅里：大门锁死，二楼的楼梯被灵封挡住。

**非对称的两个人**
- **持灯者 · 阿岩**：手电筒是真实的聚光灯，投下动态阴影；手电照得出 ❄ 霜痕和 ◐ 镜中影；强光（右键 / F）能把怨灵定住；符文锁、保险丝、暗门书架只有他能动。
- **灵视者 · 小雾**：看得见另一侧——怨灵的位置（隔着墙也能看到）、✋ 灵痕手印、◌ 灵球、写在墙上的符文密码、暗门里漏出的阴风；只有她能在祭坛主持驱灵仪式。

**一层楼的流程**：收集两种证据，在日志里确认怨灵种类（泣嫁 / 顽童 / 守钟人 / 无面者）→ 找到它惧怕的遗物（有的藏在书房、温室、暗门后的杂物间）→ 同时拉下客厅和餐厅的两根拉杆打开祈祷室 → 灵视者在祭坛主持仪式，持灯者用强光守住她 → 一起登上楼梯。每局随机：怨灵种类、它盘踞的房间、证据位置、符文密码、遗物位置。

**紧张感**：恐惧值（分开、黑暗、看见怨灵都会上升，越怕它越早猎杀）；猎杀前灯光乱闪、低鸣响起；躲进衣柜（被它看见躲进去的话会被拉出来）；被抓住倒地，45 秒内要被同伴扶起；跑步会被听见；立体声定位的合成音效、雷雨、心跳。

**操作**：WASD 移动 · 鼠标朝向 · Shift 奔跑 · E / 左键 互动（按住）· 右键 / F 强光 · Q 标记 · 1–4 快捷信号 · G 发送符文 · J 日志 · Esc 菜单 · M 静音。iPad / iPhone：左半屏拖动移动，右下拖动朝向，按钮互动 / 强光 / 奔跑 / 标记 / 信号 / 符文。

**联机**：一人创建房间，把 4 位房间码发给同伴（WebRTC 直连，房主页面保持在前台）。只支持双人。

源码在 `src/`（见 `src/README.md`），改完运行 `python3 src/build.py --deploy` 重新生成本目录的 `index.html`。
