# 幽宅双影 · Hollow Manor

双人像素风鬼屋探索（3/4 斜俯视，地板、墙纸、家具、角色和怨灵全部程序化画出来）。可以两个人用一台电脑 / 平板同屏玩，也可以联机。雨夜，两个人被困在一座老宅里：大门锁死，楼梯被灵封挡住。一共三层，每层一个怨灵，最上面的阁楼住着宅子的女主人。

**非对称的两个人**
- **持灯者 · 阿岩**：手电是一道被墙挡住的光锥，黑暗里只有它照到的地方看得清；手电照得出 ❄ 霜痕和 ◐ 镜中影；强光（右键 / F）能把怨灵定住；符文锁、保险丝、暗门书架只有他能动。
- **灵视者 · 小雾**：看得见另一侧——怨灵的位置（隔着墙也能看到）、✋ 灵痕手印、◌ 灵球、写在墙上的符文密码、暗门里漏出的阴风；只有她能在祭坛主持驱灵仪式。

**三层楼**（每层都要先认出怨灵、找到它惧怕的遗物、驱散它，再一起上楼；通关的楼层可以在大厅直接选择开始）
- **一楼 · 门厅**：收集两种证据，在日志里确认怨灵种类（泣嫁 / 顽童 / 守钟人 / 无面者）→ 找到遗物（有的藏在书房、温室、暗门后的杂物间）→ 同时拉下两根拉杆打开祈祷室 → 灵视者在祭坛主持仪式，持灯者用强光守住她 → 登上二楼。
- **二楼 · 卧房**：换一个怨灵（不会和一楼重复）。浴缸里泡着主卧的黄铜钥匙——拧开阀门放水才拿得到；画室的门要按灵视者才看得见的顺序敲响五只铜铃（敲错会重来）；墙上的裂缝只有灵视者挤得过去，她要从里面拉开衣帽间的门闩。仪式在主卧梳妆镜前。
- **三楼 · 阁楼**：宅主温夫人本人，没有证据可找，她更快、更狠、要三次强光才定得住。点亮阁楼里的油灯能拖慢她（猎杀时会被吹灭）；三件镇物要灵视者先解开灵缚、持灯者再砸碎；破掉封印后，灵视者在法阵里吟诵 15 秒，持灯者必须守在她身边；最后从屋顶的天窗逃出去，迎来黎明。

**画面与演出**（参考百物语、恐怖屋、尸夜孤楼）：像素精灵四方向走路帧；墙后的人会让那段墙变淡；黑暗遮罩上挖出房间灯、油灯、手电光锥和小雾的灯笼；灵视者的画面偏冷，看得见灵痕、灵球、铜铃上的数字。每层开场有一段像素小剧场（阁楼是温夫人现身），通关有结局；猎杀开始时离它太近会被贴脸惊吓；平时也会有“不对劲”——手电尽头一闪而过的人影、黑暗里的眼睛、墙上的血手印、耳边的低语。设置里可以关掉贴脸惊吓（改成红光和心跳）和震屏。

**紧张感**：恐惧值（分开、黑暗、看见怨灵都会上升，越怕它越早猎杀）；猎杀前灯光乱闪、低鸣响起；躲进衣柜（被它看见躲进去的话会被拉出来）；被抓住倒地，45 秒内要被同伴扶起；跑步会被听见；立体声定位的合成音效、雷雨、心跳。

**联机操作**：WASD 移动 · 鼠标朝向 · Shift 奔跑 · E / 左键 互动（按住）· 右键 / F 强光 · Q 标记 · 1–4 快捷信号 · G 发送符文 · J 日志 · Esc 菜单 · M 静音。iPad / iPhone：左半屏拖动移动，右下拖动朝向，按钮互动 / 强光 / 奔跑 / 标记 / 信号 / 符文。

**双人同屏**：一台电脑——阿岩 WASD 移动、鼠标瞄准、E 互动、F / 空格 强光、左 Shift 跑；小雾 方向键移动、回车 互动、右 Shift 跑。一台平板——左摇杆和左边按钮是阿岩，右摇杆和右边按钮是小雾。也支持两个手柄。两个人不能走出同一个画面。

**联机**：一人创建房间，把 4 位房间码发给同伴（WebRTC 直连，房主页面保持在前台）。

源码在 `src/`（见 `src/README.md`），改完运行 `python3 src/build.py --deploy` 重新生成本目录的 `index.html`。
