# 猫猫咕咕的家（PawPals 网页版）

桌面宠物 + 待办软件「猫猫咕咕 PawPals」里“小屋”部分的网页版：三层小屋和院子、两只猫（三花猫猫猫、狸花猫咕咕）、
爸爸妈妈和小宝的日常、小镇地图和各个地点、对战区的十几种游戏、躲猫猫……都和桌面版一样。

## 怎么玩

- 鼠标：点家具 / 开关灯 / 拉窗帘；**右键**（触屏：**长按**）猫、家人、家具或空白处出菜单；**双击**猫或家人就自己操控 TA。
- 操控时：WASD / 方向键走，空格跳，E 互动，F 拍 / 扔，Esc 放开；触屏上会出现摇杆和按钮。对战里 J / K / L 攻击、技能、格挡。
- 上方工具栏：全部 / 二楼 / 一楼 / 户外，🗺 地图（小镇、对战区），🎮 玩耍（控制谁、小游戏、玩法说明），✎ 装修，⌂ 游戏厅。
- 右键空白处 → 🌐 联机：开房间会得到 4 位房间码，朋友在自己的浏览器里“加入房间”输入它，两个人共用一间小屋（最多 3 位客人）。
- M 键静音；右键空白处 → 设置 → 名字、称呼、音量。
- 存档（家具摆放、名字、心情、好感、访客图鉴等）存在这个浏览器的 localStorage（`pawpals.` 开头）。

第一次打开要下载浏览器里的 Python 运行环境（Pyodide，约 10 MB，之后浏览器会缓存），等几秒。

## 怎么做的

页面在浏览器里直接运行桌面版的 Python 代码：

- `src/desktopcats/` 是桌面版代码包的副本（小屋、画图、对战等模块），网页版专用的几处小改动写在 `src/patches.py`（构建时套用，断言只匹配一次）。
- `src/py/PySide6/` 是一个小小的 Qt 替身：几何、颜色（和 Qt 的 lighter/darker 算法逐位一致）、QPainter 把画图指令编码成 float32 流 + 字符串表；页面用 Canvas 2D 回放。菜单、对话框（开始对战、访客图鉴…）变成网页 UI。
- `src/py/webapp.py` 代替桌面版的 App：存档、声音、菜单、联机（PeerJS 代替 TCP，协议还是桌面版的 JSON 快照）。
- `src/index.src.html` 是页面：加载 Pyodide、回放画面、输入、菜单 / 对话框、触屏摇杆、声音、PeerJS。
- 声音：`src/make_sounds.py` 把桌面版合成的声音预先渲染成 16 kHz μ-law → `src/sound_data.js`。

重建：`cd src && python3 build.py` → `index.html`（游戏厅用）和 `src/artifact.html`（claude.ai 单人版）。
桌面版更新后，把新的 `desktopcats/*.py` 拷进 `src/desktopcats/` 再重建即可（`patches.py` 匹配不上会报错）。
