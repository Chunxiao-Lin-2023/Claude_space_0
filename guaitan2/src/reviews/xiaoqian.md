# 第十一夜「聂小倩」（xiaoqian）· 自审 20 条

文件：`src/chapters/11_xiaoqian.js`、`src/tests/sol/xiaoqian.py`。先对照 LESSONS.md 逐条自查（第 10 条投票分支本作不做），再补上本章独有的问题。20 条全部已实现。

## 故事与传说
1. **开场丢了原句「生平无二色」**：标题卡只有白话 → 卡上先写原句，再用白话解释一遍。
2. **名句「缓待同行」没出现**：小倩追来时只喊「等等我」 → 先喊原句「缓待同行！」，再接白话。
3. **坟里那块木牌（「儿莫怕，娘明年来接你」）没有回应** → 下葬时，宁在旧木牌旁另插一块「聂氏小倩之墓」；结局补一句两块木牌一直并排立着。
4. **回家一幕只有文字，宁母没出场** → 走到堂屋门口时宁母出来，小倩行礼，母亲说不出话，然后才进结局。
5. **窥院、剑匣夜两段对话太长**（LESSONS 16）→ 合并旁白，「更敬重燕生」挪进第四天的标题卡，两段都压到 10 页左右。

## 谜题
6. **挖错的代价只有天变暗**（LESSONS 1）→ 第一次挖错，坟里的冷气冲裂剑袋一块补丁（追逐时少定一回，至少留两块）；之后每次挖错仍会变暗、惊吓，并按挖错的原因给针对性提示（柳/槐/松/喜鹊窝/掉在地上的窝）。
7. **第 3 级提示没给位置**（LESSONS 2）→ 第 2 级给方向（只有三棵灰白皮、长「眼睛」的白杨），第 3 级点出三棵白杨的方位，第 4 级直接说是哪一棵。
8. **树冠和鸟窝被地图上沿切掉，看不见窝**（LESSONS 3）→ 坟地整体下移两行；调查树时镜头抬到树梢，看完再放下。
9. **乌巢和喜鹊窝在画面上差别太小** → 乌巢画成宽扁的敞口碗，窝沿探出两个黑脑袋；喜鹊窝画成高圆的封顶窝，侧面一个黑洞，老鸹蹲在窝顶。窝的类型每局随机分给三棵白杨（`f.pr`），死记位置没用。

## 危险段
10. **追逐按真人速度实测**（LESSONS 5）：一直走、从不站住也能逃掉 → 夜叉 4.4→5.0 格/秒（玩家抱骨只能走，3.36 格/秒）；第一次被扑只算警告，但只撞开 4~5 步、0.6 秒后再追。实测结果见文末。
11. **被剑袋定住的夜叉看不出来** → 定住时它身上罩一层冷白光，快解冻时一闪一闪（`light` 会同步给客机）。
12. **不知道什么时候该站住** → 夜叉进到 3.8 格内，剑袋「叮」一声，越近越亮；它每走一格有一声闷响，越近越重（LESSONS 18）；目标改成「剑袋叮一响就站定」。站定判定要连续静止 0.12 秒，过格子那一帧不会误触发。
13. **夜叉可能落在玩家面前**（LESSONS 7）→ 只落在北墙根、离玩家至少 4 步的点，先显形 0.6 秒、再停 0.5 秒才追；玩家站在角门口不走，先冒「！」和一句提醒，不刷在身边。
14. **第二夜的诱惑全都绕得开，夜巡没有张力** → 金锭挪到殿前石路正中，池边女人挪到去东厢必经的池东岸；犯一次是警告（脚心一凉），犯两次才死，重来后计数复位。

## 双人
15. **目标栏太长，竖屏折成三行；「一人盯身后」没有意义（两人看的是同一个画面）** → 各目标压短；追逐改成「一人走，一人听剑袋『叮』就喊停」，坟地是「一人看笺念燕生的图，一人认树」，夜巡是「两人互相盯着」。

## 氛围与音效
16. **寺钟只在第一天黄昏响过一次** → 挖出骨殖、老鸹炸群时城里的暮钟响起来，接着进追逐，前后呼应。

## 画面
17. **大殿匾额的笔画拼成了「王古廿」** → 改成辨不出字形的褪金墨迹。
18. **门洞用了石板瓦片，花纹溢到左边墙上成了灰块** → 两间僧舍的门洞改成木地板。

## Bug
19. **坟地下移时的批量改坐标误伤了别的地图**：正则从 `light()` 表里的 `fen:` 开始匹配，把兰若寺和僧舍里所有没 id 的实体往下挪了两行（窗户掉到墙下、书箧挪了位、水缸跑到地图外）→ 只对坟地下移，其余还原，逐个复查坐标。
20. **与燕生见面前后，门口的台词穿帮**：他已经回来站在门口，你的门却说「先等主人回来」，他的门说「他说过喜欢清静」（还没说过）→ 见面前（`a1y`）两扇门各写一句对得上的话。
