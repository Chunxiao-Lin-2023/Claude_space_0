# 第三夜 · 犬鸣村（inunaki）自审与优化：20 点

先按 SOL 跑通主线、看截图，再用实时脚本（fast=1、真人按键）跑了出隧道、村子巡逻和岔路口几段。下面 20 条全部已实现。

## 谜题
1. **岔路口提示改成四级** —— 原来错 3 次就直接报答案 → 改为：错 1 次提醒「只有信号格不会骗人」，2 次教方法（每条岔路走两步看信号），3 次缩小范围（两条会变圏外、一条会多一格），4 次才说出是哪条。
2. **岔路里信号变化加文字** —— 头顶的信号格太小，只靠提示音容易漏看 → 每个路口前 3 次信号变化弹出「信号 n 格 ↑/↓」或「信号：圏外 ✕」。
3. **纸条可能被错过** —— 候车亭的纸条是岔路口和倒着走两条规矩的出处，玩家可能根本没去 → 救出拓也时若还没读，拓也会提起「候车亭长椅上钉着一张纸」，候车亭冒「!」，目标里也补一句。

## 危险段
4. **出隧道开头太容易死** —— 实测选完「倒着走」后愣 3 秒就被追上 → 两个村人晚 2 / 2.4 秒才动身，速度降到 1.5 / 1.4 格每秒；中途停 6 秒仍会被追上（实测）。
5. **倒着走的信号时间放宽** —— 计时在对话中也走（during），回头那段对话要读 4 页 → 34 秒改 36 秒；实测按规则走完剩约 16 秒，读字慢的玩家也够用。
6. **村人第一次发现你多给反应时间** —— 原来只有 0.9 秒预警 → 第一次被发现时停顿 1.6 秒并弹出「快跑 / 躲进水桶」提示，之后才是 0.9 秒。
7. **第一次碰响罐头绳只是警告** —— 一碰就把提斧头的人引过来太狠 → 第一次它只转头朝响声张望（提示「下次它就会走过来」），第二次起才走过去查看。
8. **追兵的脚步用声音提示远近** —— 倒着走时看不见身后，也听不出追兵多近 → 用 `S.tone` 合成斧头拖地的刮擦声，越近越响、越亮、越密。

## 双人
9. **目标提示里写明分工** —— 原来分工只在一闪而过的 toast 里 → 联机时岔路口目标带「一人盯信号格，一人盯身后的油灯」，出隧道目标带「一人盯着油灯，一人替同伴看出口那边的路」。
10. **倒着走时镜头偏向村子** —— 操作的人朝村子看、看不清身后的路 → 出隧道时镜头往村子那边偏 3 格，追兵始终在画面里；出口方向的碎石路交给观看的一方提醒。

## 叙事与传说
11. **档案年份修正** —— 旧隧道附近那起真实刑事案件写成了「九十年代」→ 改为八十年代末，并保持「据说」「不涉及细节」的写法；新隧道（七十年代）、水库（九十年代建成）、2020 年电影核对无误。
12. **「会学人说话」做成一幕** —— 原来只在录像笔记里出现 → 第一次走近仓库时，门前有个穿着你外套的人在用你的声音叫门，转过头来是两个黑洞的眼睛，然后消失，只留下湿手印；也解释了拓也为什么要盘问车钥匙。
13. **传说「车子靠近会熄火」做进来** —— 原来只写在网页上 → 进隧道前去碰车会打不着火；好结局要拧三次钥匙；「一个人」结局里车子最后是拖下山的。
14. **把水库和 GPS 联起来** —— 「水库下沉没的旧村落」只在档案里 → 村口被封死时，GPS 把你们的蓝点放进「犬鸣水库」正中间；第三个岔路口 GPS 也指向湖心（真实背景仍只在档案里讲）。

## 氛围与画面
15. **木牌第三行字被裁掉** —— 截图里「つうじません」压在木牌下沿外 → 木牌加高 6 像素，三行 / 两行字都重新排位置；iPad 竖屏截图确认看得全。
16. **惊吓大头像别用太多次** —— 「拓也」的脸会在回头、信号耗尽、电话亭三处出现 → 信号耗尽改成雪花屏，大头像每张最多出现 2–3 次。
17. **信号格第一次出现时说明** —— 头顶的小图标没人解释 → 开场掏出手机时提示「头顶的小图标：手机信号格」，进隧道第一次掉到圏外也提示一次。

## 目标提示
18. **开场找不到车** —— 车停在镜头下方的画面外，目标只写「在车边等」→ 车头冒「!」，目标改成「回车上等拓也（车停在路的下面）」。

## Bug
19. **重来后罐头绳一直晃** —— 罐头绳 / 狗链的晃动用 `W.t` 时间戳，重来后 `W.t` 归零，旧时间戳让它们一直晃 → 判断加上 `W.t >= 时间戳`，村子的三个检查点重来时清掉时间戳。
20. **躲进水桶时拓也还站在外面** —— 救出拓也后躲藏，他就杵在村人眼前 → 躲藏时拓也一起藏起来（缩进柴堆后面），出来后重新跟上。

## 测试结果（全部改完后统一跑一次）
- 主线：`play.py inunaki` → `inunaki OK`，无 ERRORS、无 REACH WARNINGS。
- SOL 变体（scratchpad）：电话亭坏结局 + 重来后改选不接 → 好结局；「一个人」结局（进村时 / 村口隧道两处）；车钥匙答错 3 次（每次引来村人 + 三级提示）再答对；村子被抓 → 重来村人回巡逻起点、罐头绳停晃；救出拓也后被抓 → 重来拓也仍跟着；岔路口连错 4 次 → 被油灯追上 → 重来回到本路口、错误计数清零；信号耗尽 → 重来计时回满、追兵回洞口、仍是倒着走；第二次回头死亡 → 重来；先选「转身跑」一次再倒着走；水桶躲藏。全部通过，结局收集记录 out / booth / alone。
- 真人速度（fast=1 按键脚本）：出隧道按规则走完剩约 16 秒；中途停 6 秒被追上；站着不动被追上；回头一次扣时间、第二次死亡；村子沿土路直走会被发现并抓住，走北边后巷能摸到摄像机和仓库；被发现后往回逃能拉开距离，钻进死角会被抓；岔路口按信号格走 18 秒通过三个路口，站在路口不动约 13 秒被油灯追上。
