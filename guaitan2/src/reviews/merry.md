# 第一夜 · 玛丽的电话（merry）自审 20 点

写完后先按 SOL 跑通主线，再对照 `LESSONS.md` 逐条自查，并用实时脚本（真人按键速度）跑了「下楼拿藤篮」限时段。下面 20 条全部已实现。

## 谜题
1. **宝物盒密码盘写明双人分工** —— 已实现：原来只弹一条一闪而过的 toast → 密码盘提示第二行固定写「联机时：一人翻「笺」里的信和单子，一人拨」。
2. **翻错垃圾笼给针对性提示** —— 已实现：限时段翻红/蓝笼子只扣 2 秒、没说错在哪 → 追加「妈妈扔的是大件——黄牌子的那个」，黄笼子不再误扣时间。

## 节奏
3. **第一通之后的空档太长** —— 已实现：没有倒计时显示的 45 秒容易让人在屋里干转 → 缩到 35 秒。
4. **「坐在电话旁边等」不好发现** —— 已实现：做完准备只能干等 → 第二通后提示「等不及的话：坐到电话旁边，等它响」。
5. **开门的朝向 bug** —— 已实现：在玄关面朝屋里按调查键开门，会被判成「背贴着墙」（身后是门）→ 开门时先转身面向门，身后是屋里，玛丽站在玄关走廊上。

## 恐怖与氛围
6. **敲门时看得见门外的小影子** —— 已实现：第六通玛丽站在走廊里，玩家根本看不到 → 敲门时镜头对准门口，她身上加一圈很弱的光，猫眼里看不见、俯视却看得见。
7. **铃声一通比一通急** —— 已实现：七通电话铃声完全一样 → 间隔从 2.3 秒逐通缩短、音量逐通加大，离电话远会变轻。
8. **第五通后楼梯间的脚步** —— 已实现：「她在楼下」只是一句话 → 第五、六通之间每 2.6 秒一声闷闷的上楼脚步（`S.tone` 合成）。
9. **秋千上的八音盒** —— 已实现：限时段只听见秋千吱呀 → 玛丽坐在秋千上时，走近 9 格以内能听见很轻的《玛丽有只小羊羔》，越近越响。

## 危险段
10. **按真人速度重调限时** —— 已实现：实时脚本测得 → 计时 27 秒 + 第一次超时警告再给 7 秒（见文末）。知道路跑过去不用警告；走路要用掉警告；迷路翻错笼子还走路、或在院子里愣住会死。
11. **电话亭闪烁状态复位** —— 已实现：警告后电话亭一直闪 → 1.2 秒后熄掉；从检查点重来时也强制复位。
12. **死第二次给更具体的路线** —— 已实现：重来时总是同一句提示 → 第二次起说清「贴着楼前水泥地往东走到头、再往南，别进公园，别翻红的和蓝的」。

## 双人
13. **最后站位的目标点明分工** —— 已实现：联机时目标追加「一人翻「笺」看外婆的卡片，一人站位」。

## 结局
14. **隐藏细节：给医院打过电话** —— 已实现：打不打医院电话不影响任何东西 → 打过的话，好结局多一段「铃响两声就挂」的暗号，「背贴着墙」结局里妈妈从此不再值夜班。
15. **背靠柜子的措辞** —— 已实现：背靠冰箱/柜子也说「墙里：你身后，是墙呢」→ 按身后是墙还是家具分开写说话人和旁白。
16. **最后 4.5 秒的目标改写** —— 已实现：「别乱动」和「铃响时还能挪最后一步」矛盾 → 改成「最后一通。站好，别回头」。

## 画面
17. **选章卡片的黑电话太暗** —— 已实现：缩略图上黑电话和暗底几乎分不出 → 加一块窗外月光底和灰色描边，右边仍是玛丽（缺一只眼的金发洋娃娃）。
18. **出门时铁门真的开一下** —— 已实现：进出 503 只有黑场 → 门牌铁门 `open` 时画成黑洞洞的门缝，进出各开一下。

## 可玩性与 bug
19. **玛丽走回篮子被挡住时兜底** —— 已实现：玩家站在必经的门口时寻路失败，她会停在半路 → 走完后强制放到篮子前再淡出。
20. **最后一通前提醒还缺什么** —— 已实现：第六通后玩家可能忘了宝物盒或手里的藤篮 → 没开宝物盒提醒「眼睛还锁在宝物盒里」，篮子没放提醒「藤篮还在我手里」。

## 需要引擎支持
- 无（全部用现有 API 完成）。

## 测试结果
- `python3 guaitan2/src/build.py --out guaitan2/.tmp_merry/index.html --only merry`
- `play.py merry` → **merry OK**，没有 ERRORS，没有 REACH WARNINGS。
- SOL 变体（scratchpad）全部按预期：回头 → 坏结局「回头」→ 从「最后一通」检查点重来 → 好结局；背贴西墙 → 「背贴着墙」；背靠冰箱 → 「背贴着墙」（柜子措辞）；三次不回头 → 「一直在身后」；不下楼拿篮子、给了眼睛 → 「一直在身后」（没有床）并可重来；没开宝物盒 → 只有回头/不回头；院子里愣住 → 警告 → 死亡 → 重来照常通关；第六通开门 → 直接最后一通 → 好结局（820×1180 竖屏截图，文字和走廊里的玛丽都看得清）。
- 实时限时段（`fast=8` 下淡入淡出偏快约 1 秒，计时为游戏时间）：知道路跑过去剩 4.5 秒、不用警告；知道路走路用掉警告后剩 3.5 秒；迷路（秋千旁愣 2.5 秒 + 翻错两个笼子）跑步用掉警告后剩 0.8 秒；同样迷路但走路 → 死；在院子里一直不动 → 约 34 秒后死。
