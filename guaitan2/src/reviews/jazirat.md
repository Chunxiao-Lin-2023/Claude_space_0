# 第三十夜 红岛空城（jazirat）· 自审 20 点

先按 LESSONS.md 逐条对照（第 10 条投票本作不做）：
- 谜题：珍珠要放回 6 个壁龛里唯一对的那一个，条件三条要同时满足（风塔底下 / 炉里是乳香不是沉香 / 里壁有刻痕）。三条分别来自赛义夫的话、外婆的嘱咐与口袋里那包乳香的样子，没有一条能单独定位。放错有代价：闪屏或雪花、珍珠被「推」出来、门外的蹄子声；玛雅姆先按错法给针对性的一句（「这间顶上没有风塔」「这是沉香」「没有刻痕」），再按错的次数逐级提示：第 1 次说要三样都对上，第 2 次指向乳香，第 3 次缩到北边三间，第 4 次直接给答案。
- 危险段：沙暴开始前先设目标，再在大宅门口存 `storm`。乌姆·杜瓦伊斯在第五个路口才出现，出现前有一段蹄子声旁白，刷在身后 13 格、光圈外。第一次被追上只算警告（大头像，她被放回玩家身后 ≥7 格的足迹上），第二次才死。重来会复位：她的位置和隐藏状态、警告次数、足迹、路口旁白、禁止奔跑、赛义夫的跟随。死过以后重来，给一句规则小结；死两次以后再给一条路线提示。
- 状态：记号（`e.s.d/n/mir/er`）、壁龛（`e.s.pearl`）、木箱（`open`）、门（`open`）、车（`e.s.hz/sand/arrow`）都在 VKEYS 或 `e.s` 里。沙暴画面跟着客机自己的 `W.pl` 画。
- 3 个结局都带 id：`dawn`（好）、`wedding`（坏）、`take`（坏，只有读过木箱里的信才会出现这个选项）。隐藏细节有两处：读过信，好结局多一段；在壁龛前说过「打扰了」，结局多一句。
- 大头像两张：`umm`（警告和死亡各一次）、`goat`（只在坏结局出现）。
- 关键声音都用 `S.tone` 合成：蹄子声（越近越响越密）、风笛式的吹奏、羊叫、海浪（越往西越响）、风塔的呜呜声、蜡笔刮擦、伪造记号的「指甲声」、心跳、车门、晨礼时远处的长音。

## 谜题
1. **「它们学人总学反」只有放错壁龛才会被演示，一次就放对的玩家进沙暴前没见过假记号** → 进大宅时院墙上当场「嚓、嚓」地多出一个反写的 5，玛雅姆点破：它在学我们。
2. **乳香是悄悄塞进口袋的，没有提示，玩家不知道自己有一份「外婆的味道」可以对照** → 改成有获得提示（toast），物品说明里写明它的样子（黄白色、半透明颗粒）。
3. **3×5 像素字里，反写的 5 和正写的 2 一模一样（反写的 2 也就是 5），第五个路口的假记号看起来像个正写的「2」** → 数字改成 4×5 字形，正写反写一眼能分；文字描述也一并改过。
4. **读过信、选了「带走」进坏结局后重来，`pearl` 检查点里还没读信，信得再翻一遍，那个选项也消失了** → 读信后再存一次 `pearl` 检查点。

## 危险段
5. **按真人速度实测：速度 2.3 时，每个路口犹豫 2.5 秒就会死，太苛刻（读记号的对话不计时，但看完以后的犹豫计时）** → 降到 2.0，再测一遍（结果见文末）。
6. **她贴近时，只有一个 toast，紧迫感不够** → 4 格以内加合成心跳，蹄子声也随距离变密。
7. **从 `storm` 重来后，赛义夫的跟随还记着上一次的格子，会瞬移一下** → resume 里清掉跟随记录。
8. **反复走到清真寺后面那扇门前，每次都要把整段诱惑对话再看一遍** → 第二次起只剩一句话和一个选择。

## 交互与联机
9. **跟随的玛雅姆站在玩家脚下时（刚切地图、停下来的时候），调查键会先选中她，面前的门、记号点不到**（测试中清真寺后门就点不到）→ 跟随中的玛雅姆、赛义夫被选中时，如果站在玩家脚下，就改为调查玩家面前的东西。

## 画面
10. **沙暴几乎看不见：沙粒撒在整屏，可只有光圈里亮** → 大半沙粒集中在玩家周围，加一层黄褐色的雾和更暖的光圈。
11. **瞭望塔上看到的沙墙像几块橙色的砖** → 改成一层层翻卷的云头，前沿拖着沙丝。
12. **壁龛画得像一排人头** → 重画成白灰尖拱框，里面分别是陶香炉（乳香）、铜盘（沉香木片）、沙堆。
13. **乌姆·杜瓦伊斯的大头像像个小丑（方脸、大红嘴）** → 重画：黑头巾裹出瓜子脸、额前金饰、浓黑眼线；眼睛烧红后嘴角才慢慢咧开，一弯金色镰刃从下面扫过来。
14. **黑山羊大头像的角像两根棍子** → 改成往外弯的羊角。

## 叙事
15. **沙暴里调查清真寺窗户、铜壶、喷漆字，说的还是「月光照进去」「壶身是热的」** → 这 3 处按阶段给不同描述。
16. **进村时的吹奏声没有交代，到沙暴里第一次听懂已经太晚** → 第四个路口画完记号，加一句内心独白：清真寺那头有人在吹曲子，像办喜事——外婆说别凑过去。
17. **档案里写了「夜里举办过集市」，没有可靠出处** → 改成保守的「近年开始修缮，也会举办一些文化活动」。

## 音效
18. **刻记号的声音和「它们」伪造记号的声音一样，听不出是谁在画** → 新增一种更慢更低、像指甲刮的声音（`claw`），只用在伪造记号上。
19. **沙暴里和赛义夫说话只有一句** → 改成三句轮换（听见妈妈在叫、香味又来了、我不看我不回头）。

## 结局
20. **没读信的玩家完全不知道还有隐藏内容和第三结局** → 好结局里，如果没读过信，会多一句：会客厅那只铜钉木箱的箱底，好像压着一封谁也没念过的信。

## 测试结果

- SOL 变体（放在 scratchpad，同一个 Chromium 依次跑，全部通过，没有错误）：
  - `wedding`：沙暴里绕到清真寺后面，第一次退回（确认玩家被让开一格、没进结局），第二次从门口进去 → 坏结局「沙夜的喜事」；重来后回到 `storm`：她隐藏、未激活、禁跑恢复，再走完拿到好结局。
