# 第二十九夜 托克洛希（tokoloshe）· 自审 20 点

先按 LESSONS.md 逐条对照（第 10 条投票本作不做）：
- 谜题：六口水各有四样特征（岸、树、水草、水里的东西）。答案要四条线索合在一起才唯一：白沙（第一夜那块砖）、弯腰树（西菲的画）、锯齿叶（第二天的水缸）、小螺（最后吐出来的石子）。另外五口里，四口各差一样，一口全不对。答错扣 30 秒，屋外的它会尖叫；会按「差的是哪一样」给针对性提示。第 2 次错有大头像，治疗师提醒「四样都要对上」；第 3 次错点出「只剩两口，牛饮水处没有螺」；第 4 次直接说回水湾。
- 危险段：第二夜开始前先设目标，再存 `hunt` 检查点。重来时复位这些：三张床的砖、备用砖、手里的砖、地上掉的砖、水迹、它的位置和状态、扑住的次数、警告、困意、光圈。它第一次爬上歪床只算警告，第二次才死。死过、睡着过以后重来，各有一句规则小结。河边存 `river` 检查点；天亮死后重来，时间取「剩余」和 120 秒里较大的那个。
- 状态：床（`s.br/who/pt`）、托克洛希（`s.vis`）、水缸（`covered`、`s.leaf/lid`）、铺子（`s.night`）、圆屋（`lit`）、火塘（`off`、`light`）、涟漪（`s.hot`）都用 VKEYS 或 `e.s`。走动判断用 `S.moving`；它的走路帧读 `e.fr`。
- 结局：3 个结局都带 id（回到河里 / 砖被偷走的那晚 / 指认）。隐藏细节：村会上替老太太说话、又去找她两次，好结局会多一段；只替她说了话，会多一句。
- 大头像有 `tok`（第一夜水缸边一次、河边第二次答错一次）和 `tok2`（只在死亡时出现）。
- 关键声音都用 `S.tone` 合成：滴水、喝水、刮砖、垫砖、它的尖叫、咳出石子、羊叫、心跳、西菲的喊声、哈欠、鸡叫、治疗师的哼唱。

下面 20 条是对照之后找出来的问题，都已经改好。

## 谜题
1. **河湾笔记末尾写着「对得上的还有两口」，替玩家做完了推理** → 改成只记六口水，末尾写「好像还差一样东西，才知道是哪一口」。
2. **天亮前在河边，水面上的涟漪太淡，暗处找不到能调查的那几口水** → 进入最后一幕时给六口水打上 `s.hot`，涟漪更亮、扩得更快。

## 危险段
3. **第二夜一开始，玩家就站在水缸旁边，它从水缸爬出来就在身边（真人测试 2 秒就扑到第一回）** → 开局改在你自己屋里。它先在厨房喝 2.6 秒水，西菲会喊「它在水缸里喝水」，这是一次能看懂规则的教学扑。
4. **它只会从大门回来，守在门口就能一直扑（真人测试 20 秒通关）** → 它回来时随机从大门或水缸里出来，两处离得远，守不住两头。
5. **它重新出现时可能正好刷在玩家身上（变体测试里站在水缸边就被白送一回）** → 选入口时避开玩家 3 格以内；两处都近就再等半秒。
6. **扑过一回之后，追着它跑就一定扑得到，没有难度** → 扑过一回以后它会躲：走动或抱着砖时，你在 1.6 格内移动，它就往远离你的方向蹿一格，冷却 1.8 秒。偷砖的时候它顾不上躲，正好对应治疗师说的「它偷砖的时候扑住它」。
7. **困意只有文字提示** → 困意过半后，画面整体更暗、光圈缩小，并加一声合成的哈欠。
8. **不知道怎么「扑」** → 开局 toast 明说「走进它所在的那一格，就能扑住它」；第一次扑住后，再提示掉在地上的砖可以捡。

## 联机与操作
9. **西菲的喊声只有 toast，没有声音，跑动中很容易错过** → 每次喊方位，都有两声上扬的合成童声。偷砖、进门的时候更急，是三声。
10. **好几条目标提示超过 20 字，iPad 竖屏要换行** → 压短：搬砖、找治疗师、河边放石子三条都压到 20 字左右。双人分工的说明只在双人时用 toast 提示。

## 叙事
11. **治疗师那段对话加起来超过 10 页** → 合并成 3 + 1～2 + 1 页。
12. **河边旁白写「西菲牵着奶奶的手」，奶奶却不在画面里** → 加上奶奶，站在西菲身后，可以调查，有一句台词。
13. **「指认」坏结局重来后没有任何回应（`S.f.blamed` 写在检查点之后，读档就丢了）** → 改用跨重来的变量，重来时给一句内心独白。

## 画面
14. **第一夜它在水缸边喝水那一幕，水缸在玩家光圈外，几乎看不见** → 这一幕用 `S.lights` 打一束月光照在水缸上，喝完再撤掉。
15. **水迹的光在红地板上照出一团团粉红色的光晕，还从远处暴露它的位置** → 屋里的水迹不再发光，只有走到跟前、进了你的光圈才看得见。远处要靠西菲的喊声、脚步声和心跳。院子里的水迹改成淡淡的冷光。
16. **杂货铺招牌是一串看不懂的方块，选章卡片上的月牙画成了一个「L」** → 招牌用 3×5 像素字写出 SPAZA；月牙改成两个圆相减画出来。
17. **河边的托克洛希在暗处看不见；治疗师背对着玩家** → 给它一圈很淡的水光，治疗师改为面朝玩家。
18. **床脚的砖太小，远看分不出哪张床歪了** → 砖画大一号，缺砖的腿下面画出阴影。少于三块时，床尾下沉 3 像素，床边一闪一闪地亮红色。

## 音效
19. **隐身的它走路没有声音，远处只能等西菲喊** → 它每走一格有一声滴水声：7 格以内才听得见，越近越响。

## 结局与 bug
20. **扑到第三回时手里还抱着砖，砖会一直带到河边的物品栏里；只替老太太说了话、没去找她的人，好结局里没有任何回应** → 赢的时候清空手里的砖。好结局为「只替她说了话」也加一句：她坐在门口晒太阳，冲你抬了抬手。

- 真人速度测试（键盘事件，30ms 一帧）：机器人只知道玩家能感知到的信息，也就是西菲喊出的区域、2.5 格以内看见的水迹和心跳，并带反应延迟。
  - 会玩的：
    - 反应 1.0 秒，跑步：42.7 秒扑满三回。
    - 反应 2.0 秒，跑步：35.6 秒扑满三回。

    - 站着不动：21.3 秒睡着，进入坏结局。
    - 乱走：被它爬上床，先警告一次，61 秒死亡。
