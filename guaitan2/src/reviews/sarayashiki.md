# 第六夜 番町皿屋敷 · 自审 20 条（已全部实现）

## 谜题
1. **摆错只说「对不上」**：错了只有一句「对不上」，24 种排列等于瞎试 → 现在每次摆错都会说「有几片的茬口对上了」（针对错法给反馈）；同一片摆两次不算一次尝试，也不扣续饭。
2. **拼的时候要来回翻囊**：密码盘上只有甲乙丙丁四个字 → 提示里列出每片的样子（弧线／三个「へ」／穗子／卷着白花的蓝线），只需要再对照御皿帐就行。

## 危险段
3. **数到九被看见当场就死**：违反 LESSONS 第 7 条 → 第一次只是警告（她的眼睛停在你身上，然后沉下去），同一段里第二次犯规才死。
4. **偶数拍判定看的是出发格**：从暗处一步迈进亮处再站住，不算犯规 → 改成按要迈进的那一格判定；宽限时间从 0.32 秒放到 0.6 秒（反应时间加上走完脚下这一格）。
5. **安静段太宽**：实测一段 4.2 秒的安静就能捡两片 → 缩到 2.6 秒（第一轮 3.1 秒），要真正跟着奇偶拍子走。
6. **回屋／进土蔵能刷安全期**：出去再进来，数数就重置成安静 → 现在接着原来的拍子数，只有第一次进院子或重来时才从安静开始。
7. **终幕可以躲进土蔵**：放下盘子后能逃进土蔵跳过九枚 → 数数开始后，两扇门都拦住。
8. **第一夜之后还能回院子闲逛**：这时没有数数，碎片也不显示 → 拦住，并提示滴水声从下人部屋传来。

## 双人
9. **目标提示太长**：双人分工那半句被截断 → 目标精简成一行；分工说明单独弹一次 toast（单人时改成「盯着小盘子」的提示）。
10. **报数的人只能靠耳朵分奇偶** → 井上那圈小盘子按奇偶变色：她低头时是白的，抬头时整圈泛青，最新那枚在闪。一人看一眼就能喊「走／停」。

## 氛围与画面
11. **阿菊在井里太小**：被井柱挡着，数到九的「升起来」不吓人 → 九枚时换成放大一倍的身影，从井口高高升起（死亡和坏结局也用这个）。
12. **数数声远近一样** → 按离井的距离调整 `S.tone` 的音量，离井越近声音越大。
13. **八枚只有一声心跳** → 八枚中段再补一声，让心跳加快，催人躲进暗处。
14. **土蔵和白墙有物件没描述**（第二个架子、蔵的墙、海参墙）→ 都补上描述。另外选章缩略图顶部的盘子圈被裁掉了 → 下移。

## 叙事
15. **「莫站井边」重复了三处**（教程、留书、瓦版）→ 删掉留书的附记，留书只讲重点：「少的那一枚，不在嘴上」。
16. **弥平和这座宅子的关系没交代** → 开场加一句「九岁那年就在这府里当小厮」，为坦白埋伏笔。
17. **教程没讲井上那圈小盘子** → 弥平补一句：「数到几枚就亮几枚，泛青的时候就是她在抬头。」

## 结局
18. **普通好结局写错了手巾的下落**：原文写「他到死也没拿出来」，可手巾在阿铃身上 → 改成「阿铃一直收在袖子里，他没有问，她也没有拿出来」，同时暗示还有第三个结局。
19. **隐藏细节**：读过阿菊那封没寄出的信，普通好结局会多一句（阿铃把信压在小祠的木牌底下）；坦白结局里也多一句阿铃的台词，阿菊最后那句「被子没再尿吧」正好呼应这封信。

## Bug
20. **榻榻米的文案不分阶段**：第一夜还没出门时调查，文案就写「掀开的榻榻米底下」→ 按阶段分成三种文案（白天／夜里还没去看井／已经掀开）。
