# 第十八夜 中元·放河灯（zhongyuan）· 自审 20 点

先按 LESSONS.md 逐条对照（第 10 条投票本作不做）：
- 谜题：第三盏灯写名字用 8 个字的键盘写 3 个字，没法靠蒙。线索分在族谱（字辈「德」、次子被涂掉）、阿公的旧木箱（「阿添」）、庙里的石碑（林姓、九岁）、签诗（「手足同根共一字」）和第二盏灯「林公德水」里。写错会有惊吓，第 2 次给方向，第 3 次给具体线索，第 4 次直接给答案。烧纸画圈三问按单子第八条作答，答错按错法给提示。
- 危险段（归途的白灯笼 + 子时倒计时）：开始前先设目标，再存检查点 `ret`。重来时复位白灯笼位置、撞击次数、回头次数和喊声触发，计时取剩余时间和下限 22 秒中较大的那个，并给一句规则小结。第一次撞上、第一次回头都只是警告，第二次才算数。抢孤段前存 `qg`，重来时锣、粿、爬杆的人和顺风旗全部复位。
- 状态：灯、篮子、衣服、火、旗、空桌、戏台都放在 `e.s` 里，或者用 VKEYS 里的 `lit/off/oy`。三盏灯用 `S.wear('@me1~3')` 换外观，检查点会存下来。
- 4 个结局都带 id。主要的鬼都有大头像：「东西」`ying`、阿添 `tian`、阿公 `akong`，一次通关里每张最多出现 2 次。
- 关键声音都用 `S.tone` 合成：锣、木鱼、法铃、唱腔和板鼓、灯灭的「噗」、心跳、白灯笼的铜铃、阿公的喊声、小孩的笑、鞭炮。
- 选章卡片：黑水上漂着三盏莲花灯，女孩背对镜头，头顶和两肩各亮一盏小灯。

下面 20 条是对照之后找出来的问题，都已经改好。

## 谜题
1. **选「先等等」后，不知道去哪找线索** → 目标提示会点名还没看过的线索：厅里的族谱、阿嬷床脚的木箱、庙里的石碑和签。
2. **烧纸画圈答错没有代价** → 每答错一次，黑地里伸出一只手抢走一沓纸钱，伴随闪光和低语。第 2 次提醒去看单子，第 3 次直接说出做法。
3. **名字写错时提示太笼统** → 按错法给针对性提示：写成阿公的名字、姓写成「陈」（阿嬷娘家的姓）、字辈写成「永」或「昌」（父辈、自己这一辈）、最后一个字写错，各有一句。

## 危险段
4. **阿公喊你的那段对话会吃掉倒计时，读得慢的人会在对话中途被「子时」打断** → 这段对话期间倒计时暂停。真人速度测试里，dawdle 策略原来就是这样输的。
5. **第一次撞上白灯笼后，那盏灯笼还停在身边，一抬脚就会撞第二次** → 撞到你的那盏灯笼顺着方向被推开 3 格，再给 1 秒缓冲。
6. **回头警告之后一直按着「下」，马上就会第二次回头** → 警告后 1.2 秒内按「下」，只会被扳回去，不算第二次回头。
7. **在家里灭光三盏灯，要从开场重来** → 拿到单子后存一个检查点 `home`。
8. **归途时间按真人速度实测重新调过** → 原先 42 秒，对话还吃时间：average 和 dawdle 都输，careful 只剩 7 秒。改成 28 秒，对话暂停计时，重来下限 22 秒。实测结果见文末。

## 联机
9. **归途目标提示太长，1280 宽的屏幕也会换行** → 缩短成「回家：等白灯笼过去再过田埂，莫回头、莫跑（一人盯灯笼喊「走」）」。
10. **写名字时，双人分工只写在目标里** → 写名字的键盘提示里也写明：另一个人可以在档案里翻族谱、照片和石碑。

## 叙事
11. **没跟阿峰说话的话，他整晚都站在家里院子里，同时又出现在庙口，结局时院子里还站着他** → 天黑时他自己去庙口集合，并补一句旁白：背心湿着就穿走了。
12. **阿嬷的单子一屏看不完** → 十条规矩每条压成一行，背面的三盏灯缩成一句。
13. **好结局里阿公和阿添一直没有同框** → 写下名字后，下游阿公那盏灯停在水面上打转，像在等；第三盏灯追上去，两盏碰了一下，并排漂走，镜头跟过去。

## 画面
14. **门口的纸灰圈像一个个橙色火盆** → 改成贴地的灰圈，只剩零星火星往上飘，光圈也调小调暗。
15. **孤棚顶上的供品、顺风旗和棚顶的孩子在镜头外** → 孤棚整体下移一格。调查孤棚时镜头会抬上去看一眼；第三声锣响后，镜头也会对准棚顶。
16. **抢孤开始时，玩家被直接瞬移到孤棚底下** → 加一个短黑场，配旁白「人群一拥而上，把你挤到了孤棚底下」。

## 结局
17. **读过阿公的本子却没写名字，「不写名的灯」结局里对此没有回应** → 结尾会根据读过的线索变化：读过本子、只读过族谱、什么都没看，各有一种结尾。
18. **「带回家」坏结局重来后，火盆旁边没有任何提醒** → 从 `back` 检查点重来时，如果身后还跟着「东西」，会提醒单子第十条和火盆的位置。

## 音效
19. **三声锣一模一样，听不出第三声就是「开抢」** → 第三声更响，带回音，后面跟着人群呐喊和一串鞭炮。
20. **白灯笼的铃声只按距离变响，听不出它离你还有多远** → 铃声越近摇得越急：间隔从 0.7 秒缩到 0.3 秒左右，音量同时变大。

## 测试结果
- 主线 `play.py zhongyuan`：`zhongyuan OK`，没有 ERRORS，也没有 REACH WARNINGS。走的是一条忌也不犯、读族谱和照片、写「林德添」的路线，结局是「送走所有人」。
- SOL 变体（放在 scratchpad 里，用同一个 Chromium 依次跑）全部 OK，没有错误：
  - `v1`：
    - 在家里晾背心、把筷子插在粥里，灭 2 盏灯，「东西」开始跟着你。
    - 在老街第一次踩灰圈只是警告，第二次踩灭掉最后一盏灯，死亡。从 `night` 重来后，灯数和「东西」都对得上。
    - 庙公点回一盏灯；捡铜钱又灭一盏。
    - 画圈答错 3 次后答对。
    - 第三盏灯先选「先等等」（前两盏已放），再选不写名。
    - 归途按「下」：第一次是警告，被扳回去。
    - 阿公喊你时回头，坏结局「回头」。重来后计时不少于 22 秒，喊声能重新触发。
