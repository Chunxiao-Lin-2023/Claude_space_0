# 第二十七夜 明天再来 · 自审 20 条（已全部实现）

## 谜题
1. **材料用光、还有门空着时毫无反馈**：玩家要到夜里才知道分错了 → 粉笔头和红漆都用完、仍有空门时，立刻一句内心独白点明「今晚怕是保不住每一家」；阿吉那边直接给最高一级提示，或在已经无解时劝你「重来一回先数清楚」。
2. **柱子写好后不知道两户都算了**：目标里的户数一下少二，但没人解释 → 写柱子成功时明说「站在哪一扇门前都看得见这两个字」。

## 联机
3. **分工只写了「一人念一人写」，没说作业本在哪儿看**：客机玩家找不到线索 → 写字的目标和键盘提示里都注明「J 打开作业本」。

## 危险段
4. **被她碰到就直接死**（违反「第一次警告、第二次才死」）→ 第一次被揪住辫子挣脱：推开两格、闪白、心跳，她停 1.6 秒；第二次才死。重来后复位。
5. **雨夜/宿舍她可能刷在玩家身边**：玩家提前跑到巷口或大门口时，她一出现就贴脸 → 出现前检查距离，4 格内就推迟出现，并提示「榕树底下有什么东西在动」。
6. **雨夜躲进屋以后要干等她走完整条巷子（约 40 秒）** → 玩家躲进屋后，她走得更快（2.6 格/秒）、每扇门只停 1.2 秒，门外的叫门小字也不再刷屏。
7. **雨夜还有字没保住就进屋，只能眼看坏结局发生** → 进屋前按「漆 / 遮好的油布」判断，还有危险就确认一次：「吉塔家、穆尼大爷家门上的字还在被雨冲。真的进屋？」
8. **宿舍停电后看不见她走到了哪一间** → 她敲哪扇门，那扇门的门牌就闪红光；她身上的冷光从 1.3 格加到 2 格。
9. **穆尼大爷起身走向门口时屋里很黑、没有声音**，而且玩家调查别的东西时他会停下（可被利用）→ 他身上加一圈弱光，每走一步拐杖「笃」一声（`S.tone`），离门三步时提示；剧本运行时也照样走，到门口用 `force` 打断对话。

## 叙事
10. **第二天早上的群戏有 14 页**（LESSONS 16）→ 压到 8 页：阿吉、吉塔、拉希姆、阿吉各一句，材料说明合并进一句。
11. **「她的脚是反着长的」只在偷看门缝时提一句** → 第三天清早，巷子泥地上留下一串脚尖朝着巷口的赤脚印（5 处，可调查），开场旁白点出。
12. **第三天去宿舍时手里常常一根粉笔都没有，「白粉笔写在白石灰墙上看不见」这一幕被跳过** → 接完电话，文卡特主动塞给你半截记账用的粉笔。
13. **第八天一进场就逼你选「擦不擦」** → 改成自由走动：阿吉、吉塔、拉希姆各说留不留，穆尼说拉朱来电话了，文卡特给第二份报纸，想好了再和阿妈说话做选择。

## 节奏
14. **第二天分错材料后重来，第二夜整段过场要从头看一遍** → 失败重来过以后，她走得快一些（3.4 格/秒），省掉第一次读字时的长描写。

## 氛围与音效
15. **她的敲门声就是普通的 knock 音效，木门和铁卷帘一个声** → 用 `S.tone` 合成：指节敲木门是闷、湿的三下，拉希姆的铁卷帘是哗啦啦的铁皮声；第一夜、第二夜、宿舍、雨夜、六号房、擦字结局全部换掉。
16. **雨夜只有雨声，巷子一片黑** → 每 8–14 秒一声合成雷，闪电时整条巷子亮 0.35 秒（`S.dark` 临时降到 .45），能借闪电看清她走到哪了。

## 画面
17. **油布遮住柱子后几乎看不出来** → 改成亮蓝色塑料布：上沿高光、褶子、四角麻绳结、几颗水珠。
18. **iPad 竖屏目标文字过长**（第二天目标 40 多字折成三行）→ 所有长目标缩到一行以内，例如「帮邻居写字（粉笔2·红漆1）还剩 5 户·卡住问阿吉」；768×1024 截图确认。

## bug
19. **第一夜傍晚，邻居说的是后面几天的台词**（相位判断只认 `eve`，实际相位是 `n1c/n1d`）：拉希姆说「谢谢你」、吉塔说「昨晚听见她念明天」、穆尼一声不吭 → 补上傍晚相位判断，各自有傍晚的台词。
20. **宿舍墙上随机生成的小窗户和门牌叠在一起** → 门所在的那几列不画窗户。

- 主线：`naleba OK`，无 ERRORS，无 REACH WARNINGS。
- 变体（scratchpad 脚本，按 SOL 前缀 + 真人按键模拟，键盘每键 520ms、选项 450ms）：

  - 第二天：粉笔头浪费在穆尼家门上 → 第二夜「有人开了门」（自家）；重来回到「day2」，材料与门上的字全部复位，阿吉提示升一级，按正解可过。粉笔写铁卷帘会打滑、不消耗。
