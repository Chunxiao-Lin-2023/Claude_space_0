# 第二夜「子取箱」（kotoribako）· 自审与优化 20 条

先按 SOL 通关一遍、拼图看了截图（含 iPad 竖屏的密码盘和笔记），再用真人速度的走路脚本跑了夜里抱箱子穿院子那段（站着不动、走主屋旁的近路、走参道往东、在出发点愣 1/2/3/4 秒），最后用 SOL 变体把每个坏结局、每种死亡和重来都走了一遍。下面 20 条全部已实现。

## 故事与传说
1. **天亮的时间和头班车对不上** —— 挂钟说头班车五点，叔叔却四点五十分就到了 → 天亮卡改成「五点四十分」，挂钟改成「五点零几分发车，开过来四十分钟」，叔叔进门补一句「头班车一到站就跑上来了」。
2. **「平成十七年当返」看不出就是今年** —— 隐藏结局要靠这一句，可游戏里只写了 2005 年 → 茶之间挂历印上「平成十七年（2005年）七月」。
3. **封好箱子以后，屋里的人没有任何反应** → 封箱成功时补一句「主屋那边的咳嗽声轻了下去」；之后再去澪门前，她说「肚子里那块冰化了一点……送过去的时候别从我窗户底下走」（顺带提示夜里的路线）。
4. **没读曾祖父手记的人，到结局都不知道「返」是什么** → 天亮时如果没读过手记，叔叔会用两句话讲清「百来年后拆开烧掉，叫『返』」。

## 谜题
5. **箱子没封好时没有持续的反馈** → 旧仓地图加 tick：没封好的箱子隔几秒低低嗡一声（S.tone），错开得越多越频繁、离得越近越响；封好以后安静。
6. **作业台上的箱子太小，看不出哪块错开** → 箱子精灵重画、放大到整格，左板上抬、右板下沉、顶盖右移露出黑缝都画成 2–3 像素的位移，和密码盘上的文字对得上。
7. **行礼答错没有代价，五下随便按** → 每错一次灭一支蜡烛（`off` 同步给客机，画面变暗）、唐柜里敲两声；提示三级：先指木牌 → 说出「二拜二拍手一拜」 → 直接给按法；行礼成功时把灭的蜡烛重新点上。
8. **封箱密码盘的文字太长，竖屏挤** → 七行状态压成三行（两块木板一行），标题和操作说明合成一行；iPad 竖屏（768×1024）截图确认 11 个键和状态都在一屏内。

## 危险段（夜里抱着箱子穿院子）
9. **小翔的速度按实测重调** —— 原来 2.6 格/秒、等 1.1 秒，愣 3 秒再走都赢得很轻松 → 起步 2.8、等 0.9 秒、每 4 秒加速 0.12（上限 3.3）。实测见文末。
10. **走主屋旁边的近路也能过** —— 原来警告后还要再靠近 1.6 秒才出事，从主屋西侧直插本殿照样能到 → 警告阈值 0.5 秒、警告后 0.6 秒出事；实测近路必死。
11. **第一次被追上就直接死** → 第一次让小翔贴到 1.7 格以内时，奶奶在窗户里大喊「小翔——！」，他停住 1.3 秒（气泡「？」+ 提示「快走开」）；第二次才会碰到箱子。
12. **黑暗里听不出小翔在哪** → 他走路时每步一声光脚踩石板的 S.tone，离得越近越响、越亮（音量和低通都随距离变）。
13. **「离主屋两格」看不见边界** → 进入主屋三格内，主屋的两扇亮窗开始一明一暗地闪（两格内闪得更快）；`lit`/`off` 都在 VKEYS 里，客机同步；重来时复位成常亮。

## 双人
14. **夜里那段没有分工** → 第一次出仓时说明：一个人抱着箱子走，另一个人在画面上点一下（ping）给对方标出小翔的位置；配合第 12、13 条的声音和窗光，看地图的人能报方位。（封箱时「一人看笺念《箱守帐》，一人推木板」原本就有。）

## 结局
15. **两条路线的「箱开了」给的是同一句提示** —— 守夜时拔木栓打开的，结尾却提示「封箱顺序与开箱相反」 → 按触发方式给不同的结尾提示（封箱时推到底 / 守夜时听了自己的声音）。
16. **守夜坏结局重来要把整段开场再看一遍** → 守夜重来时跳过「丑时」标题卡和第一段敲击描写，改成一句「谁叫都别开门，箱子怎么响都别打开」，直接进两次诱惑。

## 画面
17. **本殿的御帘被祭坛挡住，调查不到** → 御帘改成纯装饰，它后面的圆镜写进祭坛的描述里。
18. **院子里主屋窗户的描述和屋里房间对不上**（说窗里是澪的房间，可屋里澪的房间在走廊另一头） → 两扇窗改成「玄关边的窗」「澪和小翔都在这扇窗后面」，并编上 id 给第 13 条用。
19. **笔记和卡片文字溢出** → 《箱守帐》《曾祖父的手记》精炼到 1280×800 一屏看完（截图确认，竖屏也不用滚）；选章卡片的来源「日本网络怪谈（2ch）」会折行，改成「日本 2ch 怪谈」。

## Bug / 可玩性
20. **封箱推到「箱开了」以后，重来要从电话之后重新拿钥匙、盐、神酒** → 每次开始摆弄机关前存一次 `prep` 检查点，重来直接回到作业台前（箱子状态、已拿的物品都在）。

## 测试结果
- `python3 guaitan2/src/build.py --out guaitan2/.tmp_kotoribako/index.html --only kotoribako`
- `play.py kotoribako` → **`kotoribako OK`**，没有 ERRORS，没有 REACH WARNINGS（主线走隐藏结局「送还」）。
- SOL 变体（scratchpad）：
  - 封箱时往开的方向连推四下、确认「推开它」→ 坏结局「箱开了」；重来回到作业台前，箱子还是错开三块、木栓在手里，接着封好、通关。
  - 乱推三次 → 箱子自己往开的方向滑一格 + 惊吓头像，提示逐级出现，按第四级提示从「错开四块」封回去；小翔摸过箱子的分支；唐柜先放箱子（错一次）；行礼错两次（两支蜡烛依次灭）→ 第三次对 → 结局「天亮了」。
  - 夜里站着不动 → 奶奶喊住一次 → 被小翔碰到（「他碰到了箱子」）→ 重来回到旧仓、小翔隐藏；再出仓、贴着主屋站 → 先警告、再「离主屋太近了」→ 重来，窗户恢复常亮、小翔复位 → 送进本殿通关。
  - 守夜：掀盖拔木栓 → 「箱开了」；重来 → 开门 → 「门外的人」；重来 → 熬到天亮、不问 → 「天亮了」。四个结局全部记入收集。
- 真人速度（方向键驱动，玩家抱箱 3.57 格/秒，时间从出仓的旁白开始算）：
  - 站着不动：约 7.8 秒被碰到（中间被奶奶喊住一次）。
  - 走主屋西侧的近路：约 5.6 秒出事（主屋警告后很快倒下）。
  - 参道往南绕、再往东去本殿：11.5 秒进本殿，最近相距 5.0 格；愣 1 秒再走：相距 3.7 格；愣 2 秒：2.9 格；愣 3 秒：2.2 格，险过；愣 4 秒：被追上。
  - 截图看过：旧仓、院子（傍晚/夜里）、主屋、本殿、结局页、选章卡片、密码盘和笔记（1280×800 与 768×1024 竖屏）。
