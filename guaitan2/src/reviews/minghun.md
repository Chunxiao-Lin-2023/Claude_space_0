# 第十三夜 · 冥婚（minghun）自审 20 点

写完后先用 SOL 跑通主线，再对照 `LESSONS.md` 逐条自查（第 10 条本作不做），并写了一个按真人速度（Playwright 按住方向键）走纸人巡夜的机器人反复实测。下面 20 条全部已实现。

## 谜题
1. **没看通书就去了纸扎铺** —— 已实现：通书挂在阿嬷家墙上，不读也能往下走，到了工作台才发现缺线索 → 阿嬷讲完后把通书从墙上摘下来塞给你（没读过就当场打开），之后在「笺」里随时能翻。
2. **单人写庚帖时看不到线索** —— 已实现：密码盘打开后没法同时翻笔记 → 提笔前先问一句「提笔就写 / 先看一眼庚帖 / 通书 / 信」，只列已经拿到的笔记。
3. **每次写错都要把四格重填一遍** —— 已实现 → 写对的格子留在红纸上（陈松：「对的那几格，我给你留着」），下次只改写错的。提示还是逐级给：第 2 次给方向，第 3 次给具体位置，第 4 次直接说出答案。

## 危险段
4. **纸人走到巷尾掉头没有预警** —— 已实现：原来一到尽头当场转身 → 先停住、头顶冒「…」，0.45 秒后才僵硬地转过来，再过 0.65 秒才开始走。
5. **第一次出门不知道纸人看得多远** —— 已实现 → 开场镜头先对准东段那个纸人，说明「灯光往前照出四五步就是它看得见的地方；走到尽头会停一停再掉头」，灯笼的光也朝着它面对的方向打出去。
6. **计时太松** —— 已实现：机器人实测北路 13–15 秒、正街 12 秒、绕南路 33–49 秒 → 子时计时从 110 秒改为 80 秒；重来取剩余与 55 秒的较大者。
7. **巷子里没有方向感** —— 已实现 → 每 7 秒从林家那头传来一段喜乐（`S.tone` 合成），离林家大门越近越响。
8. **跑步被纸人听见但玩家不知道为什么它转身** —— 已实现 → 4 格内跑步时纸人转身并冒「?」，同时 toast「纸人听见了你的脚步声，转过身来」（5 秒内不重复）。
9. **第一次被发现的警告用的是内心独白** —— 已实现：独白要按键才关、计时还在走，警告反而害人 → 改成不打断走路的气泡 + 音效 + toast，给 2.4 秒离开它的正前方；第二次被发现才死。

## 双人与界面
10. **重来后不再提示双人分工** —— 已实现 → 每次从「巡夜」检查点重来，双人时都会再弹一次「一个盯着纸人的背影报方向，一个走」。
11. **巡夜目标提示太长** —— 已实现：二十多个字，iPad 竖屏挤 → 缩成「子时前把牌位送进林家大门（躲开灯笼，别跑）」，规则放进陈松的话和死后小结。

## 叙事与结局
12. **「红包认人」在三个地方重复** —— 已实现 → 林家厅里林伯那句改成「她的屋子在左边。你去看吧。我不进去」（进过闺房后是「屋里的东西，你看见了？」），只保留村口红姨那一处。
13. **报假八字只在喜帖里回应一句** —— 已实现 → 进林家时红姨当面拆穿：「骗得了我，骗不了红包。喜帖上写的是哪天，你自己看过了吧？」
14. **好结局里红姨没有交代** —— 已实现 → 礼成后红姨：「做了三十年媒，头一回让新娘自己挑。这一单，红姨不收钱了」，然后淡出。

## 氛围与画面
15. **天井里的纸人倒下后什么都没留下** —— 已实现 → 原地留下两张能调查的「纸人皮」（脸朝天、竹篾散了），各有一句描述。
16. **拜堂三声锣一模一样** —— 已实现 → `gong` 加音高参数，「一拜、二拜、对拜」三声一声比一声高，礼成接一串鞭炮；坏结局「拜了堂」同样处理。
17. **林家院子的灯笼不能调查** —— 已实现 → 两盏灯笼都补了描述（喜事的灯笼挂着丧事的纸钱；松记纸扎的金粉浆糊）。
18. **选章卡片 / 笔记 / 密码盘的显示** —— 已检查并调整：卡片是「红包 + 囍」缩略图加纸新娘（`iconX` 往右挪，不挡红包）；四张笔记和十二地支、六个日子的密码盘在 1280×800 和 iPad 竖屏（768×1024）都一屏显示完整。

## Bug
19. **扔掉红包后马上进阿嬷家** —— 已实现：红包要 2.5 秒后才回到口袋，进门时阿嬷却在问「你手里拿的什么」→ 进门时没有红包就当场还回来（「跨进门槛的时候，口袋忽然一沉」），延后的那段剧本用 `hbBack` 旗标避免重复。
20. **子时到点时人在纸扎铺里，文案却是「从四条巷子里飘过来」** —— 已实现 → 按所在地图分两种：在铺子里是「四个纸人挑着灯站在门口……陈松挡在你前面，被它们轻轻推开」。

## 需要引擎支持
- 无（全部用现有 API 完成）。纸人巡逻在地图 `tick` 里用 `startMove` 推进，状态放在 `e.s`，灯笼朝向每次换新的 `light` 对象，客机能同步。

## 测试结果
- `python3 guaitan2/src/build.py --out guaitan2/.tmp_minghun/index.html --only minghun`
- `play.py minghun` → **minghun OK**，没有 ERRORS，没有 REACH WARNINGS（主线：带上纸自行车、庚帖写错一次年份再写对、证据先选错一次、捧牌位拜堂 → 好结局「心上人」）。
- SOL 变体（scratchpad，一次跑完，最后到好结局）：绕开红包两次被迫捡起 / 报假八字 / 扔进垃圾桶（红包回来，只有一个）→ 灶膛烧红包 → 坏结局「烧了红包」→ 重来回到村口；没读通书时阿嬷塞给你；提前推门进林家 → 坏结局「拜了堂」→ 重来回阿嬷家（林家门已复位）；庚帖先翻笔记再连错四次（第 4 次陈松说出答案）；站到纸人正前方 → 先警告 → 留在原地 → 死 →（铺子里、检查点「sneak」、纸人复位、计时 ≥55 秒、无警告）；躲在岔巷干等 82 秒 → 子时到死 → 重来计时 55 秒；进门就跪 → 坏结局 → 重来回到「等一下」之前；证据选错两次；自己跪下 → 坏结局 → 重来从拜堂前 → 捧牌位 → 不带自行车的好结局。
- 真人速度（`fast=8` 只加速剧本等待，移动和计时是真实时间）：北路 14.7 秒到达、正街跟在纸人背后 11.6 秒到达、绕南路 33.2 秒到达，都没有被发现；沿正街一路跑 → 4.7 秒被抓；躲着不动 → 80 秒子时到死；出铺子后原地愣 6 秒 → 东段纸人掉头发现 → 被抓。
