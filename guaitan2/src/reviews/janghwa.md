# 第二十二夜 蔷花红莲（janghwa）· 自审 20 条

## 谜题
1. **已出示的证物不标记** → 升堂菜单里出示过的证物后缀「（已出示）」，减少重复误选。
2. **准备阶段卡住没方向** → 坐方席时按缺项给出具体位置（库房在西、吏房在东、衣架、书案上的册子）。
3. **嫁妆箱的门槛无提示** → 裴座首台词循环补一句「箱子锁着，钥匙贴身带着，没脸打开」，引向「给他看鞋」。

## 危险段
4. **灯灭后全黑，找不到灯和窗** → 撞开的窗漏一圈月光，灯芯留一点红光（S.lights，双方同步），关窗后红光还在。
5. **计时快到时没有紧迫感** → 剩 3.5 秒起心跳声。
6. **端坐段只有倒计时** → 水声随她靠近变响变密（按她的位置算音量和间隔）。
7. **计时没按真人速度调** → 键盘真人速度实测（愣 1.2 秒、每页读 0.9 秒）：灯 9→10 秒（剩约 4 秒），坐回 6→5 秒（用时约 2 秒）。
8. **死后提示千篇一律** → 按死法给提示：灯灭（窗在右上、灯在书案右）、没坐回、动了（手离开方向键）。

## 联机 / 状态
9. **「面对」检查点的目标是旧的** → stillDone 先设「她停在书案前——别喊，别跑」再存档。
10. **重来后丢了双人分工提示** → 夜里目标统一用 NIGHT_GOAL（一人盯窗和门，一人守灯）。

## 叙事
11. **她跪下时 face(0) 背对府使** → 删掉转向，她一直面朝书案。
12. **乳母说悄悄话没有压迫感** → 第一次和乳母说话时，大厅里的许氏转头看过来（「…」气泡）。
13. **隐藏结局没有任何暗示** → 不从轻发落时，开闸那一幕乳母说「老爷要是能来送送你们就好了」。

## 氛围 / 画面
14. **村民白衣白头巾，像鬼** → 改成土黄短褂草帽 / 绿衣妇人两种。
15. **升堂只有几个人，镜头只照着府使** → 门口加四个围观百姓，升堂时镜头对准院子（S.focus），退堂复位。
16. **东轩门口是个空洞，「门开着一条缝」看不见** → 门口加格子门实体（open 是 VKEY），水声进门时打开，天亮金吏房推门也开。

## 结局 / bug
17. **隐藏结局靠「自动压字条」，玩家不知道自己做了选择** → 碑前改成选择：把字条留给她们 / 收好存档。
18. **「一箱银子」重来后自动弹出同一问题（测试里默认项直接又收了一次）** → 重来后管事站在门口，调查他再答，重来的人有时间想。
19. **开闸后离开池塘再回来目标丢失** → 已开闸时进池塘只重设「在碑前上一炷香」，不重复播剧情。
20. **前任「面对」段落里，夺门而逃 / 喊人 / 骂她都走 S.die 但看不出是哪种** → scared() 记录死因（lastDeath），resume 按死因给提示（同 8，并确保重来时清空）。
