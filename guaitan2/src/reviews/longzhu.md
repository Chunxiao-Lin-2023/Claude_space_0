# 第十七夜 · 延安高架龙柱（longzhu）自审 20 点

写完后先按 SOL 跑通主线，再对照 `LESSONS.md` 逐条自查（第 10 条本作不做），用 SOL 变体跑了每个坏结局、每种死亡与重来，又用 Playwright 按住方向键的实时脚本（真人速度）跑了坑底请安。下面 20 条全部已实现。

## 谜题
1. **抄本用文言排行「长曰、次曰、三曰」**：目标提示说「下一个是老二」，要自己换算 → 每行前面注上「老大」「老二」……，原文句式在页首说明。
2. **石兽脚下的刻纹太小、在黑里看不清**：要逐个凑上去调查才知道刻的是什么 → 座子改成一块浅色石面、刻纹加深，九只石兽眼里各有一点幽绿的光，远远就看得见在哪。
3. **在坑里转悠很久请不对，没有人提醒**（只有请错才给提示）→ 低水期累计 45 秒没请对，老法师主动敲一下木鱼：第一次给方向（去抄本找名字和脾气），第二次给名字和脾气；请错的提示仍按 2/3/4 次逐级给（方向→名字与脾气→位置与刻纹）。
4. **结局抉择「刻在柱子上」缺铺垫**：答案像凭空冒出来 → 阿婆转述外公「庙拆了不怕，就怕没人记得」，老法师在庵里说「浜填了，庙拆了，就再没人记得它了」；选「重修龙王庙」时法师解释为什么不行，再问一遍。

## 危险段
5. **按真人速度实测，原来乱跑也输不了**：石兽多在高地上，只有过浜底时淹一下，而且对话时水不涨；「无视水情」的脚本一次没被抓就通关 → 五只岸上的石兽脚边塌成小水坑（请安必须站进去），水在插香、对话时照样涨（只是对话合上才判定抓脚）；浜底上加三处铺路钢板当桥；低水期 8 秒起、每请错一次缩短 0.8 秒（最短 5 秒），预警 2.4 秒、淹 5 秒；长香 240 秒，重来时取存档时剩余与 100 秒的较大者。数据见文末。
6. **老浜底和高地在黑里分不清**：两种泥地颜色太接近，不知道哪一溜先淹 → 老浜底换成专门的「浜底」瓦片（更黑、带水光），一眼看出那道斜沟。
7. **退水没有任何信号**：不知道什么时候能下浜底 → 退水时一声长长的「吸气」（`S.tone` 低频上扬），木鱼恢复慢拍；第一次退水 toast「这一阵，浜底能走」。
8. **第一次冒泡就可能被抓脚**：新手没见过预警 → 第一次预警加长到 3.4 秒，老法师头上冒「!」并喊「冒泡了——上铁板、上高地」；第一次被抓只丢一只胶鞋（警告），第二次才死。

## 叙事与结局
9. **老法师在庵里一口气讲 15 页**（另加两张笔记）→ 压到 10 页：童年看拆庙、「它就是那条浜」、要一个一个打招呼合成三页。
10. **阿婆的讲述 12 页** → 压到 8 页，保留「九个小囡守着门」这句名场面。
11. **开场打桩戏 12 页太拖** → 压到 8 页：一锤、回弹、红泥浆、三十一米二、管子里三声「当」，节奏更紧。
12. **档案没分清各类说法** → 分成【真实背景】【流传的说法】【有出处的说法】【查无实据】【游戏虚构】五段；不写任何真实当事人姓名，高僧只写「一位高僧」。

## 氛围与画面
13. **PM107 墩柱横穿火桶**：俯视下墩柱往上伸 5 格，盖梁正好压在老卞和火桶中间，像一根路灯 → 挪到西南角贴着围挡。
14. **坑底只有石兽，官方说法里的「老木桩」没出现** → 坑底加三截朽木桩（可调查，一截上刻着半个「龍」），和小沈说的「三十米往下全是老木桩」对上。
15. **选章卡片上的龙像一排梯子横档**：金色色块一条条平铺在柱子上，柱子还被卡片底栏截断 → 重画成桥面 + 粗柱，一条金龙沿螺旋绕柱盘上去（前半圈亮、后半圈暗），柱顶龙头对着一颗红珠，底下一排车灯。
16. **龙头浮出那一幕没有声音**：木鱼停了以后一片死寂，画面淡入就完了 → 加水声和一声很长的低频「出气」，再淡入龙头。

## 双人与界面
17. **目标提示太长，竖屏溢出**：「跟老卞说说（火桶边上）——也可以问问小沈和王经理」等 → 缩成「跟老卞说说（火桶边上）」，其余改成 toast。
18. **单人请安时看不到抄本**：选项里只有「插香/不动」，要关掉对话去「笺」里翻 → 请安选项里加「先翻翻抄本」，看完直接回到选项；双人时第一次冒泡的 toast 点明「一个盯水喊，一个念抄本」。

## Bug
19. **打好水以后阿婆还在讲「静水庵往西走」**：台词没跟上进度 → 拿到水以后换成「替我外公跟九个小囡讲一声」。
20. **被抓脚后会被挪到老法师站的那块铁板上**：「最近的铁板」只排除了钢管桩，没排除站着人的格子，玩家会和法师叠在一起、走不出来 → 改成只挑 `passable` 的铁板格。

## 测试结果
（最终构建 `guaitan2/.tmp_longzhu/index.html` 上跑的）
- **主线**：`play.py longzhu` → `longzhu OK`。没有 ERRORS，也没有 REACH WARNINGS。走的是「龙柱」好结局：三样龙王庙旧物都收齐（结局显示 3/3），请错一次，结尾先选一次「重修龙王庙」被驳回、再选「刻在柱子上」。
- **坏结局「擅自开挖」**：对王经理选「我来挖」→ 坏结局 → 重来，回到第二夜检查点（抓斗还在、王经理还没点头）→ 改选「等法师做完」后去爬抓斗 → 同一个坏结局 → 重来 → 正常下坑。
- **坏结局「什么也没还」**：请完九位后选「什么也给不了」→ 坏结局 → 重来，回到请完第八位的检查点 → 请老九、选「刻在柱子上」→ 好结局。
- **死亡①抓脚**：站在浜底时强制涨水 → 第一次只丢胶鞋，被挪到最近的空铁板（4,6）上 → 第二次被抓 → 惊吓大头像、死亡 → 重来：请过的 1 位还在，wet 清零，长香 237 秒（不低于 100），水位复原，喘气从低水期重新开始。
- **死亡②长香烧完**：剩余时间设为 0.3 秒 → 坑底全淹、死亡 → 重来：长香回到检查点时的剩余（≥100 秒），之后一路请完。
- **真人速度**（Playwright 按住方向键，每页对话读 0.7 秒，看见冒泡 0.5 秒后才反应）：
  - 守规矩（听见退水的「吸气」才下浜底，冒泡就上铁板）：187 秒请完九位，一次没被抓，长香剩约 50 秒 → **赢**。
  - 守规矩、中间请错一次：被抓一次（警告），179 秒请完 → **赢**。
  - 不管水情直接走：请到老三时被抓一次，19 秒后第二次被抓 → **死**。
  - 停在原地不动：240 秒后长香烧完 → **死**（变体②）。
- **画面**：截图拼起来看过：工地、弄堂、庵、坑底、涨水、龙头、三张笔记、选章卡片、惊吓大头像，横屏 1280×800 和 iPad 竖屏 820×1180 都看了，没有文字溢出，笔记一屏放得下。
