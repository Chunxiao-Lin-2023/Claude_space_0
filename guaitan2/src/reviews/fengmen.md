# 第十四夜 · 封门村（fengmen）自审 20 点

写完后先按 SOL 跑通主线，再对照 `LESSONS.md` 逐条自查（第 10 条本作不做），并用 Playwright 按住方向键的实时脚本（真人速度）跑了巷子里的巡游和「第三上」。下面 20 条全部已实现。

## 谜题
1. **「绕台一周」的「台」容易被当成院子里的戏台**：玩家会跑回戏台院子绕圈 → 一上之后第一次往北巷走，先提醒一句「村心那座石台也叫台」，把人拦回广场，不算走错、不重置。
2. **绕槐台没有进度感**：绕到一半不知道算不算 → 半圈时轻敲一声梆子，整圈两响加提示。
3. **敲错锣没有实际代价**：错了只多一句话 → 每错一次，台上的旦角真的往台口逼近一步、两盏灯笼一暗一亮；第三次起加红屏。提示仍按 2/3/4 次逐级给（方向→部分→答案）。
4. **「背着锣鼓声」只靠画面**：锣鼓音量是固定的 → 第三上时锣鼓音量随离南巷的远近变化，越往南越响，配合南巷的红灯笼，听也听得出方向。

## 危险段
5. **第三上的倒计时被对白吃掉**：`during` 计时里还要念三页对白，第一次几乎只剩 5 秒 → 对白（假搜救队、大刘、内心）念完再开始计 12 秒；死后重来不再念对白，只弹一句提示。
6. **巡游按真人速度实测调参**：原来 3 格内还在动就算犯规，实测「看见她在 4 格外才停」的脚本也会因为最后半步收不住脚而犯规 → 犯规距离改成 2 格（曼哈顿），6 格内心跳、唱腔变响；旦角 2.2 格/秒，警告后停 1.8 秒，第二次才死。
7. **旦角在黑巷子里太难看见**：光圈只有 2.4 格，拐角冒出来时已经在 3 格内 → 光圈加大到 3.2 格、颜色更亮；唱腔音量按距离变化，6 格内加心跳。
8. **第一次犯规只有一行字**：容易没注意到 → 犯规时她头上冒「!」、一声很响的梆子（`S.tone`）、白闪和轻震，并停 1.8 秒给你站住的机会，第二次才死。

## 叙事与结局
9. **相机那场戏太长**：发现相机到开戏共 14 页 → 压到 9 页（照片合并成三页，喊大刘与「他没有回头」合成一页）。
10. **好结局字太多，竖屏放不下** → 上山扫院子的大爷那段压成两小段，一屏看完。
11. **「GPS 乱跳」名场面只在帖子里**：→ 第一次鬼打墙时掏手机看导航，小蓝点往南挪着挪着「啪」地跳回村子正中间。
12. **旦角的名字只在照片背面出现一次**：结局里没人提起她 → 好结局里大爷说出「唱旦的叫秀芝」；照片没还的结局里，大刘说要「还给秀芝」。

## 氛围与画面
13. **夜里老槐树几乎看不见**：树冠和夜色同色 → 树冠调亮、加几处亮叶；入夜后树上的红布条泛一点暗红的光（实体光源，随检查点保存、同步给客机）。
14. **「出将」「入相」石柱夜里看不清**：它们是走戏路的关键标记 → 入夜后两块竖匾的金字反一点光。
15. **巷子夜里太黑**：暗度 .9，广场里连路都看不清 → 调到 .86。
16. **拉二胡的老人背对玩家、看不清**：对话后一直朝着玩家的方向，坐在暗处 → 身边加一盏油灯似的暖光，说完话转回去面朝广场拉琴。

## 双人与界面
17. **夜里目标提示太长，竖屏溢出**：「照戏本末场走出村子（第一上）· 唱腔近了就站住」→ 缩成「照戏本走出村子（第一上）」，「唱腔近了就站住」改成第一次入夜时的 toast 和老人的台词。
18. **单人敲锣时看不到锣鼓经**：密码盘打开就没法翻「笺」→ 敲之前多一个选项「先翻一遍戏本」，看完直接进密码盘；双人时 toast 提示一人念、一人敲。

## Bug
19. **对着巷子里的旦角按调查键会弹对白，让她停下**：可以用来卡住巡游 → 去掉她的调查处理。
20. **锣打对之后、扶起大刘之前，台口和锣架还按「开戏中」处理**：喊话会让已经不在台上的旦角「转过脸来」，锣架还能再敲一遍、重复触发下台剧情；拉二胡的还在说「台上那个下不来」→ 三处都按「锣已打完」分支。

## 需要引擎支持
- 无（全部用现有 API 完成）。

## 测试结果
- `python3 guaitan2/src/build.py --out guaitan2/.tmp_fengmen/index.html --only fengmen`
- `play.py fengmen` → **fengmen OK**，没有 ERRORS，没有 REACH WARNINGS（主线含：敲错一次锣、鬼打墙一次、还照片、三上背着锣鼓往北走 → 好结局「第十四夜　完」）。
- SOL 变体（scratchpad）全部按预期：
  - 坐太师椅后站起来 → 无事；坐着不起 → 坏结局「那把太师椅」→ 重来回到村口检查点；夜里再坐一次 → 坏结局 → 从 night 检查点重来（大刘仍跟随、巷子里旦角重新出现）→ 不还照片走完 → 结局「照片还在包里」。
  - 开戏后上台 → 坏结局「上了戏台」→ 重来回到 stage 检查点（旦角、大刘在台上，灯笼亮着）；没看戏本先敲锣两次 → 两级提示；喊大刘三次；敲错四次（提示逐级到答案、旦角每次逼近一步）→ 敲对；锣打完后台口、台阶、锣架、老人台词都按新分支。
  - 走戏路：一上不绕台就下场 → 重置；绕台途中往北巷走 → 提醒并拦回、不重置；二上不望井就下场 → 重置；三上往南走进锣鼓 → 死 →（rit 退回二下、计时清空、灯笼隐藏、旦角回巡游）；三上愣着 → 约 12 秒超时死 → 重来；三上往东 → 退回西头重新上场；最后往北 → 结局。
- 实时脚本（Playwright 按住方向键，`fast=8` 只加速对白，移动和计时是真实时间）：
  - 「看见她 5 格内就站住」的脚本：完整走完三上两下，0 次犯规，约 60–135 秒（取决于和巡游撞上几次）；三上对白念完后反应 1.5 秒再往北走，计时剩约 6 秒。
  - 「一直走、不停」的脚本 → 第一次警告后约 20 秒内被抓；「2 格内才停」的脚本 → 警告后同样被抓。
- 截图总览：四张地图的黄昏/夜里光照、戏台开戏、三上的南巷灯笼；四张笔记、密码盘、结局页在 1280×800 和 iPad 竖屏（768×1024）都完整显示（论坛帖压短后不再需要滚动）；选章卡片是戏台剪影 + 旦角头像。
