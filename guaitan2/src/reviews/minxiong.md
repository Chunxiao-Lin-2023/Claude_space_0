# 第十六夜 · 民雄鬼屋（minxiong）自审 20 点

我写完后先用 SOL 跑通了一次主线，然后对照 `LESSONS.md` 逐条自查（第 10 条本作不做），再补上本章特有的问题。另外写了一个按住方向键、真人速度的实时脚本，跑「那一夜」的巡夜段。下面 20 条都已实现。

## 谜题
1. **对照片可以乱点**：点错只多一句话，把所有东西点一遍就能过 → 点错的地方会在拍立得上晕开一块水渍，留在相纸上不消失。第 3 次点错起出雪花和低语。提示仍然按 2/3/4 次逐级给：先给方向，再给具体位置，最后用黄色虚线圈出来。
2. **步数的起点有歧义**：「后门往南八步」不清楚后门那一格算不算，「神明桌前退七步」也一样 → 背面的字改成「出了后门，往南走八步……」。两种数法落到的格子（C：8,9 / 8,10；B：9,9 / 9,10）都算对。只差一格时，取景框会提示「差一点点」。
3. **挖井只能靠看**：四团树根只能猜 → 拍完第三张后，后院里会有滴水声（`S.tone`）。离旧井越近越响，越近也滴得越急。
4. **拍摄点就在必经之路上**：第一张在石板路正中，第二张在大厅入口正上方，走着走着就自动对上了，等于不用读相簿 → 第一张改成「第五块石板，往左三步」，大厅入口挪到右边。现在只有照着背面的字数，才能走到拍摄点。

## 危险段
5. **一冲就能赢**：头家娘原本从西厢出发，开场直奔后门三秒就到 → 改成她一开始就守在东厢后门口，然后巡出来、绕去西厢再回来。必须等她走远才过得去。
6. **被听见后的提示是错的**：toast 说「站住别动」，可她会径直走到你站的地方 → 改成「她正往你这边走——快绕开她的灯笼」。她走到声音那里张望 1.4 秒，再回去巡逻。
7. **不能奔跑没有交代** → 开场加一句提示「木头地板，一跑就响」。
8. **第一次被抓住后，她瞬移到远处**：这样既突兀，又顺手把路清空了。冲第二次就过了 → 改成灯笼一灭，你在黑暗里跌跌撞撞跑回神明桌旁，她留在原处。如果她离神明桌太近，就回到后门口，免得一亮灯又抓住你。第二次被抓才死。
9. **巡夜段没实测过** → 用实时脚本按住方向键，试了 5 种走法（结果见文末）。冲过去、太早走都会先被警告、再被抓死。等灯笼去了西厢再走能过。走得太晚刚好擦边过。

## 叙事与结局
10. **阿婆第一次说话 13 页** → 压到 7 页：传说版本两页，「第三下」的禁忌两页。
11. **阿婆之后每次都重复「第三下」**，同一件事在阿婆、场记单、井边讲了好几遍 → 只有在挖井阶段才提一次。
12. **隐藏细节没有引导**：三张老照片里都有小时候的阿嬷，玩家不知道该找 → 第一次认出阿嬷时，心里多一句「别的照片里会不会也有她？」。三张都认出来后有一句总结，好结局也多一段。
13. **头家娘这条线没收尾** → 好结局补一句：从那以后，夜里再也没人听见大厅里的木屐声和「镯仔」。

## 氛围与画面
14. **照片里的榕树根像一格一格的黑方块** → 照片版的树根改成画在泥土上的根须。
15. **老照片里的大厅地面和现在一样脏** → 老照片改用干净的磨石子。
16. **老照片的山墙、拍立得里的大榕树冒出相框** → 全部收进框里。
17. **拍完大厅以后，墙上的全家福还是原样**：拍立得里头家娘的脸被刮掉了，现实里却没有 → 拍完后，现实中那张全家福上她的脸也被刮掉了（`e.s.scr`）。大厅两扇窗另外加了微弱的月光。
18. **开场看不到洋楼**：镜头停在马路上，旁白却在描写房子 → 开场镜头先移到洋楼（`S.focus`），带出「二楼正中间那扇窗，玻璃破了一个洞」，再回到玩家身上。

## 双人与界面
19. **iPad 竖屏看不到两张照片**：横排的对照图有 20 格宽，竖屏只放得下 12 格，只能来回走着比 → 竖屏时改用上下排的对照图（老照片在上、拍立得在下，正好 16 行，一屏放得下）。目标提示和井边的三个选项也都压短了，竖屏不会溢出。

## Bug
20. **没跟阿婆说过话，阿哲在井边也说「阿婆讲的——第三下」** → 按玩家实际知道的内容分三种说法：听过阿婆的话、读过场记单、两样都没有。

## 测试结果
- 主线 `play.py minxiong` → `minxiong OK`，没有 ERRORS，也没有 REACH WARNINGS。
- SOL 变体（scratchpad）：
  - `shutter`：连按三下快门 → 坏结局「第三下快门」→ 从检查点重来，井、阿春、`done` 都正确复位。按到第三下前收手，再放下照片 → 好结局。
  - `jade`：只放照片 → 坏结局「镯子带走了」→ 重来后镯子还在身上 → 好结局。
  - `death`：第一次被抓给警告，第二次被抓死亡 → 重来后头家娘回到后门口，`nWarn` 清零，禁跑、目标都复位 → 逃出 → 好结局。
  - `hints`：对照片点错 4 次，水渍出现，第 4 次出现黄色虚线圈 → 通过。
  - `dig`：挖错 3 次，提示逐级给出 → 挖对 → 好结局。
  - `portrait`（768×1024）：全程走竖排对照图 → 好结局。
- 真人速度（实时按键，fast 不影响巡夜）：rush → 警告，再冲 → 死；early → 警告 → 死；late → 擦边逃出；smart / smart2 → 逃出（17–21 秒）。
