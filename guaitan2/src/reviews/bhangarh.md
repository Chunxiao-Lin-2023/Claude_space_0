# 第二十八夜 巴恩加尔古堡（bhangarh）· 自审 20 点

先按 LESSONS.md 逐条对照（第 10 条投票本作不做）：

- **谜题**（香油巷五家铺子，哪家是瓶子「出来的地方」）：
  - 线索要拼三处：白天画的速写本（从宫殿那头数，五家门楣分别是孔雀、鱼、莲花、大象、新月）、宫殿地上的侍女采买单（飞的、游的、开在水上的都不进），还有寝宫壁龛里的瓶底印（一头往里卷的弧，新月两头尖）。答案是从宫殿那头数第四家，大象。
  - 认错的代价：掌柜转头，第一次出大头像，之后红闪；影子里还会站起来一个人找你（离你 4–7 格，有 1.2 秒预警）。
  - 认错时按错法给针对性提示（孔雀会飞、鱼会游……）。提示逐级升：方向 → 采买单 → 瓶底印 → 直接说第四家。白天没画速写本也能玩：夜里可以掀帘子看门楣，但每掀一次都会惊动人。
  - 双人：目标提示和一次小字提示里写明「一个人翻日志里的速写本和采买单，一个人去铺子」。
- **危险段**：
  - 夜里的「月影」潜行：城里的人只能走在影子里。云遮月时，整条街只剩灯底下是安全的。在影子里走、跑、站着不动，被发现的距离各不相同。
  - 天亮前的逃跑：倒计时用 `during`。集市中间塌了，要绕路。
  - 每段开始前先设目标、再存检查点（`night` 每次进集市或宫殿都存，`run` 在宫殿，`run2` 在集市）。
  - 重来时复位城里的人、云、计时（取死时剩余与下限 24/18 秒中较大的那个，但不超过存档时的值）、周屿的位置和跟随状态。
  - 第一次被抓只是警告，红线还能多挡一次。死过以后，重来时给一句规则小结。
- **状态**：
  - 铺子灯、布棚和颜色用 VKEYS 里的 `lit/off/col`。掀帘、放瓶、巫师亭子被压塌、石头上的油、影子前沿、云、小天空都放在 `e.s`。城门洞变黑用 `lit`，太阳下沉用 `oy`。
  - 走动判定一律用 `S.moving/S.running`。城里的人的状态机是只在主机 tick 里用的瞬时量，重来时在 `resume` 里复位。
- **结局**（4 个，都带 id）：好结局 `dawn`（日出时站在城外）；坏结局 `oil`（带着小陶瓶出城门）、`charm`（把油抹在手腕上）、`stay`（天亮时还在城里）。
  - 好结局的结尾会按几件事改写：早到拿没拿到红线、红线用没用掉、夜里拜没拜苦行僧、白天画没画门楣、闻没闻过那瓶油。
- **大头像**：巫师 `singhia` 用 3 次（山顶回头、石头压下去、坏结局），城里的人 `ghost` 用 3 次（被抓、第一次认错、逃跑时被抓）。
- **合成音**：纳格拉鼓、侍女脚铃、海螺号、守门人的哨子、叶猴叫、山上的念咒、神龛小铃、滴油、石头滚动的闷响、车喇叭。
- **选章卡片**：夕阳下的古堡剪影，一道长影一直伸到白色小屋脚下，旁边是蓝色告示牌。

下面 20 条是对照之后找出来的问题，都已经改好。

## 谜题
1. **瓶底印和采买单的结论看过一遍就忘，瓶底印还只在对话里出现** → 看过以后，结论写进右上角的目标提示：「不进飞的、游的、开在水上的；瓶底印：一头往里卷的弧」。
2. **不认错就永远拿不到提示，在铺子前犹豫的人会一直卡住** → 在铺子前选「先不动」也算一次犹豫。每犹豫两次，提示升一级。
3. **只读了采买单的人以为线索够了，会在大象和新月之间瞎蒙** → 读完采买单，如果还没看过壁龛，林禾会想到「瓶子原来放在这间屋的壁龛里，会不会还留着印」。
4. **门楣上的「鱼」只是两道横杠，看不出是鱼** → 重画成两条头对头、带分叉尾鳍的鱼。其余四个浮雕也对照截图确认过能认出来。

## 日影计时
5. **太阳和月亮画在地图最上面一行，平时在镜头外，看不出还剩多少时间，也看不出云要来了** → 右上角加一块小天空（加了光源，夜里也看得清）。白天是山脊、一列「指」刻度和慢慢下沉的太阳；夜里起风时云开始盖过月亮，遮住后全黑；逃跑时东边的天一点点亮起来。
6. **实测时间太松：真人速度的机器人走完整条路线（画门楣、读木牌）还剩 42 分钟，直奔周屿还剩 58 分钟（共 80）** → 总时长 80 改成 66 分钟。现在完整路线还剩约 28 分钟，直奔约 44 分钟。把下面的神庙、阶梯井、舞女宅子都逛一遍再回去，就会刚好赶不上。
7. **读木牌、画门楣、跟周屿说话都会扣时间，可玩家感觉不到** → 扣 3 分钟以上时小字提示「影子又往前爬了一截」，快来不及时换成更急的说法。
8. **迟到的玩家不知道自己错过了什么** → 天黑时补一句「……晚了。要是太阳落山前回到城门口就好了」。苏雷什没来得及说的规矩，夜里苦行僧的油灯会补上。

## 月影潜行
9. **实测太容易：沿街直走 5/5 都能过；宫殿的影子窄，发现距离小，追得也慢** → 宫殿的影子从 x≤4 扩到 x≤6，榕树影从 31–37 扩到 30–38。发现距离：走 4.5 格、跑 7 格、站着 1.5 格，云下再加 1.5。预警 0.85 秒改成 0.6 秒，追速改成 3.4（云下 3.8），宫殿影子里巡逻的人速度 2.2。实测：月下直走每次都会被发现，但能走脱；不理起风提示、云遮月时还在街上走，4/4 死；照规矩先到灯下、绕南边院子、等巡逻的人走远再过，4/4 过。
10. **没拿到红线的玩家，第一次被碰到就死** → 第一次被抓只是警告：挣脱，2.5 秒内不会再被抓，并提示「离开影子」。第二次才死。逃跑时同样宽限一次。

## 天亮前的逃跑
11. **两条绕路都有人堵在一格宽的口子上，实测 8/9 死；时间又太松，跑完还剩 23 秒** → 追的人改到身后、两侧和开阔的院子里，不刷在一格宽的口子上。时长 38 秒改成 32 秒，重来的下限 24/18 秒。实测（会躲人的机器人）：跑着走南院剩约 16 秒，走着走南院剩约 4 秒，不躲人直冲会被抓。
12. **北边的小巷只有一格宽，对谁都是死路，提示却说可以走** → 夜里拜过苦行僧的人，跑的时候城里的人不敢进他小屋那边的小巷（隐藏细节，实测 2/2 过）。没拜过的人，提示改成「走南边院子，北边小巷太窄」。
13. **逃跑时画面还是月影的明暗，可规则已经变成「哪儿都能追」** → 跑的时候灯全灭，整条街一样黑，只有城门那头亮。天色随倒计时慢慢变亮。

## 叙事
14. **迟到的玩家没听过「日出那一刻要站在城外」，跑的时候林禾却在引用这句话** → 按她听谁说过换台词：苏雷什、苦行僧，或者公主那句「别让太阳在城里找到你」。
15. **公主泼完油，城里的人为什么还追你，没有交代** → 跑之前补一段：满城的灯一盏接一盏灭了，没有脸的人全都转过身来——巫师的咒还在，城里的人一个都不许走。
16. **从周屿攥着的手心里拿瓶子，旁白却说「你捡起那个小陶瓶」** → 按瓶子从哪儿来换说法。

## 状态与 bug
17. **重来以后，周屿回到了白天的位置，宫殿出口的机关也挪了格，出不去（`oil` 变体实测卡死）** → 原因是检查点按地图、按下标恢复没有 id 的实体，而周屿被 `moveTo` 搬过以后，宫殿实体的顺序变了。现在给每个实体都编上 id；每个 `resume` 里再按阶段把周屿摆回去（夜里在露台，逃跑时跟着你）。
18. **坏结局重来后，目标提示会一直停在「捡起地上的小陶瓶」** → 捡起瓶子时统一更新目标。另外，拿瓶子之前先存一次检查点：`charm` 坏结局重来后，瓶子还在地上，可以重新捡。
19. **过场镜头移开时（天黑那一下对准苦行僧的小屋），影子图层的锚点还在玩家身上，被裁掉，影子会闪没** → 锚点每帧跟着镜头中心走，过场里也更新。

## 画面与结局
20. **「带出城」坏结局只有走回城门才会碰到，迟到的玩家几乎遇不到；开场镜头也看不到城门** → 夜里拿着瓶子走到集市东头时，城门那边会传来两声车喇叭，把人引过去。地图上方补了两行天空，开场旁白时镜头对准城门和告示牌。

## 测试结果（改完后完整验证一遍）
- 主线 `play.py bhangarh`：`bhangarh OK`，没有 ERRORS，没有 REACH WARNINGS。
- 变体（scratchpad，不进仓库），7/7 通过：
  - `oil`：带出城的坏结局，重来后继续走到好结局。
  - `charm`：坏结局，重来后瓶子还在地上，捡起后目标正确。
  - `stay`：天亮时还在城里的坏结局。重来时计时取下限，周屿跟着；之后走到好结局。
  - `catch`：夜里被抓三次：红线挡一次、宽限一次、第三次死。重来后城里的人和目标都复位。
  - `runcatch`：逃跑时宽限一次，第二次死。重来后从集市检查点继续，计时不低于下限。
  - `late`：在集市里天黑、周屿跟着、没画速写本，靠掀帘看门楣解谜。
  - `late2`：在宫殿里天黑、没找到周屿，从他手里拿瓶子。
- 真人速度机器人：
  - 白天：完整路线剩约 28 分钟，直奔剩约 44 分钟（总 66）。
  - 夜里：照规矩走 4/4 过；云遮月时还在街上走 4/4 死；月下直走能过，但每次都被发现。
  - 逃跑：跑着躲人剩约 16 秒，走着躲人剩约 4 秒，不躲人会被抓。北边小巷没拜过苦行僧 2/2 死，拜过 2/2 过。
