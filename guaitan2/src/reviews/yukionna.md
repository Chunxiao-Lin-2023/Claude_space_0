# 第七夜 雪女（yukionna）· 自审 20 点

先按 LESSONS.md 逐条对照（第 10 条投票本作不做）：
- 谜题有代价、有逐级提示，线索都在笺里。
- 危险段前都存了检查点，复位完整。
- `S.moving` 判定玩家走动；状态放在 VKEYS 或 `e.s` 里。
- 4 个结局都带 id。
- `faces.yuki` 全章只用 2 次（雪女俯身、说破）。
- 关键音效都用 `S.tone` 合成。
- 选章卡片是雪女头像加飘雪。

下面 20 条是对照之后找出并已实现的问题。

## 谜题（六地藏找钥匙）
1. **拂错地藏的提示不分错法** → 茂作先按错法说一句：戴着斗笠的说「这尊戴着呢」，被风刮掉斗笠的说「它本来戴着」。之后再按次数逐级提示：第 2 次给方向、第 3 次给具体特征、第 4 次直接报出「左数第几尊」。
2. **没读留守书也能乱拂雪** → 读过门上的留守书之前只能看、不能拂，茂作会提醒先去看门上的木板。
3. **乱试成本太低** → 拂雪的代价递增（体温 −10 / −14 / −18 …），确认框里写明代价。

## 危险段（前半夜守火）
4. **门开着是看不见的陷阱** → 门被白风撞开时（`f.blown`）给出明确目标「风把门撞开了——去把门关上」。门开超过 4 秒，茂作会喊一声。
5. **在屋外看不到火还剩多少** → 体温条上方加一道火苗刻度（`e.s.fi`，同步给客机），抱柴途中也能判断该不该往回赶。
6. **塞满墙缝再挨着茂作坐，没火也不掉温，可以缩着熬过去** → 没火时每秒至少掉 0.8。实测：一直待在火边不动，58 秒冻死。
7. **生火前冻死重来，体温可能已经很低** → `resume.hut` 和 `resume.arrive` 重来时体温分别不低于 60 和 70。
8. **怀里已有两捆柴还能劈船桨，超出携带上限** → 怀里满了先提示「先把柴添进地炉」。

## 画面
9. **雪花落在雪地上看不见** → 每片雪花加一像素灰蓝阴影；起白风时拉成斜线，数量加倍。
10. **黄昏和深夜一个颜色** → 第一幕暗色偏灰（黄昏），点火以后改用更深的蓝黑，黑暗度从 .8 提到 .87。颜色由 WX 实体的 `s.dk` 同步。
11. **雪女大头像的眼睛是两条黑带，黑发在黑底上看不出轮廓，像面具** → 眼睛重画：上眼睑、泛青的眼白、针尖瞳孔，先闭后睁。加了吹到脸前的发丝，发梢一圈冷光勾出轮廓。

## 音效与氛围
12. **屋里有火时只有环境声，没有层次** → 地炉每 2.5–4.5 秒噼啪一声（`TONE.crackle`），在火边响、离远了轻。

## 叙事
13. **茂作之死只在卡片里一句带过** → 雪女走后加一拍告别：把蓑衣盖到老爹下巴。按身上有没有披蓑衣分两种写法。
14. **真结局的「三件小事」做了两件后没有反馈** → 做到两件时内心独白轻推一下：读过娘的字条是「还差一样」，没读过是「还有什么没替她做」。

## 结局
15. **「守住了约定」和真结局区别不明显** → 守约结局按做了几件小事加一句结尾：「天窗、凉水、埋火——娘留下的话，你做到了一 / 两样。」暗示还有另一个结局。
16. **「一池温水」来得太突然** → 坚持让她先洗之前，加一句内心独白：听过阿松婆婆的冰柱媳妇故事就想起它，没听过就是「她总是最后一个洗」。之后才是二次确认。

## 双人
17. **屏息段和第四幕没有联机提示** → 屏息段目标加「联机：操作的人别碰方向键」。第四幕目标加「一人翻『笺』念娘留下的话，一人照着做」。（第一幕的留守书、前半夜守火出门，开写时就有分工提示。）

## Bug / 体验
18. **夜里目标提示随火势来回切换，toast 刷屏** → 去掉「怀里有柴」一档（改由体温条上的木棍图标表示）。「火快灭了」加回差（<25 进、>40 出），每趟抱柴最多两条提示。
19. **第一幕冻死重来后得重读留守书才能拂雪**（变体测出）→ 读完留守书立刻存 `arrive` 检查点。
20. **开锁后的门要先撞一下才开，走开后关上的门又挡住路**（自动测试也报可达性警告）→ 开锁后门不再挡路：走上门槛自动拉开，离开两格自动合上。只有被白风撞开的门需要人去关，站在门槛上不能关。

## 测试结果（第二步结束时完整跑一次）
- 主线（真结局「不说出口的话」）：`yukionna OK`，无 ERRORS，无 REACH WARNINGS。
- 变体（scratchpad，不进仓库），全部 OK：
  - `die_arrive`：第一幕冻死后重来，体温 ≥70、留守书已读、能直接拿到钥匙。
  - `die_night`：前半夜冻死后重来，计时 >95 秒，体温 ≥80，火 ≥50，白风已清，抱柴添火正常。
  - `gust`：屋外白风中，过了反应时间还在走，被吹一口气（第一次是警告，体温 −24）；屋里白风撞开门、窗外出现白脸，关门后状态清除。
  - `die_hold`：屏息时动第一次警告，第二次死；重来回到屏息，倒计时重新开始，玩家仍是躺着的外观。
  - `told_kids`：给孩子讲那一夜 → 坏结局「说出了那晚」；重来回到讲故事，改讲笠地藏后能继续。
  - `told_lamp`：行灯下说出来（原著结局）；重来后阿雪的外观、行灯都复原，改选后进入守约结局。
  - `melt`：坚持让她先洗 → 坏结局「一池温水」；重来后浴桶和阿雪复原。
  - `kept`：只做两件小事 → 好结局「守住了约定」。
- 真人速度（键盘逐格走，遇白风 0.35 秒反应）：
  - A（一直待在火边不动）：58 秒冻死。
  - B（按规矩抱柴，披蓑衣）：熬过前半夜，体温最低约 48。
  - C（不理会白风，不披蓑衣）：两次跑出来，一次体温最低 6.6，另一次被吹 2 口气，压线过关。
  - D（等火灭了才去抱柴）：体温最低 16，压线过关。
