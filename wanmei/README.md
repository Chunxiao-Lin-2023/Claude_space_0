# 完美世界 · 石村篇（试玩）

根据辰东《完美世界》改编的双人像素剧情 RPG（同人，非商业）。

- 单人：神兽伙伴由 AI 跟随。双人联机：房主扮演小不点，另一位扮演神兽伙伴（绒灵 → 青鳞鹰 → 朱厌……，和小不点每个阶段的伙伴同种族）。
- 星露谷式分区地图：石村、山林、石林（崖顶梧木巢）、莽牛坡、山林较深处，从路口走过去换图。
- 操作：WASD 移动（也可点击地面走过去），J 普攻，1–5 技能，Shift 闪避，空格跳，F 交互，B 背包，K 技能，L 任务，M 地图，C 角色。

## 开发

源码在 `src/`，`python3 build.py` 生成 `src/out/index.html`，复制到本文件夹的 `index.html`。开发守则和必跑测试见 [`src/RULES.md`](src/RULES.md)。本地存储前缀 `wanmei.`。
