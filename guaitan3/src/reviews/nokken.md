# 第二十六夜　水妖奈克 · 自审 20 条（已全部实现）

## 叙事
1. **开场一口气 16 页对话（醒来、外婆四条规矩、「你怎么知道这么多」）** → 合并成 10 页：琴声与空床两段旁白，外婆的规矩压成三句短话，删掉多余的问答。
2. **「他问你回」在外婆、奈克、佩尔的信三处各讲一遍** → 外婆只说一句「他问，你就得回」；佩尔的信只留「照着水尺的影子回」；完整的规矩由奈克在溪边亲口说。
3. **卡琳从头到尾一声不吭，答对外公的《摇篮曲》也毫无反应** → 答对第一句时她脚步一慢，迷迷糊糊地低声叫一句「……外公？」，然后接着转。
4. **时间不对：后半夜一点多就写「天边发白了」、好结局写「天亮的时候回了家」（八月底的韦姆兰五点多才日出）** → 改成「东边的天还黑着，雾已经开始散了」「那天后半夜，你背着卡琳回了家」；只有坏结局「跳到天亮」真的到天亮。

## 谜题（回琴石）
5. **第二句误输入第一句的答案（3567）只得到一句「不对」** → 针对性回应「那是《摇篮曲》的回法。这一句，是我的」（另有学舌、照搬琴谱的岸上答法、前后倒拉、只错第一个音等专门回应）。
6. **打开琴盘时看不到他刚拉的是什么，只能退出来重听** → 琴盘提示里加一行他那一句的听感（「四个音，一个比一个低」/「头一个音高得刺耳，后三个落下去又往上挑」），不给数字。

## 危险段（追溪马）
7. **「它看见你在前头就掉头」没有任何画面预兆，玩家以为它在随机乱走** → 掉头时头顶冒「!」并打一声响鼻，第一次掉头弹提示「从后面追」。
8. **马背变长只在开头演示，追逐中看不出时间在流逝** → 计时每过四分之一，马背长一截（背上多一个淡淡的孩子影子），配一声木头撑开的「吱」声和提示「马背又长了一截……」。
9. **镜头跟着玩家，溪马走出画面后完全不知道它在哪** → 蹄声音量随距离变化（远轻近响，最低 25%），看不见也能听出远近。
10. **在它前头跑会被直接撞上，撞之前毫无预兆** → 受惊冲过来之前先人立而起 0.35 秒（停顿 + 嘶鸣 + 「!」），给反应时间；冲撞期间一格以内都算撞上。

## 画面
11. **答错时卡琳「往深处挪」只是往下错几个像素，看起来像站到了岸上** → 加一层盖住她双腿的水面，水位随答错次数从脚踝涨到膝盖、再到腰；答对后退回脚踝。
12. **外婆「守着炭火坐了一晚上」，画面上却是站着** → 给她加一把会轻轻摇的摇椅，画在她身后。
13. **雾里的白马放在篱笆外的桦树丛里，镜头根本拍不到** → 挪到界石旁的空草地 (22,9)，从磨坊出来时就在画面里。
14. **奈克坐在石头上拉琴，人却一动不动** → 问答阶段他的手臂随弓子来回摆（交替走路帧），说话时也不停。

## 声音
15. **你回的琴和他拉的琴音色一模一样，分不清是谁** → 你的琴用三角波、更亮更响（新换的E弦）；他的是锯齿波，低通更「湿」。
16. **水塘里那双眼睛睁开时没有声音** → 加两声往下沉的低沉水泡声，再接惊吓大头像。

## 结局
17. **「半瓶酒」结局和好结局只差最后一段，奈克的话也几乎一样** → 半瓶酒线奈克多说一段：外公十九岁时口袋里只有半瓶酒的钱，后来常坐在磨坊里拉给水听，「拉得不好，可我每回都听完了」，和外公琴谱最后一页呼应。
18. **没读过圣经的玩家永远看不到隐藏的「我能得救吗」一问，也没有任何引导** → 外婆在读过琴谱、问过地窖之后补一句：桌上圣经扉页有太姥姥写的几句话，出门前念一遍。

## Bug
19. **地窖盖板第一次调查被无故挡回一句描述，第二次才问要不要下去** → 直接询问（描述并进问题里）。
20. **屋里、草场、溪边的远处琴声共用一个计时器，切图后可能立刻连响两遍、和进场剧情叠在一起** → 每次进图把计时重置为 3 秒。
