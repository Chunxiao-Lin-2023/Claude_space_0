# 第十七夜 魔王（erlkonig）· 自审 20 点

## 谜题
1. **错路提示按错法给**：第一次走错只有一句笼统的「到底是什么」→ 四条错路各配一句针对性的回想（雾→沼泽、黄灯→鬼火、亮水→最深、紫花→烂泥滩），第 2–4 次再走方向 / 位置 / 答案三级提示。
2. **岔路描述写进目标栏**：卢卡斯的三条描述只在对话和 toast 里一闪，翻笺对照时要靠记忆 → 目标栏直接写「左（上）：…／前：…／右（下）：…（J 翻笺对照）」，读笺的人对着它就能推理。
3. **路口原地「再问」能无限刷满清醒时间**：站在岔路口狂按调查键，计时形同虚设 → 再问只复述描述；只有卢卡斯真犯困（≤35 秒）时，说话才加时间，和路上的规则一致。

## 危险段
4. **抓手之后最后一段毫无压力**：实测抓手时女儿们落后约 8 格，最后 8 格稳赢 → 抓手戏结束后把她们拉到身后 5–6 格再追，并提示「她们又追上来了」（实测跑步仍能赢）。
5. **桥上开跑没有起跑信号**：对话一关女儿们就开追，玩家容易愣住 → 加三声马蹄刨地的 S.tone 起拍，和 1 秒预警同步。
6. **在雾里兜圈子没有长远代价**：走错只扣清醒时间 → 两个路口累计走错 2 次 / 4 次，女儿们早出发 0.2 / 0.4 秒，桥头旁白点明「她们比你想的还近」（实测走错 6 次仍能赢）。
7. **犯困见底只有心跳**：最后 15 秒容易错过 → 15 秒时远处飘来一段女儿们的摇篮曲，8 秒时再 toast 警告一次；马背上的孩子精灵也随之垂头、闭眼。

## 双人
8. **分工只写在一处**：双人时谁看笺谁骑马不明确 → 岔路口描述完、联机时 toast「一个人按 J 翻笺对照，一个人骑马」；单人时改为提示可以再问卢卡斯。

## 叙事与传说
9. **开场缺了第一节的后半**：只有「是谁在夜风里骑行」→ 开场卡补上「他把男孩搂在臂弯里，抱得稳稳的，暖暖的」，原诗第一节完整出现。
10. **父亲的名字没交代**：对话框里突然出现「马丁」→ 格蕾特婆婆第一句就叫他的名字。
11. **歌单笔记超过一屏**：八节诗加说明要滑动 → 每节压成一到两行，魔王的台词标出说话人，1280×800 下基本一屏读完。
12. **原诗结局的触发不透明**：一路回答「那是雾 / 风 / 柳树」没有任何回响 → 第二次否认时，婆婆的第二条规矩在耳边响一遍，给想避开原诗结局的人一个提醒。

## 结局
13. **隐藏细节太少**：只有木马一条 → 读过床头那张画（「爸爸看不见他」）的人，好结局里会在画背面添一行「爸爸看见了」。
14. **「看见了」重复三遍**：门口的选项、天亮卡片、结局文字都在说「看见了」→ 天亮卡片改成孩子醒来说「爸爸，你的胡子上结霜了」，呼应路上的闲话，结局文字只点题一次。

## 氛围与画面
15. **柳树像灰帘子**：方块垂幕看不出是树 → 重画：分叉的树干、圆冠、稀疏摆动的垂枝；路南侧的柳树往下挪，不再盖住最下面那条道。
16. **女儿们像几块白墓碑**：白发白脸白裙糊成一团 → 头发改灰绿、眼睛加深、加唱歌的嘴；追逐和桥头时上下浮动，像在跳轮舞。
17. **魔王的雾团只是一根白光柱**：看不出是「他」→ 加亮王冠剪影和两点黑眼，出现时同时响起魔王的甜小调。
18. **选章缩略图认不出**：小马小人挤在角落 → 放大戴冠的雾影和骑马父子，月亮、雾带、树影一眼能认出「夜里骑马 + 魔王」。

## 声音
19. **「风吹枯叶」只写在字里**：山毛榉坡上听不到枯叶 → 马蹄踩在枯叶瓦片上时，周期性地沙沙响（呼应诗里父亲那句话和第二次信与不信）。
20. **石桥和泥路的马蹄一个声**：→ 桥面上的三连音马蹄叠加清脆的「嗒嗒」，和泥地区分开，过桥那一下更有实感。

## 测试结果（第二步实现后完整验证）
构建：`python3 guaitan3/src/build.py --out guaitan3/.tmp_erlkonig/index.html --only erlkonig`

- 主线 `play.py erlkonig`：**erlkonig OK**，无 ERRORS，无 REACH WARNINGS。
- 变体（scratchpad，复用 play.py 的 run_chapter）：
  - 错路 + 原诗结局：赤杨林岔路上下两条错路各走 2 次（四级提示全部出现，计时最低压到 8 秒）、路口再问加时、三次都回答「那是雾 / 风 / 柳树」、河边两条错路各 1 次 → 桥头旁白「她们比你想的还近」→ 骑到城里 → 门口答「那是雾」→ 坏结局「照着歌里的样子」→ 重来（回到桥头）→ 门口答「看见了」→ 好结局「天亮了」。通过。
  - 睡着：第一次说话选摇篮曲（-8 秒、下回还能选）→ 正常说话（+30 秒）→ 在赤杨林入口 / 枯叶坡 / 河边各睡着一次并从对应检查点重来（计时恢复到 ≥30 / ≥25 秒，有规则小结）→ 通关。通过。
  - 骑马（真人速度，按住方向键 + 奔跑键，自动换道躲雾团）：只走不跑 → 在 x=42 被女儿们追上；跑到 x=30 停 2.5 秒 → 在 x=31 被追上；不躲雾团 → 第一次人立警告、第二次在 x=47「魔王动手了」；只躲第二个雾团 → 撞一次仍能到城门。每次重来女儿们、玩家、雾团、撞击次数都复位。通过。
  - 松手：抓手时选「松开一点」→ 坏结局「松开的手」→ 重来（桥头，grabbed 复位）→ 抱紧 → 城里 → 门口答「那是雾」（只否认过 0 次）→ 好结局的「你骗人」变体。通过。
