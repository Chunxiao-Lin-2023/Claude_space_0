# 第二夜　波利比乌斯 · 自审 20 条（已全部实现）

## 谜题
1. **字母键和引擎快捷键打架**：键盘输入 LETHE 时，E/X/I/J/WASD 会同时变成确认、取消、开背包、移动焦点，结果按出错的码 → 这块 25 键的背板打开时，章节在捕获阶段截下字母键，只把它当字母输入（J 归到 I）。
2. **按错次数被提前用掉**：数字还没凑齐时乱按也算进逐级提示，等数字齐了，第一次按错就直接给出答案 → 只在五个数字齐了以后才累计错误次数。
3. **数字不全时试按就扣十分钟**：新玩家第一次好奇按一下就被罚 → 数字不全时第一次按错只吓一下、不扣时间，第二次起才扣十分钟。

## 危险段
4. **幻觉黑衣人吃掉倒计时**：它离机器 4 格以内，一踩就弹对话；按真人速度实测时，高潮段走向背板正好触发，玩家直接输 → 挪到长椅那一头，触发半径改成 2 格，只在夜里触发，高潮时隐藏。
5. **高潮段被抓后重来，又要翻两页背板说明**：30 秒倒计时被说明吃掉 → 高潮段里第一次看背板只给一句内心话。
6. **GAME OVER 之后没有缓冲**：连着死的玩家下一局还是一样难 → 每次 GAME OVER 后多边形基础速度降 0.1（最多降三次），第一次 GAME OVER 给一句「绕着柱子兜圈」的提示。
7. **第三个多边形可能刷在玩家身边**：原来固定刷在左上角或右上角，玩家在附近就是贴脸 → 刷在三个角里离玩家最远的那个，出现前先响一声预警，等 1 秒再开始追。

## 联机
8. **双人分工只在一闪而过的提示里**：投币以后就看不到怎么分工了 → 双人时目标提示写明「一人握摇杆，一人盯屏幕报数字」，背板的提示里也写「一个人念数字，一个人数格子」。
9. **客机上飞船被撞不闪**：闪烁判断读的是只存在于主机的局面变量 G → 改读 HUD 实体上同步过去的状态。

## 结局与叙事
10. **开场两段剧情二十多页**：「十天前」加「今晚」一共 22 页 → 合并旁白和内心话，压到 8 + 8 页。
11. **好结局路线上从来没见过黑衣人的脸**：大头像只在被抓和坏结局里出现 → 开场他转过头问「你玩过它吗？」时给一张特写（墨镜滑下来，后面只有眼白）。
12. **结局不随调查变化**：看没看过照片和卡片，结局都一样 → 看过失物招领箱里的照片，两个好结局都多一段「这天我记得」；读过雨里的卡片，「拔掉电源」结局多一句「撤收，不留痕迹」。
13. **两点以后才看完第五个数字，台词不对**：仍然说「现在才 02:05，他们提前来了」→ 按时间分成「提前来了」和「准时来了」两种说法。

## 氛围与画面
14. **矢量墙是一格一格的方块**：看着像瓷砖，不像矢量街机 → 按相邻格画连续的双层霓虹轮廓线，凹角补上拐角。
15. **游戏厅下半截空荡荡**：只有柜台和长椅 → 加第二排四台机器、可乐贩卖机、塑料棕榈和收银机（每台机器都有自己的描述，症状加重时屏幕也会变成螺旋）。
16. **HUD 分数太小**：iPad 竖屏上 3×5 的小字几乎看不清 → 分数和最高分改成 2 倍字，「HI」和最高分在破纪录阶段闪红。
17. **失眠加重在现实里不够明显**：原来只是变暗 → 看到四个数字以后，游戏厅里每隔几秒闪过一层不到半秒的绿色矢量网格。
18. **瑞奇睡着了却没有画面**：文字说他睡着了，画面里他还站着 → 高潮段他头顶飘起「z」。
19. **屏幕里那张脸的眼睛糊成一团**：32×32 网格上螺旋线太密，看着像噪点 → 改成两口反向转动的方井，嘴张大时瞳孔闪红。

## 声音
20. **那台机器的嗡嗡声没有远近**：只在离开游戏时响一下 → 夜里和高潮段每 1.7 秒按与机器的距离调整低频嗡声的音量和低通，靠近 3 格以内再加一层很轻的显像管高频声。
