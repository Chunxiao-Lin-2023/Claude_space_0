# 第一夜 亲爱的大卫 · 自审 20 点

## 谜题
1. **第二夜加一个像对的干扰问题**：问题 → 第二夜只要挑出「调子」「钥匙」两个就行，读不读露丝的信都一样；改法 → 加「亲爱的大卫，妈妈的钥匙在哪儿？」，只有读懂信（露丝那把早交回管理员）才知道该问大卫自己那把红绳钥匙。
2. **问过的问题标出来**：问题 → 第二夜再问第一夜问过的「怎么死的」会白白浪费名额，玩家却不知道自己重复了；改法 → 选项后面标「（问过）」，答案照旧算一个。
3. **问错的夜晚要有代价**：问题 → 第二夜问错只是醒来再睡一次，没有代价；改法 → 每失败一次，下一夜大卫开场就离床更近（第二次直接走到枕头边，雪花屏 + 刺耳音），并按失败次数给方向 → 规则（哪一把钥匙、必须叫名字）→ 原句三级提示。

## 叙事与传说
4. **推特串（一）根本没出现**：问题 → 规则的出处写在推特串（一）里，可游戏里没有任何地方打开它；改法 → 到五楼时「爬楼的时候又把那条串翻了一遍」，在贝丝的问候之后弹出。
5. **时间线对齐原串**：问题 → 「问了三个问题」写在 9 月、仓库淤青写在 10 月，和原串（8 月 7 日的第一串就说问过三个，8 月下旬梦见仓库）对不上；改法 → 挪回第一串，仓库改到 8 月 22 日，删掉多余的一条。
6. **名场面「每六十秒拍一张」**：问题 → 原串最有名的照片只在笔记里一句带过；改法 → 第一夜醒来，手机相册里多了三张自己没拍过的全黑照片，调亮后一张比一张近，第三张是大头像。
7. **长对话、长笔记压短**：问题 → 贝丝第一次的对话十五页，两条推特串都要往下滑；改法 → 贝丝主线压到十页内，「两个问题，然后睡觉」的来历挪进追问选项（并点出那原是一个妈妈的睡前规矩），两条推特串删到一屏。

## 危险段
8. **第一次被抓只是挣脱**：问题 → 仓库里一被碰到就死，愣一下就从头来；改法 → 第一次被攥住会挣开（红闪、胳膊火辣辣），大卫被甩回来路上 4 格，0.8 秒后再追；第二次才死。
9. **按真人速度实测并调参**：问题 → 速度 3.0 时，拐弯反应 0.6 秒的玩家会被抓两次死掉，太苛刻；改法 → 用按住方向键 + 拐弯反应延迟的脚本实测，速度调到 2.9（数据见文末），并修掉「挣脱后把大卫放到玩家前面」的问题（只在来路上找位置）。
10. **同一张大头像不滥用**：问题 → 不叫名字、照片、仓库死亡、第三个问题都用同一张脸，倒霉的一局会连吓四五次；改法 → 剧情里的大头像最多两次（`faceOK`），仓库只在第一次死时用大头像，之后换成雪花 + 尖叫。

## 重来与提示
11. **问了第三个，重来时给一句小结**：问题 → 坏结局重来后直接回到问答，没有任何提醒；改法 → 模块计数 `THIRD`，重来时先想一句「两个。只问两个。问完了，就闭上嘴」。
12. **仓库重来时先指一下路**：问题 → 重来后一片漆黑，不知道往哪走；改法 → 镜头先看一眼出口红灯、再看一眼煤球的绿眼睛（煤球同时叫一声），然后才开始追。
13. **两个答案都要记得住**：问题 → 先问调子再问钥匙时，目标里调子的提示被钥匙覆盖；楼梯口的密码盘也没写大卫说过什么；改法 → 目标合并显示两条已知答案，密码盘提示写上大卫的原话和「歌词纸在笺里」。

## 氛围与音效
14. **仓库要像露丝上班的地方**：问题 → 仓库只有心跳和拖脚声，和「服装仓库夜班」没关系；改法 → 远处一台缝纫机空转（短促方波串）、传送带低嗡（`S.tone`），打卡钟和暴雪告示交代背景。
15. **走廊和午夜的声音**：问题 → 现实里的段落几乎没有声音；改法 → 走廊灯管「滋滋」（锯齿波）、午夜猫去门口时煤球「咕噜咕噜」（低频三角波），文字点出「只有见到熟人才这样」。
16. **黄雨衣小女孩留下痕迹**：问题 → 小女孩说完就消失，像旁白；改法 → 门口真的留下一摊水（可调查，漂着一片黄色雨衣扣子），呼应白天贝丝「那是九岁的我」。

## 双人
17. **问答时点明分工**：问题 → 第二夜挑问题需要对照露丝的信，提示里没说两个人怎么分；改法 → 第二夜问答提示加「两人时：一人在笺里翻露丝的信，一人选问题」（哼歌的目标和密码盘里同样写明）。

## 画面
18. **大卫的头看不出是瘪的**：问题 → 人物精灵上的凹陷只有两格像素，被描边吃掉；大头像顶上两撮黑块像猫耳；改法 → 精灵用 `clearRect` 抠出 4×3 的缺口并加淤痕色（正、侧、背三个方向），大头像改成整块塌陷 + 凹坑内沿 + 一圈发紫的淤痕，头发改成稀疏的一层。

## Bug
19. **贝丝的问候先隐身后冒出**：问题 → 进楼时贝丝说话那几页是隐藏的，说完 `hallStage` 又把她摆出来；改法 → 先设幕次、摆好人再说话，说完关门隐藏，门缝状态一起复位。
20. **检查点缺口**：问题 → 贝丝讲完、读完箱子都没有存档，扔椅子（坏结局）重来会退回早上；改法 → 两处各存一次检查点；同时把白天贝丝的摆放逻辑简化成「第一次进走廊摆一次，之后留在原地」，删掉无用变量。

## 测试结果（第二步结束时完整验证）
- 主线：`play.py deardavid` → `deardavid OK`，无 ERRORS、无 REACH WARNINGS。
- 变体 A：第一夜不叫名字 + 问第三个（坏结局「第三个问题」）→ 重来回到问答前、规则小结 → 白天追问贝丝三项 → 扔椅子（坏结局「路边的摇椅」）→ 从读完箱子的检查点重来、椅子复位 → 仓库愣着：第一次挣脱、第二次死 → 重来（`grabbed` 复位、玩家回到 (5,12)）→ 第二夜问错（不叫名字 + 「妈妈的钥匙」）→ 失败的早晨 → 再睡直接回卧室、大卫更近、问对 → 没拿钥匙开门 / 没哼就开锁 → 哼错四次（纸上格错、只错水泡格、再错、乱按，四级提示）→ 哼对 → 好结局（无照片版）。通过。
- 变体 B：第二夜问第三个 → 坏结局 → 重来（默认选项问错 → 失败的早晨）→ 再睡问对 → 好结局。通过。
- 仓库按真人速度（按住方向键，每个拐弯有反应延迟，速度 2.9）：反应 0.25 秒不走错 → 不被抓，约 25 秒到出口；反应 0.6 秒 → 被抓一次挣脱，能逃出；开局愣 2.5 秒 → 挣脱一次，能逃出；中途停 3 秒 → 挣脱一次，能逃出；走错一条过道 → 两次实测分别是挣脱一次 / 没被抓，都能逃出；走错两条过道 → 死；反应 0.9 秒 → 死。（速度 3.0 时反应 0.6 秒就会死，太苛刻，故调到 2.9。）
- 截图检查：走廊、公寓（傍晚 / 白天）、梦里卧室、仓库、梦里走廊、结局页、选章卡片、iPad 竖屏（768×1024）；大卫的凹陷与大头像清楚，笔记一屏内。
