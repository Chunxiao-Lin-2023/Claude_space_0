# 第二十夜 迪亚特洛夫山口 · 自审 20 点（均已实现）

## 谜题
1. **雪板位置只能靠笔记推** → 帐篷里靠坡那面雪墙的切面按 X 画出雪板厚度（门口厚、最里头薄），进帐篷时旁白点一句，雪墙本身成了第二份线索。
2. **方位环提示升级太快** → 改成四级：反过来 → 加 180° → 指北针刻度（东 90/南 180/西 270）→ 直接给 315。
3. **拧错没有针对性** → 135（往林子的方向）、差 12° 以内（「差几度就摸不到帐篷」）分别给专门的提示，每错一次扣 6 秒体温。
4. **最后一张胶卷没有取舍** → 纪念碑前可以拍掉最后一张（记 `memoPhoto`），这样就拍不了火箭光；隐藏结局「最后一张底片」只给把胶卷留到夜里的人，普通结局也会写到纪念碑那张照片。

## 危险段
5. **帐篷里移动太快，雪板计时没经过真人测试** → 帐篷地图 `speed: .8`（爬着走），用真实按键实测：犹豫 3 秒能活、犹豫 6 秒会死，计时定为 14 秒（每死一次 +2 秒，最多 +4）。
6. **雪板倒计时期间听不到声音** → 计时期间雪墙一直嘎吱作响，间隔随剩余时间缩短，最后 4 秒画面抖得更厉害。
7. **恐慌只是一个数字** → 心跳声的间隔随恐慌值缩短（1.6 秒 → 0.42 秒），超过 70 后低频嗡鸣时画面抖得更厉害；实测站着不动约 35 秒会割开帐篷。
8. **脚印消失后找人全靠运气** → 哨声间隔随距离变化（越近越密），音量也随距离变化；列夫的手电光负责标出方向（S.tone 没有左右声道）。

## 惊吓与氛围
9. **会玩的人永远看不到那张脸**（恐慌 ≥55 才触发）→ 凑近帆布看温度计时必然出现一次「风里的脸」，随后读到的数字再把人稳住；恐慌 ≥55 保留作兜底。
10. **火箭光只有一层橙色** → 从门口看出去时显示整屏天空：星星、黑色山脊、一团慢慢张开的发光的雾和弯尾巴。
11. **雪原看不出哪边是下坡** → 雪原瓦片加上往东南流的雪纹（`tileOpts.diag`），玩家看得出下坡和林子在哪个方向。
12. **回程时火光的诱惑太弱** → 起白风后火光的光圈变大变亮；拧对方位走出 5 格后，列夫会低声说「火在后面，我们是不是走反了」。

## 叙事与结局
13. **好结局没交代史实结论** → 结尾加了后话：「第二年夏天」（2020 年）检方的结论是雪板加能见度差；有人信，有人不信；塔尼娅把探杆记录夹进了相框。
14. **「割开帐篷」坏结局照搬了真实的搜救经过（直升机找到帐篷）** → 删掉搜救情节，只写这几个虚构人物留在坡上的帐篷和录音机，免得像在演绎真实遇难者。
15. **同一信息讲了三遍**（塔尼娅讲次声、列夫笔记本又讲一遍）→ 列夫的笔记本改成带时间的读数记录（风速、频率、心率、看到脸、风向变了），结尾一行塔尼娅的字：「数字是实的。脸不是。」
16. **没带靴子的代价只在结局提一句** → 雪原计时减少 8 秒，标签显示「体温（只穿毡袜）」，出帐篷时有一句身体感受，结局里写冻伤住院。

## 双人
17. **恐慌段的目标提示没写怎么分工** → 目标提示里加上「两人时分头做：一人叫醒塔尼娅，一人去看温度计」（雪板段和雪原段原本就写了分工）。

## Bug
18. **列夫的笔记本出现后挡住了录音机**（录音机四面被睡袋、墙和笔记本围住）→ 笔记本挪到门口那侧的 (1,3)。
19. **取消方位环以后很难再打开**（列夫跟在身后、不实心，很难对准）→ 取消后 4 秒自动再问一次，对着列夫按调查键也能打开。
20. **雪原上那棵雪松的描述只有「那棵雪松。」** → 补成有画面的一句：没有活枝，树底下黑黢黢的，没有火也没有人。
