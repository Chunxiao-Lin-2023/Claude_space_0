# 第十五夜 调换儿 · 自审 20 点（均已实现）

## 谜题
1. **蛋壳酒答错没有代价**（LESSONS 1）→ 每错一次，十二只蛋壳全碎，得回鸡窝重新摸一窝蛋；错到第三次，奶奶从灶边篮子里补蛋，免得来回跑。
2. **玩家不知道小老头能给提示** → 进仙丘时他扯扯裙角说「卡住了，就回头问我」；问一次指向刻字，两次给方向，三次给具体办法，四次直接给答案（认错会叠加提示级数）。

## 危险段
3. **第二环舞者对称等距，安全窗口只有 0.3 秒**（模拟算出）→ 改成成对的舞伴（第二环相隔 2 格逆转、第三环相隔 3 格快转），触碰判定收紧到 10px；模拟窗口 1.1–2.3 秒，真人速度实测可过。
4. **计时 34 秒太松** → 改成 28 秒；剩 8 秒时远处鸡先「叫半声」（`S.tone`）并提示，给最后的预警。
5. **环外的安全格看不出来** → 每个环入口前一格铺一道白蘑菇线（贴地），开场内心独白和目标里点明「站在蘑菇线上，他们够不着」。
6. **第一次被抓（铁剪救命）的旁白有 3 页，在 `during` 计时里白白吃时间** → 先把人推回蘑菇线再说话，压成 2 页。

## 叙事
7. **奶奶开场一口气 13 页**（LESSONS 16）→ 拆成「他不是伊万」和「不伤人的老法子」两段，中间目标「再和奶奶说说话」，每段 7 页。
8. **揭穿 + 交易连着 30 页** → 揭穿场面压到 10 页后先放开控制，目标「和小老头谈谈」，玩家主动去问；铁剪改成出门时奶奶叫住你给（3 页）。
9. **进仙丘的开场 14 页** → 压到 9 页；坏结局重来后只剩 3 页加一句「别说名字，别吃东西」。
10. **妈妈只有一句梦话** → 交易后再看她：她在梦里哼那支歌，把伊万托付给格温；结局里她摸到眉梢的小痣才认出孩子。
11. **进院子不知道东西在哪，奶奶还提到不存在的「谷仓」** → 第一次进院的内心独白点出鸡窝、井、麦芽的方位，台词改成「东边篱笆底下的麻袋」。

## 氛围与画面
12. **收集段一点惊吓都没有** → 拿到第二样东西时镜头转向农舍：熄了光的窗玻璃上贴着一张皱巴巴的小脸，一眨眼又只剩炉火（不用大头像，留给揭穿那一下）。
13. **院子太黑，门口没有光** → 门边挂一盏马灯（光源 + 描述）。
14. **选章卡片只有一座土丘** → 改画炉火边的摇篮：篷子底下一双黄眼睛、上头挂着张开的铁剪、炉石上一排蛋壳，窗外仙丘的门亮着；山中夫人大头像加深头发、补下颌阴影，不再是一块白。

## 音效
15. **开场屋里只有炉火声** → 奶奶在哼那支摇篮曲（`S.tone` 合成），哼到一半停下；同一旋律在仙丘里认出伊万时、在妈妈梦里、在结局里再响三次。
16. **土廊舞曲和仙丘竖琴是同一个音色** → 舞曲加快（0.26 秒一拍），每两拍加一记低沉的鼓点。

## 双人
17. **土廊的分工提示只是一闪而过的 toast** → 写进目标：「两人时：一人盯舞步喊『走』」（摇篮、蛋壳酒两处原有分工保留）。

## 结局
18. **隐藏结局（母亲的祝福）无从察觉** → 奶奶在交易后提一句「红披肩、牛奶」；什么都没做时夫人会说「你让他冷着、饿着，走了这一路」，暗示还有别的走法。

## bug
19. **揭穿后的新阶段里能直接出门、奶奶只回「……」、炉台还写着燕麦粥** → 按阶段处理：出门被拦（「先听听小老头怎么说」），奶奶说「问问他」，炉台改写蛋壳冒热气。
20. **蘑菇圈把人传送到固定格 (18,9)，从右边踩进去会被甩到另一头**；「一截桤木」坏结局重来后开场没缩短 → 改成退回上一格；三个坏结局都计入重来次数。
