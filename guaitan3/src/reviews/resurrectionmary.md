# 第五夜　复活玛丽 · 自审 20 条（已全部实现）

## 谜题
1. **第三结局的入口太隐蔽**：月牙别针只在开场主动跟乔搭话时才记下，没搭话的人永远看不到「照片上这个人是你吧」→ 回舞厅后乔插上点唱机时，别针在灯下闪一下并自动记下，第二次跟他说话就能拿出照片。
2. **对号码要来回翻笔记**：点唱机密码盘只有曲目卡，点歌单要合上去翻手包 → 曲目卡下面补一行点歌单（《……月……》 4□8）；节目单仍要按 J 看（双人时一人念、一人按）。
3. **放错唱片的代价只在心里说一句**：玩家不知道错了会怎样 → 目标提示写明「已放错 N 张：最后一支舞要多踩对 N 步」（最多多两步）。

## 跳舞
4. **往上那一步的脚印被玛丽挡住**：她站在你正前方，目标格正好在她脚下 → 改成玛丽领舞：脚印一亮她先退开或让开；只有往下那一步等你离开原地她再跟上。
5. **只能靠音乐和光圈判断拍子**：静音或嘈杂环境里很难踩准 → 脚印下面加一排拍点小灯（一小节几拍就几颗，走到第几拍亮到第几颗，落脚那一拍是白的）。
6. **狐步「早到也算」，华尔兹忽然改判抢拍**：玩家不明白规则为什么变了 → 狐步里第一次早到就提示「早到也算——下一支华尔兹就算抢拍了」。
7. **最后一支舞 16 小节，中途没有进展感** → 每踩对一步，舞池里那些 1934 年的人就清楚一分，从淡影慢慢变成实影。

## 危险段
8. **第一辆车毫无铺垫**：一出酒馆就可能直接被撞 → 存档后先放一辆演示车从门口开过去（不撞人、走远车道），开过去后一句「就是它。听见喇叭，就进光圈」。
9. **实测太松**：车要开过人 26 格才收、下一辆隔 2.5–5 秒，完全不理规矩一路走过去也只被擦一下 → 车开出屏幕（过人 12 格）就收，间隔改成 0.6–2.2 秒；实测坏灯那一段步行偶尔会被擦到，跑过去才稳，和老板娘的话对得上。
10. **擦身而过的警告每次重来都送一次**：乱跑的人永远死不了 → 警告整章只给一次，死过以后再被撞上就是真的；重来时的规则小结里加一句「这一回，它不会再偏开了」。
11. **第一次被擦到以后不知道往哪儿躲** → 警告之后提示「最近的光圈在你左/右边 N 步」，下一辆 0.8 秒后就开始来，愣在原地会出事。

## 联机
12. **跳舞时旁观的人只能干看** → 旁观的人屏幕上，脚印旁边多一个蓝色小箭头，预告再下一步往哪儿走（一人报方向、一人踩）；操作的人看不到。

## 结局与叙事
13. **老板娘一口气说了 18 页** → 第一次只讲「认出她、柜台上的本子、电话断了、规矩」（10 页），1976 年的栏杆挪到第二次搭话和墙上的剪报里。
14. **华尔兹之后的散场戏 17 页** → 把领班喊话、钟敲十二下、大灯亮起合进旁白，压到 10 页。
15. **回到打烊的舞厅，乔的第一段 11 页** → 合成 8 页，插点唱机和别针一闪放进同一段旁白；点唱机插上电后自带一圈灯光，黑舞厅里一眼能找到。
16. **档案没分清来源** → 1976 年的手印标明「有当年的报道可查」，她的身份写成「查无实据」，出租车司机的证言标明是口耳相传；结尾列清楚哪些是游戏虚构。
17. **好结局不随调查变化** → 读过旋律酒馆里「司机们的话」的玩家，「最后一支舞」结局多一段：几天后你在那本本子的最后一页写下自己的一行。

## 氛围与画面
18. **好结局路线上从没见过玛丽的脸**：大头像只在放错唱片和坏结局里出现 → 后视镜那一下：第一眼后座是空的，第二眼她的脸贴在镜面上（大头像），一眨眼又空了。
19. **铁门上的手印太小，离开车灯就看不见** → 手印放大成两只张开的手（左右镜像）；发烫时铁门自带一圈闪动的橙光和白汽，烧完留一点余温的暗光。

## 声音
20. **舞厅里的乐队几乎听不见**：原来 16.5 秒排一整段、音量很低，还会在跳舞开始后继续响一会儿 → 改成一拍一拍地排的无缝循环（跳舞一开始马上停），按离乐台的远近调音量和低通。
