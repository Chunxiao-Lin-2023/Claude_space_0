# 第十一夜 无头骑士 · 自审 20 点

## 危险段
1. **追逐根本跑不赢**（LESSONS 5）：真人速度机器人走最优路线也被擦过、反应 0.45 秒就死在第一个岔口之前；原因是岔口前六个急弯（每个弯都要停顿、冲过头），加上「狂奔一秒换小跑两秒」的气力账正好打平 → 岔口前的路拉直成两个弯（下坡那段改成躲倒树）；黑森兵 6.5 格/秒，狂奔每秒掉 18 气力、小跑回 10；开局他离你 5 格、等 0.9 秒才动。
2. **一直小跑的人永远抓不到**：引擎默认 11 像素才算追上，追的人总是瞄着你刚离开的那一格，只要你在动他就贴在马屁股后面抓不到 → 章节里自己判定「贴到一格以内」算追上；第一次是冷风擦着后脖颈过去（警告，把他甩回他自己来时的路上），第二次才死。
3. **两个错岔口的代价失衡**：回汉斯家那条几乎不吃亏，老墓地那条（原来是个环）他会从另一个口子迎头堵死，次次都死 → 汉斯家门口火药一头扎住站 1.7 秒、再走泥道；老墓地改成只有一个口子的死胡同，火药被无名坟惊得一退。复测：走错任何一条都是「擦过一次、还能活」，再加一次愣神就死。
4. **竖屏（iPad）镜头往前看三格，身后的他完全在画面外** → 前瞻改两格（跟随段一格）；他离你 6 格以内时，火药尾巴后面出现红色箭头，越近越多、一闪一闪。
5. **追逐一开始三条提示（目标、操作、联机）同时弹，第一条被挤掉；马背上的气力条没人解释** → 操作说明并进火药撒蹄狂奔那句旁白里；气力低于 25 时火药口吐白沫、喷一声鼻子，并提示一次「缓一缓」。
6. **倒树在黑路上看不清，又带着调查键**：追逐中骑手头上一直冒「!」提示 → 倒树去掉调查，各带一点月光，提前三格就看得见。

## 谜题
7. **马厩认马认错没代价，五匹挨个试就完了**（LESSONS 1）→ 认错一次，马扬蹄踹隔板、马灯脱手灭了，得摸黑回门口重新点上；每匹认错的马都按它对不上的那一条给针对性理由，第 2/3/4 次再逐级给「四样都要对上」「逐条对照」「左数第四个隔间」（LESSONS 2）。
8. **先认出火药、手里却没有鞍子时不知道鞍子在哪** → 内心独白提示「长工卸了鞍一般挂在隔板的木桩上」，那根木桩冒「!」。

## 叙事
9. **「过了桥，别回头」在老布劳尔、笔记、琴师、过桥四处重复**（LESSONS 16）→ 琴师改说「火药认得路，您别跟它犟」。
10. **布罗姆问「是不是过不了那座桥」的选择没有下文** → 答了「邪祟渡不过流水」的人，过桥时的内心独白会接上这句书上的话，再想起老布劳尔的规矩。
11. **威利沼泽那一幕来得太突然** → 过了少校树，远处响一阵很轻的马蹄声，勒住马再听，没了。
12. **南瓜结局要凑 3 条线索，但玩家不知道这些怪事算数** → 每发现一件，提示「（不对劲的事 n/4）」。

## 结局
13. **好结局和追逐里发生的事无关** → 被擦过（外套后领上一道口子）、走了回家的路（汉斯听见有马在院门口喘）、闯进老墓地（无名坟前的泥被刨乱）、鞍子掉了（汉斯心疼一冬天）各加一句；凑齐线索却推门进教堂的，结尾留一句「要是转过身去喊他的名字会怎样」。

## 氛围与画面
14. **跟随段那个骑马的几乎看不见**（他在身后、路又黑）→ 他身上带一点冷冷的反光，镜头前瞻减到一格，他留在画面里。
15. **少校树只看得见一截树干，扭曲的大树枝全在黑地里** → 树冠上加一片月光，演出时镜头往上抬。
16. **惊吓大头像读不出「没有头」**：第一版月亮像个白脑袋，领口那道红线像一张嘴 → 重画：月光勾出宽肩膀和两片竖起来的高领，领子中间只有夜空，月亮挪到一边，手里拎着发光的脑袋。
17. **选章卡片的骑手是一团黑，看不出是马** → 重画：大月亮衬在身后，剪影是扬起前蹄的黑马，骑手领子上空着，高举一颗发光的南瓜头；桥栏杆压在下面。
18. **谷仓的笑声在院子里任何地方每 8–13 秒都响一次，很快就烦了** → 只有走近谷仓（9 格内）才听得见，听过墙缝里的话之后就不再笑。

## 双人
19. **追逐时旁观的人看得见路牌，却不知道什么时候该开口** → 快到岔口时，旁观者那一端的路牌会一闪一闪地描边（本地绘制，操作者看不到）。

## Bug / 界面
20. **「别回头」判定会吃掉还按着的方向键**：过桥那一下、凯特琳的声音、第一次警告之后，玩家手还按着左键，对话一关就直接判成回头 → 任何剧本结束后 0.5 秒、警告后 1.2 秒内不判定，强制朝前。

（写作中顺手修掉的：舞池里跳舞的人原来靠改 `fr` 摆动，会被引擎每帧清零 → 改成左右换向加上下颠一下；马厩出门时马灯没挂回门口；死亡时原来也用大头像，死几次就看几次 → 改成红屏，大头像只在现形和坏结局各出现一次。）

## 测试结果（最终版本）
- `play.py headless`：**headless OK**，没有 ERRORS，没有 REACH WARNINGS。主线：杜夫、老布劳尔、布罗姆三个故事 → 南瓜子、圣经、巫术书、餐桌、巴尔图斯 → 凯特琳 → 院子（断茬、墙缝、稻草人；没骑马出院门被挡回）→ 马厩（没灯看马、点灯、空隔间、认错锈红马、马灯灭了重点、先认出火药再拿鞍）→ 夜路（开场、少校树、远处马蹄声、威利沼泽「你是谁」、跟随、坡顶现形）→ 追逐（传送到桥头）→ 过桥后按住的方向键不算 → 回头一次警告 → 再回头坏结局 lookback → 从桥上重来 → 三段声音 → 教堂门口转身喊布罗姆，南瓜结局 pumpkin。
- 变体（scratchpad，不进仓库）全部通过、没有报错：一条线索都没找 → 好结局 bridge，门口不出选项；找到 2 条 → 好结局多一句「没想通」；4 条但推门进教堂 → 好结局多一句「转过身去」；马厩连续认错 4 次（每次马灯熄灭、逐级提示、第 4 次火药冒「!」）；先认马后找鞍（木桩冒「!」）；故事没听完、没和凯特琳说话时出不了门，没骑马出不了院门，骑上马后进不了屋和马厩；站着不动连续死 5 次，每次重来都复位（他回到 50,11、气力 100、擦过标记清零、鞍子和目标还在），第 2 次起路牌常亮、第 3 次起正确路线上有光点、第 4 次起他慢 0.5；肚带断、鞍子掉在路上、换成光背马的贴图。
- 真人速度追逐（fast=1，方向提前按、气力判断每 0.22/0.45 秒一次，每种跑两遍）：最优和慢反应都 0 次被擦过（最近 5.8 格）；全程只小跑 → 擦过一次后死；一直按着狂奔 → 被擦过一次、能过桥；中途愣 2.5 秒 → 擦过一次、能过桥；走回汉斯家 / 闯进老墓地 → 各擦过一次、能过桥；愣 2.5 秒再走错任一条岔路 → 死。
- 截图总览看过（1280×800 和 768×1024 竖屏）：四张笔记一屏放得下，舞会、马厩、少校树、跟随、追逐（气力条、他的脑袋发光）、教堂、两张大头像、选章卡片都正常，竖屏下身后箭头能看到。
