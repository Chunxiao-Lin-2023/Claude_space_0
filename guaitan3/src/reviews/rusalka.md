# 第十九夜　水仙女 · 自审 20 条（已全部实现）

## 叙事
1. **奥克萨娜说「他娘说他半夜出了门」，可斯捷潘家门口写着只有他爹、而且赶集去了** → 改成奥克萨娜自己起夜，看见他光着脚从门口走过去、叫他也不回头；屋里没人的描述保留。
2. **玛尔法半夜站在门口，没有任何交代** → 第一次见她先加一句旁白：一年了，她每天夜里都倚着门框站着，像在等谁回家。
3. **黑麦田里她叫你「姑娘，姑娘」，可前面刚在麦子里喊过「娜佳」** → 问话改成「娜佳，娜佳，这么晚了你去哪儿呀？」——她认得你，后面在白桦树下认出阿廖娜才接得上。

## 谜题（梁上八把草）
4. **木牌上刻的道数小得数不清** → 木牌改成浅色、加高，刻痕改成 2×1 的短横、四道一排，草把相应缩短，不再压住木牌。
5. **只有第 1、3 次答错有代价，第 2、4 次白错** → 每错一次红灯盏就暗一点（玩家光圈 3→1.8 格，认对了才恢复）；第 2、4 次另有敲窗声和一句旁白，第 1、3 次是窗外的笑声和闪白。
6. **一把草都没看就能去问外婆，靠密码盘乱试** → 没看过梁上的草时外婆只说「你去梁底下看过了没有」，不弹密码盘；同一颗钉子按两次也单独回应、不算错。

## 危险段（河滩歌声）
7. **被歌声往下拽时，画面上看不出是「水在拉你」** → 歌声里，你脚下正对着的浅水里会伸出几只苍白的手，跟着你左右移动，歌停就沉下去。
8. **歌声在哪儿都一样响** → 音量随离老白桦的距离变化（河滩西头 0.05，到白桦跟前 0.11）。
9. **河滩上悄悄禁了奔跑，玩家以为是卡了** → 第一次进河滩的旁白里写明「脚下的草湿漉漉的，一跑就滑——只能一步一步地走」。
10. **预警只有一声低哼和一个「!」，开着别的声音就容易漏** → 预警时再轻轻震一下屏幕，前两次弹出「（远处的歌声近了……）」。

## 画面
11. **老白桦太靠上，树枝上荡秋千的她被地图上沿裁掉了半个** → 白桦挪到 (39,7)，她从树上下来、走进水里的位置和斯捷潘上岸的位置一起往下调，镜头对准 (40,6)。
12. **村子里的大白桦树干细、树冠稀，像一根杆子** → 树干加粗、加根部，树冠垂枝从 14 条加到 22 条、四种绿色交错。
13. **标题卡在 iPad 竖屏上可能把「波列西耶」从中间折开** → 标题和副标题按全角空格分词，词内加 WORD JOINER。
14. **看不见的东西：黑麦田的地界橛子是隐形的，河滩 (12,9) 有一格看不见的芦苇挡路** → 橛子画出来（短木桩上系一小把苦艾）；那一格改成真正的芦苇瓦片。

## 声音
15. **黑麦田里只看见麦子在动，听不见「沙沙」声** → 每次麦子晃动配一串低沉的短锯齿音（低通 420 Hz）当沙沙声，再随机配轻笑或耳语。
16. **好结局「送水仙女」的歌只是一条单薄的旋律，公鸡也只叫一声** → 姑娘们的歌加了三度和声和低八度，公鸡叫两遍（头遍、二遍）。

## 结局
17. **扔苦艾的结局不管你有没有听过她说「我冷」都一样** → 和她说过话再扔苦艾，结局前多一句「……她说她冷」。
18. **「再等一等」什么都不发生，最后一幕没有紧迫感** → 每等一次水就漫上去一截（大腿→腰→胸口），第三次起她笑得更响；不会因此输，只是更急。

## 双人
19. **河滩一段没有双人分工的提示** → 河滩目标里写上「双人：一人听歌喊『停』，一人赶路」（梁上认草的「一人念练习本、一人去看」保留）。

## Bug
20. **黑麦田的相遇剧本一开始用 `S.walk('pl')` 把玩家拉到固定格；玩家刚踏上那格、移动还没落地时被打断，脚本会永远卡住（实测约 1/3 概率）** → 不再移动玩家：在田埂竖直那一段（y≥17）触发，她出现在你前方 3 格、自己走到你面前。

## 测试结果（第二步结束后完整跑一遍）
- `play.py rusalka`（主线，好结局「送她过节」）：`rusalka OK`，无 ERRORS、无 REACH WARNINGS；连跑多次稳定。
- 坏结局「我的小亲亲」：答「欧芹」→ badend，结局收集记入；重来回到黑麦田入口、她已复位，重答「苦艾」可继续。不说话两次 → 同一坏结局。
- 河滩淹死：站着不动，第一次被拽进浅水 = 警告（退回岸上、`wet=1`）；再不动 = 死亡；重来后回到河滩入口，`wet` 清零、禁跑、速度 1、歌声从安静段开始，并给一句规则小结。
- 第三结局「苦艾」：不拿衬衣，到白桦下「再等一等」两次（水位旁白）、说话、扔苦艾 → 结局收集记入；从 birch 检查点重来可用。
- 认草提示：没看草时不弹密码盘；同号不算错；错 1–4 次依次给针对性气味提示 / 方向 / 左右各一把 / 直接给答案，灯盏逐次变暗，认对后恢复。
- 安静时自己走进浅水：只被推回岸上，不计警告。往返村子 ↔ 黑麦田 ↔ 河滩，阶段和禁跑正确切换。
- 真人速度：按「歌一起就按住上、安静往右走」约 20 秒走完河滩、不湿脚；反应慢 0.6 秒（连预警一起约慢 1.5 秒）会湿一次（警告）但能到；无视歌声一直往右走，在第 15 格左右被拽进水里（警告，再一次就死）。
