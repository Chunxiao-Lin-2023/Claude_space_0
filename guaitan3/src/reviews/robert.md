# 第六夜 罗伯特娃娃 · 自审 20 点

## 谜题
1. **写好的信看不到**：问题：写完信只有一句旁白 → 改法：封口前打开整封信笺（「你的字迹」），划掉的行也照原样列出来。
2. **写信提示只有两级**：问题：错两次后就没有新提示了 → 改法：每一句三级提示：先给规则方向，再指向墙上哪封信，第三次直接给出写法。
3. **四根闸刀长得一样**：问题：玩家记不住哪根是总闸 → 改法：总闸画成黑色大手柄、顶上加黄黑警示条；推第一下时 toast 报出这一路的名字，第二下才算数。

## 危险段
4. **停电时调查展品会弹对话**：问题：他在你读字的时候照样走过来 → 改法：停电期间走廊/修复间的展品调查一律改成 toast（`dk()` 包装）；读配电标签时他会停下等你。
5. **回头看没有用**（真人速度实测发现）：问题：他从不后退，所以回头只是推迟被抓的时间，回不回头结局一样 → 改法：被手电照住 0.45 秒以上、又在 5.5 格以内，等你移开视线，他就退回门口附近、离你 7 格以外的暗处；同时调了参数（礼貌 2.65 格/秒、宽限 1.0 秒；不理他 2.8/0.8；呵斥他 3.1/0.5）。
6. **死后重来只有一条 toast**：问题：规则一闪就过去了 → 改法：重来时先用一句内心独白复述规则；第二次重来时：读过标签的直接给出顺序，没读过的提示先去读。
7. **声音没有方向**：问题：`S.tone` 没有左右声道，玩家不知道他从哪边过来 → 改法：他走到 3 格以内时，玩家头顶冒「!」并响一声心跳，用画面补方向。

## 节奏
8. **每次离开都要选一次「说再见」**：问题：来回好几趟会很烦 → 改法：礼貌地道别两次以后算养成习惯，之后自动说「一会儿见」，只弹 toast。
9. **放回小狮子后还得重新进菜单拍照**：问题：步骤多余 → 改法：放回狮子后直接问「要现在拍吗？」，可以接着进入拍照流程。

## 叙事 / 传说
10. **画家主人存在感太弱**：问题：只在展签里提了一句 → 改法：老照片第一次调查时扶正相框，背面露出孩子的铅笔字「是罗伯特干的！」，并接一句画家一生的感慨。
11. **幻想节日期不对**：问题：2019 年的幻想节 10 月 27 日就结束了，海报却写「这个礼拜」→ 改法：改成「上个周末刚过完，石缝里还能捡到亮片」。
12. **没听留言的人不知道宋晴是谁**：问题：她做错了什么只在可选的答录机里说过，写信第二句缺依据 → 改法：没听过留言时，电话开头由她自己交代来历和做过的事。

## 画面
13. **调查提示「!」挡住娃娃的脸**：问题：气泡画在实体顶边往上 2–11 像素，正好盖住柜里的脸 → 改法：柜子整体加高，娃娃上移 9 像素；底柜加高到整格，射灯移到柜顶上方。
14. **柜里娃娃是一团白**：问题：射灯光锥太亮，衣服和玻璃糊在一起 → 改法：衣服换成暗一点的米白，娃娃加一圈深色轮廓，光锥透明度从 .10 降到 .06。
15. **合闸后只有一枚鞋印**：问题：「他刚才离你多近」看不出来 → 改法：记录他最后走过的 6 格，留下一串由浓到淡的灰鞋印；另外炮眼里的白影加了一圈微光，夜里看得清。

## 声音
16. **打招呼没有回应**：问题：说完「晚上好，罗伯特」什么也没发生 → 改法：每次正确打招呼后，柜子里传出两声极轻的音乐盒音（`S.tone`）。

## 联机
17. **台词默认只有一个人**：问题：黛布走后内心独白是「只剩我一个人」→ 改法：双人时改成「只剩我们两个人」；拍照、停电、写信三处各有一条双人分工提示。

## 结局
18. **拍坏了要从读信之前重来**：问题：「没问就拍了 / 他说了不」坏结局重来要走很远 → 改法：每次开始拍照时存检查点 `photoTry`，重来就站在柜子前；接电话前也补了检查点 `call`（「没有寄出的信」重来时电话还在响）。

## Bug
19. **径直走到柜前也被判「忘了打招呼」**：问题：从门口到柜前正好 7 步，触发了阈值 → 改法：阈值改为 11 步，站在柜子跟前那几格不计步。
20. **小狮子在手里时，拒绝提示还叫你去修复间拿**：问题：提示和实际状态矛盾 → 改法：加一档判断：「小狮子还在你手里，先把它还给他。」

## 测试结果（第二步结束后完整跑一次）
- 主线 `play.py robert`：**robert OK**，没有 ERRORS，没有 REACH WARNINGS（隐藏结局「他笑了」）。
- 坏结局（SOL 变体，放在 scratchpad）：没问就拍 → `noask`「没问就拍了」；问了没等就拍 → `noask`「没等他回答」；看到「不」还硬拍 → `refused`；两次拒绝宋晴 → `unsent`。每个坏结局重来后都回到对应检查点（柜前 / 电话响着），接着走都能通关（重来后仍可拿到 `smile`）。
- 失礼路线（叫他小娃娃、敲玻璃）→ 普通好结局 `win`，rude=2；写信划掉 2 行 → crossed=2，信笺正常显示。
- 忘了打招呼：第一次只警告，第二次进门再忘记一次失礼；从门口径直走到柜前不会误判。
- 停电段死亡 → 重来：阶段、闸刀全部复位、罗伯特回到 (12,5) 并重新追、小狮子还在、手电光圈和目标都在；第二次死后速度降到 2.45。
- 真人速度脚本（推闸间隔约 0.45 秒、走一格 0.25 秒、已知顺序）：完全不回头 → 礼貌 2/2 次被抓（10.8 秒），不理他 5.7 秒被抓；每推完一根回头看 0.8 秒 → 三种态度都赢；每两根回头一次 → 赢（最近 2.8 格）；先推错一根再改正 + 回头 → 赢（最近 2.5 格）；每次盯他 3.2 秒 → 被警告、两次扑近、失礼 +2，险胜。
