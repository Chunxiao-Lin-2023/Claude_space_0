# 第十夜 泽西恶魔 · 自审 20 点（均已实现）

## 谜题
1. **第三岔口只有两条路** → 二选一能靠蒙；加了东边第三串「舅舅的马掌钉靴印」（两行、后跟铁掌像蹄子），走错会踩裂冻住的红莓地。
2. **爪痕树离岔口太远** → 口诀第五条「抬头看树」在岔口用不上；把爪痕挪到每条正确分支的入口旁，站在岔口就能对照。
3. **到岔口没有提示** → 第一次走错之前，玩家不知道要比对；走进岔口空地时先旁白交代「三串印子」，并设目标让人先蹲下看。
4. **具体提示一闪而过** → 第三次以后的提示只在内心独白里出现；现在同时写进右上角目标（第四次直接给方向）。

## 危险段
5. **冰面在暗处看不出来，久站会裂却没人说** → 冰面改亮改蓝、加反光线；第一次踩上冰给一句「踩不出脚印，可别站久了」。
6. **它断线后飞起和落地没有提示** → 第一次飞起时提示「它在找你新脚印开头的地方」，落地时镜头抖一下，玩家能读懂规则。
7. **开场规则说明 8 页** → 拿到控制前已经忘了；压到 4 页，规则只在内心独白和目标里各说一次。
8. **松针区是方方正正的棕色块，像地上的洞** → 松针格边缘随机混进雪，颜色调暖，和雪地自然过渡。

## 叙事
9. **外公一口气讲了近 30 页** → 拆成「传说」和「托付」两段，各 9 页左右；中间目标「再和外公说说话」。
10. **1909年1月21日是朔月** → 台词、旁白和选章图里却写了月亮；全部改成没有月亮的雪光与星光（「它把星星挡住了一大块」）。
11. **「从烟囱飞出去」的名场面只是转述** → 在老宅烟囱前加一张暴雨之夜的幻象字卡（一七三五年、接生婆、火被吸进烟道）。
12. **砖缝里的信太容易拿到，隐藏结局变成默认** → 第一次摸烟囱只看到幻象和爪痕，第二次细看烟道才发现松动的砖。

## 结局
13. **开枪的抉择一按就成** → 和外公两次叮嘱没有呼应；选开枪后先响起外公的话，再问一次「还是扣下扳机 / 把枪放下」。
14. **卷一终字卡紧接在沼泽之后，显得突兀** → 两个好结局都先给一张「第二天早上　外公的木屋」小卡，再进「卷一　终」。

## 画面
15. **脚印太淡太小，暗处几乎看不见** → 加深颜色、放大一圈，蹄印下沿加一道雪光；鹿、狐狸、靴子印同步加深。
16. **老宅烟囱贴着地图顶，它蹲上去时出了画面** → 老宅地图整体下移三行，镜头对准烟囱顶时能看见整只。
17. **惊吓大头像更像牛头** → 收窄拉长成马脸，加额前鬃毛、张开的鼻孔；选章图也改成烟囱上蹲着的完整的它。
18. **松林、老宅里零散的松针格像黑洞** → 去掉零散的「,」，松针只留在沼泽里当规则用的落脚点。

## 音效
19. **松林里只有风声** → 第二岔口远处传来猎狗叫和一声闷枪（`S.tone` 合成），提醒搜索队就在附近，和第一岔口的搜索队对上。

## 双人
20. **老宅里没有分工** → 读到家谱后提示「一个人念家谱最后那句话，一个人在宅子里找」（松林、沼泽原有分工提示保留）。
