# 第七夜 娃娃岛 · 自审 20 点

## 谜题
1. **三个地方三选一，能一个个试过去**（LESSONS 1）→ 选错一次，岛上的雾就浓一层（光圈 3.2→最小 1.8），所有娃娃一起「咯」地转头、有人笑；找回一样东西退回两层，四样全找回就恢复。
2. **娃娃转头只有 1 像素的眼珠移动，很难注意到** → 开始转头时头顶冒「…」、发出塑料脖子的「咯」声；站定 2.5 秒（原 3.2 秒）它看着的地方就发光。
3. **运河迷路只有进了死路才有提示**：一直在主河道来回转的人拿不到帮助 → 在运河里两分钟还没拐进红裙子娃娃那条水道，目标自动换成具体路线并弹出爷爷的话（死路提示照旧分两级）。

## 危险段
4. **湖上追逐实测太难**：按真人速度（每次转弯反应 0.25 秒）走最优路线也会被抓两次 → 她的出生点从身后 4 格挪到 6 格、多等 1 秒。复测：正常打法不被抓；反应慢（0.6 秒）、停 2.5 秒、多踩水葫芦各被抓一次（拍水脱身）；钻进东边死水湾就会死。
5. **「拍水三下」是自动播的**：规矩没有落到玩家手上 → 被抓住时弹出「拍水」按钮，自己按三下（数字 1 或点按，避开字母快捷键），之后她被甩回身后 6 格。
6. **追逐开始时环境声照旧、只有一句旁白，玩家不知道要跑** → 歌声一停环境声就全静，多一句「别停——撑！」；她越近滴水声越密，不到 4 格时有低沉的闷响。
7. **湖上的光圈和运河一样大，雾没有压迫感** → 进湖时光圈缩到 2.8，木桩自带微光指路，靠岸恢复（改完重新跑了一遍真人速度测试，结果同第 4 条）。

## 叙事
8. **爷爷一口气讲了二十多页**（LESSONS 16）→ 拆成两段：先讲托尼奥、岛主和小姑娘（含两种说法的分支），再交代任务、《航路》和湖上的规矩；每段 10 页以内，目标在中间提示「再跟爷爷说话」，出门也要两段都听过。
9. **「她们丢了东西就一直看着」在托尼奥、画、本子里讲了三遍** → 托尼奥改说「她说她在岛上等你」，画里只画「脑袋都歪向一边」，规则只写在岛主的本子里。
10. **岛主的本子超过一屏** → 压成每个娃娃一行（位置、年份、丢了什么），1280×800 和 iPad 竖屏都能一屏看完。
11. **好结局没给第三结局留线索** → 读过本子却没带椅子上的娃娃，好结局会多一句「椅子上还坐着一个补了一半裙子的娃娃，它没能挂上老柳树」。

## 氛围与画面
12. **岛上写着「没有虫叫，没有蛙鸣」，环境声却是虫鸣的 night** → 岛上改成风声。
13. **四个娃娃全部转向老柳树时，玩家多半离得远看不见** → 镜头先移到老柳树停一下、配上歌声，再回到玩家身上。
14. **上岛后一片黑，不知道小屋在哪儿** → 小屋窗户透出烛光（带光源），从码头就能看见，调查窗户时会问「屋里有人点着蜡烛？」，和进屋时「蜡烛是新的」对上。
15. **歌声只在进湖前那段运河里响，存档以后突然安静，节奏断了** → 存档后在进湖的水道里继续唱，越靠近湖越响，进湖那一刻停下（第 6 条）。

## 双人
16. **双人分工只在爷爷那儿 toast 一次** → 进湖存档时提示「一个人盯着雾里的木桩报方向，一个人撑船」，第一次碰铁盒子时提示「一个人翻本子念年份，一个人按铜钮」。
17. **结局抉择（挂上/抱回船上）只有操作的人能选，另一个人没参与** → 双人时选之前提示「两个人商量好再选」（本作不做投票）。

## Bug / 界面
18. **门口惊吓的瓷娃娃刷在玩家出门站的那一格上**，和玩家叠在一起 → 改到门前一格，仰着脸看你。
19. **椅子上娃娃的选项问题是空字符串**，对话框只剩两个选项 → 加上「要带上它吗？」。
20. **捡到东西以后目标还是「找回（n/4）」，不知道该还给谁** → 捡到时目标改成「把小红鞋还给穿蓝裙子的娃娃」之类；顺手把湖上和岛上两条过长的目标缩短，iPad 竖屏最多两行。

（写作中顺手修掉的：柳树原来只是一格高的贴图，看不出是树 → 每棵柳树生成一个能伸出格子的高柳树实体，岛上的树冠里挂小娃娃；薄水葫芦和厚水葫芦看不出区别 → 厚的整片更亮更密、底边描暗，薄的只有几簇浮在水面；浮田上的作物原来像一排加号 → 改成一垄垄生菜；码头的空船挡住了上岸那格 → 挪到码头左边。）

## 测试结果（最终版本）
- `play.py munecas`：**munecas OK**，没有 ERRORS，没有 REACH WARNINGS。主线：窗户 → 爷爷（第一段，选「他后来呢」）→ 托尼奥给娃娃 → 爷爷第二段给《航路》→ 坐船 → 红裙子娃娃 → 沉船 → 进湖存档 → 湖上追逐 → 上岛 → 本子 → 铁盒子「白衣裳·散头发·蓝裙子·没眼睛」→ 带上椅子上的娃娃 → 出门惊吓 → 四个娃娃找回东西 → 全部转向老柳树 → 挂上两个娃娃，结局 both。
- 变体（scratchpad，不进仓库）全部通过、没有报错：没问爷爷/没拿娃娃就出门被挡回；运河两分钟迷路提示；三条死路逐级提示、水葫芦减速；湖上被抓一次（自己按三下拍水）→ 第二次被抓死亡 → 从 lago 检查点重来（她藏起、抓住次数清零、船和禁跑复原、光圈复原）→ 再进湖 → 上岛；问同一个娃娃四次直到目标常亮；站定 1.6 秒娃娃转向目标；选错两次雾浓两层、找回东西后恢复；密码盘答错三次（提示逐级）再答对；不带椅子上的娃娃；坏结局 take（抱回船上）→ 重来回到 final（娃娃还在身上、所有头仍朝老柳树）→ 好结局 hang，结尾有椅子那句。结局收集记到 take、hang、both 三个。
