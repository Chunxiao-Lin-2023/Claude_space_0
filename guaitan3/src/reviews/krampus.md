# 第二十七夜 坎卜斯 · 自审 20 条

## 谜题
1. 卡片提示只写「J 键」 → iPad/手机没有键盘，改成「点右上角的『笺』或按 J」，目标和物品说明一起改。
2. 跑铃人的铃铛响不响只能靠声音或文字判断（引擎没有左右声道，静音玩家也听不到） → 响铃的三个跑铃人腰间画出一闪一闪的铃铛亮点，不响的三个不画。
3. 伊尔泽想不起「脚——」那一句，线索就断在那儿 → 看过林子里脚印的，莱妮当场接上「一只蹄子，一只光脚」；没看过的，提示「林子里的雪地上，也许有答案」。

## 危险段
4. 按真人速度实测：一路跑过去它也不会「跟丢」，「别跑」这条规矩等于没有 → 跟丢距离从 13 格改成 8.5 格，奔跑时超过 6 格也算跟丢；重新盯上的距离改成 7 格。
5. 实测：起步愣一下、挨一桦枝以后，它被定住 1.4 秒，玩家走着走着就把它甩丢了 → 挨打后它不再定住，只是晚 0.8 秒起步、1.3 秒内不会再抓；另外落后超过 5 格时它加快到 4.0（走路的人甩不掉，跑的人照样甩得掉）。
6. 跟丢之前没有任何预兆 → 超过 7.5 格（或边跑边拉到 4.5 格）时，它头上冒「?」，提示「慢一点——它快跟不上你了」。
7. 它掉头去找孩子以后，几乎来不及回去 → 先停 0.9 秒回头张望，再以 2.2 的速度走过去；同时一串急促的铃声，菲利克斯头上冒「!」，提示「回去把它引过来」。实测：跑回去追得上。
8. 游行的倒计时只有左上角一个数字 → 每过半分钟钟楼敲一下，最后 20 秒心跳越来越快。

## 节奏与叙事
9. 开场对话二十多页 → 压到 10 页：合并旁白，把爷爷的警告和「去教堂」并成两段。
10. 第一次进教堂 14 页 → 压到 9 页，规则只讲一遍（页头、页脚在笔记里，不再口头重复）。
11. 目标提示太长，一行放不下 → 孩子的位置缩成「菲利克斯（作坊门口）、莉泽尔（雪人旁）、托尼（南边雪坡）」。
12. 从下午到六点四十，小镇的天色一直没变 → 每还清一笔账，小镇暗一档（0.66 → 0.75），游行时 0.78。

## 氛围与画面
13. 雪地太亮，小镇看起来像白天 → 雪和踩实的路压暗、偏蓝，路灯和窗户的光圈更显眼。
14. 牵着小雪往回走的一路太平静 → 走到岔路口下面时，坎卜斯在东边树影里站一下、再淡出（只有铃声，不致死），呼应它在林子里。
15. 黑面具放在喷泉沿上，很容易错过，诱惑立不起来 → 走近 3 格以内第一次会听到低语，面具上冒「…」，莱妮觉得「有什么东西在小声叫你的名字」。
16. 选章卡片上的坎卜斯被裁掉了头和角，认不出来 → 改成正面、按卡片高度自动缩放，角、红舌头、铃铛都在画面里。

## 结局
17. 真结局里圣尼古拉牵它离开只有旁白 → 两个人物真的走下台阶、穿过广场，再淡出。
18. 普通结局和真结局的分岔不够明显 → 游行开始时如果还没向菲利克斯道歉，莱妮心里会想「怀里的金书，最后一行还是红的；菲利克斯和爷爷站在广场东头」。

## 双人
19. 游行段的分工只在一句括号里提到 → 双人时广场东头的爷爷会直接分配：「一个凑近去看铃铛、白气和脚印，一个翻笺对卡片上那几句」。

## bug
20. 游行开始后作坊里还站着一个爷爷，和广场东头那个重复；引它过来时调查跑铃人没有任何反应；拿着断拐杖去找马蒂亚斯也没有指引 → 游行时藏起作坊里的爷爷；引它过来时调查跑铃人会说「现在不是看它们的时候——走！」；马蒂亚斯认出断拐杖，提一句「你爷爷是木匠」。

## 测试结果（全部改完后）
- `play.py krampus`：`krampus OK`，没有 ERRORS，没有 REACH WARNINGS。主线走的是真结局（`true`），途中验证了卡片拼错一次、托尼道歉选错一次。
- 引它过来（真人速度、按住方向键走路）：一直走 → 成功（全程它在 3–7 格之外）；起步愣 2.6 秒 → 挨一桦枝，继续走仍然成功；愣两次 → 「进了篓子」，重来后从 `lure` 检查点开始（位置复位、先说一遍规则），走过去成功；一路跑到台阶站着 → 它掉头装走菲利克斯（死亡）；一路跑、等它掉头后跑回去追 → 它重新跟上，走回台阶成功。
- 坏结局 `bell`：游行时站着不动，150.6 秒后钟敲七下 → 坏结局；重来后灯、黑暗度复位，倒计时 90 秒。
- 坏结局 `mask`：戴上黑面具 → 坏结局；重来后面具回到喷泉沿上。
- 普通结局 `good`：不向菲利克斯道歉 → 「最后一行红字」，记入结局收集。
- 林子：第一次走错路 → 吓回岔路口；第二次 → 死亡「林子里的背篓」，重来回到林子检查点，警告次数复位。牵着小雪走回去会触发树影里的一瞥，回到小镇时小雪还跟着。
- 游行里连续指认错 5 次（每次扣 20 秒，提示逐级给到答案），仍来得及指认真的那个。
- 截图检查：1280×800 和 768×1024（iPad 竖屏）下布局、光照、人物位置、文字都正常；选章卡片能认出坎卜斯。
