# 第二十五夜 热沃当怪兽 · 自审 20 点（全部已实现）

## 谜题
1. 推理答错第一次就直接给方向，提示分级太快 → 照 LESSONS 改成四级：第 1 次只指出错在哪（猜对一半、上风口、羊圈当中各有对症的话），第 2 次给方向（口诀头两句的意思），第 3 次给位置（西南角矮墙外的爪印），第 4 次直接给答案。
2. 方位密码盘的字母快捷键会被引擎截走，键盘玩家不知道怎么按 → 只用点按/方向键+回车，另配小键盘 1–9 按方位排的数字别名，并写进提示。

## 危险段
3. 实测守夜：被盯退后它回到柴堆旁边蹲守，柴永远拿不到 → 盯退以后它绕到离你最远的那一头去（`coolMove`），给搬柴留出空当。
4. 实测：背着它一路跑去抱柴，一夜只挨一次警告、根本死不了 → 柴堆挪到草垛旁更深的暗处；你背对它走时它不再先绕圈、直接扑；夜里它贴上来更快。现在乱跑两趟就会挨第二下。
5. 站在火光里没法赶它，玩家只能干等它自己走 → 火光里正对着它站定也会让它退（prowl 状态也累积「怕」）。
6. 扑之前没有任何预警，第一次扑像是随机的 → 它绕到背后 0.3 秒就压低脑袋、龇牙、低吼，0.7–0.75 秒才扑，扑到半路你转过来它会刹住。
7. 它贴在火光边上时调查它扎不到 → 扎矛的判定也认 prowl 状态。
8. 守夜开场「它从哪边来」和推理没有呼应 → 神父的第一声钟带出方向（「它从西南边来了」），和黄昏推出的答案对上。

## 氛围
9. 名场面「它放着羊群不碰」只靠旁白 → 它一出林子，羊群「哄」地四散奔逃（并发走路），它从羊群里穿过去，只盯着石头底下的艾蒂安；白额慌不择路冲进林子，引出后面的找羊。
10. 夜里只有狗叫，听不出它摸到了哪 → 它靠近羊圈时圈里的羊会挤成一团乱叫，作为第二个声标。
11. 白天高地上太安静 → 远远近近的羊铃和咩声（`S.tone` 合成，音量随机）。
12. 白天的林子用了夜里虫鸣的环境声 → 改成低沉的 drone。

## 画面
13. 钟楼上的铁公鸡被顶栏挡住，推理关键线索看不见 → 教堂整体下移一行、尖顶压低，铁公鸡画大并让鸡头冲右上（东北）。
14. 它在羊圈周围绕的时候会穿过石墙、在圈里转悠 → 位置落进羊圈就推回墙外（`penOut`），只有火灭了才从缺口钻。

## 结局
15. 隐藏结局「圣母的蜡烛」条件（点蜡烛 + 记下 4 条线索）太隐蔽 → 神父给蜡烛时多一句「看见什么都记在心里」；普通好结局末尾按缺的那一样给一句暗示（没点蜡烛 / 线索没看全）。

## 叙事
16. 黄昏「你说那是个什么东西」的回答在结尾没有回应 → 猎人按狼 / 别的野兽 / 人 / 说不清各回一句（「说不清就对了。说得清的人，都在吹牛。」）。

## 双人
17. 白天对峙只有操作的人有事做 → 联机时提示改成「操作的人原地转身，另一个人盯着它喊方向」（推理、守夜的分工提示原本就有）。

## bug
18. 早上把羊放出来后还能进屋，六只羊会跟进屋里 → 羊出圈后屋门不让进。
19. 走近吃草的羊时它正好挪开，调查落空（测试里也偶发失败） → 人走到 3 格以内，羊就站住不挪。
20. 第一次火灭时巴蒂斯特老爹被放在火堆旁的空格上，常常正好压在玩家身上 → 改放在火堆外侧。

## 测试结果（第二步结束后完整跑一遍）
- 主线 `play.py gevaudan`：`gevaudan OK`，无 ERRORS、无 REACH WARNINGS（主线把守夜缩短到 45 秒，结局为隐藏结局「圣母的蜡烛」）。
- 白天对峙按真人速度（按键转身、反应 300 ms / 650 ms）：两种都能挡退三次，不挨打；站着不动：先被罗兰救一次，再被扑倒、死亡 → 重来（它回到林子边、rep/hits 归零、给规则小结）→ 赢；一看见它就往东跑：两次被扑、死亡 → 重来 → 赢。
- 守夜按真人速度（100 秒全长，按方向键走路、它贴上来就停下转身，反应 350 ms 跑步 / 450 ms 走路）：两种都熬到天亮，9 根柴刚好够用；什么也不做：火灭、老爹救一次、第二次羊圈破了、死亡 → 重来（火、柴、它的位置复位，时间取剩余+15 秒且不少于 45 秒，给规则小结）→ 赢；背对它直接跑去抱柴：两次被扑、死亡 → 重来 → 赢。
