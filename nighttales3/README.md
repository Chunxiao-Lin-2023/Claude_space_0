# 十夜怪谈·叁

《十夜怪谈》的第三部：再十个流传已久的怪谈，每个故事是一章俯视角探索解谜游戏。引擎、操作和双人联机与前两部相同——两人共享同一个角色和画面，同一时刻只有一人操作，另一人可以请求接手（操作者同意后交换）；部分关键选择两人各投一票。存档与前两部互不影响。

## 源码

- `src/shell.html` 页面骨架与样式；`src/js/` 引擎（从第一部复制并同步其修复，独立维护）；`src/chapters/` 每章一个文件；`src/PLAN.md` 十章策划。
- 构建：`python3 nighttales3/src/build.py`（生成 `index.html`；`--artifact out.html` 生成单人预览版；`--only id` 只打包某章）。
- 写新章节看 `src/AUTHORING.md`（末尾「已知坑」）。
- 测试：`src/tests/play.py`（每章自动通关，并检查每一步真人能否走到，步骤在 `tests/sol/`）、`src/tests/coop.py`（本地 PeerJS 服务器 + 双客户端联机）。
- 本地存储键前缀 `nighttales3.`；联机房间 id 前缀 `nighttales3-`。
