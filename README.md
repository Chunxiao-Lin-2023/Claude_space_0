# 机巧百战

浏览器小游戏：十六波机关兽闯关，支持鲁班七号皮肤、iPad 触屏操作和双人在线合作。

- 打开 `index.html`（或本仓库的 GitHub Pages 网址）即可游玩。
- 双人联机：一人在菜单里点「创建房间」，把 4 位房间码发给队友，队友输入后加入。联机走 WebRTC 直连，房主的页面需要保持在前台。
- iPad：Safari 打开网址，分享 →「添加到主屏幕」可全屏游玩。

## 裂隙守卫（riftwardens/）

俯视角陷阱塔防 + 动作游戏：在兽人冲向裂隙的通路上布置尖刺、路障、箭墙、弹射板等陷阱，再操控战法师或女术士亲自参战。4 个关卡、8 种陷阱、骷髅评价与军械库升级，支持单人和双人在线合作（房间码联机）。

- 打开 `riftwardens/index.html`（Pages 网址 `/riftwardens/`）即可游玩，键鼠和 iPad 触屏均可操作。
